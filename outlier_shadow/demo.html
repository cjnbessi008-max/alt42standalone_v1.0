📊 Outlier Shadow

Student Performance Monitor with Dark Shadow Visualization

소개 (Introduction)

Outlier Shadow는 Moodle 3.7 LMS와 연동하여 학생들의 성적 데이터를 실시간으로 모니터링하고, 통계적 이상치(outlier)를 어두운 그림자 효과로 시각화하는 모바일 웹 애플리케이션입니다.

The Outlier Shadow is a mobile web application that integrates with Moodle 3.7 LMS to monitor student performance data in real-time and visualize statistical outliers using dark shadow effects.

🎯

실시간 모니터링

30초마다 자동으로 최신 학생 성적 데이터를 업데이트하여 실시간으로 성과를 추적합니다.

📊

이상치 탐지

IQR과 Z-score 통계 방법을 사용하여 저성취 및 고성취 학생을 자동으로 식별합니다.

🌑

그림자 시각화

이상치를 어두운 그림자로 표시 - 빨간색은 위험군, 파란색은 우수 학생을 나타냅니다.

📱

모바일 최적화

우측 하단에 표시되는 가상 스마트폰 화면으로 모바일 환경에 최적화되었습니다.

🔗

Moodle 연동

Moodle 3.7 데이터베이스에 직접 연결하여 퀴즈 및 평가 데이터를 가져옵니다.

🎨

필터링 기능

전체, 이상치만, 위험군, 우수 학생 등 다양한 필터로 데이터를 조회할 수 있습니다.

사용 방법 (How to Use)

기본 사용:

http://your-server/outlier_shadow/

강좌별 필터:

http://your-server/outlier_shadow/?course_id=123

퀴즈별 필터:

http://your-server/outlier_shadow/?quiz_id=456

Z-score 방법 사용:

http://your-server/outlier_shadow/?method=zscore
