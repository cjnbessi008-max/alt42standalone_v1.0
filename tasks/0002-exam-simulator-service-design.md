# [1차 결과물] – 서비스 설계안

## 0. 컨셉 한 줄 정리

**"점수 올려주는 시간 운영 근육"을 키우는 수학 시험 시뮬레이터 + 멘탈 코치 앱**

---

## 1. 핵심 기능 구조

### 1-1. 핵심 루프 (매 세션 흐름)

#### 1️⃣ 시험 세팅 화면

**입력값:**
- 시험 이름 (예: 중2 1학기 중간, 모의고사 ○회차 등)
- 총 시험 시간 (예: 45분, 50분, 70분)
- 문항 수 (예: 20문항, 30문항)

**옵션:**
- 라운드 전략 선택
  - **기본 전략:**
    - 1라운드: 전 문제 훑기 + 쉬운 문제만 1분 컷으로 풀기
    - 2라운드: 중간 난이도, 확률 높은 문제 위주
    - 3라운드: 어려운 문제 / 모르는 문제 중 선택해서 도전 or 과감히 버리기

#### 2️⃣ 라운드별 풀이 화면
(실제 훈련의 메인 화면)

**상단:**
- 남은 전체 시간 큰 타이머
- 현재 라운드 표시 (1라운드 / 2라운드 / 3라운드)

**중앙:**
- 현재 문항 번호
- 학생이 보고 있는 시험지(실제 종이 시험 기준이면 "문항 번호만")

**하단 조작 버튼:**
- **[난이도 느낌 선택]** (3초 안에 선택)
  - "쉬움 / 보통 / 어려움 / 전혀 모르겠음"
  - 선택에 따라 자동 제안:
    - 쉬움 → "지금 바로 1분 안에 풀기" 버튼
    - 보통 → "표시만 해두고 다음으로" or "지금 2분 투자"
    - 어려움/전혀 모름 → "3라운드 후보로 보류"

- **[완료 / 틀린 느낌 / 시간 초과]** 기록 버튼

👉 **포인트**: "문항에 대한 감각 + 결정 + 행동" 3단계를 짧은 시간에 자동화시키는 구조.

#### 3️⃣ 세션 종료 후 회고 화면

**타임라인 뷰:**
- 문항 1~N까지
- 각 문항별:
  - 라운드(1/2/3)
  - 실제 투자 시간
  - 결과 (정답 / 오답 / 미풀이 / 버림)

**요약 리포트:**
- "쉬운 문제인데 건드리지도 않은 개수"
- "끝까지 붙잡다가 시간 낭비한 문제 개수"
- "마지막 5분 동안 풀었던 문제들 리스트"

**코칭 문구 예:**
- "이번 세션에서 쉬운 문제 3개를 마지막에 몰아서 풀었어. 다음엔 1라운드에서 바로 처리하는 연습을 추가하자."
- "마지막 10분 동안 어려운 문제 2개에 8분을 썼어. 이건 실제 시험에서 위험 신호야. 3라운드 '버리는 연습' 강도를 올리자."

## 2. "침착함"을 위한 멘탈 코칭 모듈

### 2-1. 시험 전 루틴 (Pre-Routine)

세션 시작 전에 30~60초짜리 루틴:
- "지금 목표는 만점이 아니라 시간 안에 쉬운 문제를 하나도 안 남기는 것"
- **간단 호흡 가이드:**
  - 4초 들이마시기 – 4초 멈추기 – 4초 내쉬기 (한 두 번)
- **감정 체크:**
  - "지금 긴장 정도 0~10 중에?"
  - 이 값은 나중에 리포트에 함께 기록 → "긴장 8 이상일 때 평균 오답률, 시간 폭주 패턴 분석"에 활용.

### 2-2. 시험 중 멘탈 이벤트

앱이 자동으로 트리거하는 상황별 메시지:

**남은 시간 70% → 50%로 떨어질 때:**
- "지금은 쉬운 문제 수를 늘려야 하는 타이밍이야. '애매한 문제'에 오래 머무르지 말기!"

**남은 시간 30% 미만:**
- "이제는 살릴 문제 / 버릴 문제를 나눌 시간. 점수 기대값 낮은 문제는 과감히 못 푼 걸로 두고, 계산만 하면 되는 문제를 우선 처리하자."

### 2-3. 시험 후 멘탈 리포트

**"멘탈 지표"로 요약:**
- 첫 10분: 집중도 (문항당 평균 처리 시간, 스킵 비율)
- 중간 20분: 고민 시간 폭주 여부
- 마지막 10분: 이득을 많이 본 구간인지, 손해를 본 구간인지

**간단한 한 줄 평가:**
- "이번 세션은 '초반 좋음, 막판 불안정' 패턴이야. 다음 세션에서 마지막 10분 전용 전략을 따로 훈련하자."

## 3. 선택과 집중 로직 (알고리즘 개념)

### 3-1. 문항 상태 모델

각 문항은 세션 중 이렇게 상태가 바뀜:

- `UNSEEN`: 아직 건드리지 않음
- `SCANNED`: 난이도 평가는 했지만 풀지는 않음
- `IN_PROGRESS`: 풀이 중
- `SOLVED_CORRECT`: 정답
- `SOLVED_WRONG`: 오답(학생이 회고 때 입력)
- `SKIPPED`: 의도적 패스
- `GIVEN_UP`: 끝까지 봤지만 버리기로 결정

이걸 기반으로:
- 쉬운 문제인데 `UNSEEN` 상태로 남은 것 → "선택 실패"
- 어려운 문제를 `IN_PROGRESS`로 잡고 있다가 `GIVEN_UP` → "집착 과다"

### 3-2. 라운드별 규칙

#### 1라운드 (전 문제 스캔 + 쉬운 것만 해결)

**규칙:**
- 문항당 최대 40~60초
- 난이도 "쉬움" 선택 시 → 바로 `IN_PROGRESS` & 풀기
- "보통/어려움/모름" → 표시만 하고 `SCANNED`로 넘김

**목표:**
- 전체 문항 중 쉬움 문제 80~100% 해결

#### 2라운드 (보통 난이도 정리)

- 1라운드에서 `SCANNED` & 난이도 "보통" 위주로 다시 순회
- 문항당 시간: 1~2분
- 오답 가능성이 높아 보이면 바로 플래그 + 다음 문제

#### 3라운드 (남은 시간 최대 효율)

**후보:**
- 난이도 "어려움" / "모름"
- 2라운드에서 애매해서 남긴 문제

**전략:**
- "부분점수 가능성이 높은 문제"부터 정렬
- 남은 시간과 문제별 예상 소요시간으로 점수 기대값이 높은 순 추천

## 4. 데이터 구조 & 지표

### 4-1. 세션 단위 저장 정보 (추상 설계)

**세션 정보:**
- `session_id`
- `user_id`
- 시험 이름 / 날짜
- 총 시험 시간
- 문항 수
- 시작·종료 시각
- 세션 전 긴장도(0~10)

**문항 정보 (문항마다):**
- `question_index`
- 라운드별 상태 리스트
  - 라운드 번호
  - 상태(`UNSEEN`/`SCANNED`/`IN_PROGRESS`/…)
  - 시작·종료 시간
- 최종 결과 (정답/오답/미풀이)
- 학생이 회고 때 입력한 난이도(실제 체감 난이도)

### 4-2. 통계·피드백용 지표

**시험별:**
- 쉬운 문제 중 안 건드린 문제 비율
- 마지막 10분 동안 푼 문제의 총 점수
- 한 문제에 3분 이상 쓴 횟수

**기간별(최근 5회 세션):**
- "시간 부족으로 못 건드린 쉬운 문제 평균 개수"
- "막판 5분에 푼 문제 정답률"

👉 이 지표들을 기반으로:
- "너는 쉬운 문제를 남기는 패턴이 반복되고 있어"
- "막판 10분 집중력이 꽤 좋은 편이라, 이제는 2라운드에서의 결정 속도를 더 키워보자"

같은 식으로 학생별 패턴 레이블링 가능.

## 5. 전체 작업 맵

### [선행] 환경설정
- 세션/문항/라운드 데이터 모델 정의
- 라운드 전략 기본값 정의 (1,2,3라운드 규칙)
- 간단한 리포트 구조 정의

### [핵심] 구현/테스트
- 시험 세팅 화면: 시간·문항 수·전략 선택
- 라운드별 풀이 화면: 타이머 + 문항 상태 변경 UI
- 멘탈 이벤트(시간 기준 알림) 로직
- 회고 리포트 화면 & 기초 통계 계산

### [후속] 배포/문서화
- 튜토리얼(처음 실행 시 1분 짜리 안내 플로우)
- 사용 가이드: "이 앱은 문제풀이 앱이 아니라 **시간·선택 훈련용**이다" 강조
- 나중에 시험지 이미지/OCR, 실제 문제 연동은 별도 모듈로 확장

## 6. 실행 검증(시뮬레이션 수준)

### 성공 시나리오 (예시)

학생이 "50분 / 25문항" 시험 세션 생성

1. 1라운드에서 25문항을 15분 안에 한 번 훑고, 쉬운 문제 10개 해결
2. 2라운드에서 보통 문제 8개 중 5개를 추가로 해결
3. 3라운드에서 어려운 문제 3개 중 1개 도전 후 버리기로 결정
4. 회고에서:
   - "버린 문제 2개 점수 합 6점, 대신 그 시간에 푼 쉬운 문제 덕에 10점 확보"라는 리포트 출력
   - → "버리기 훈련"이 점수에 도움이 됐다는 정서적 학습 발생

### 실패 시나리오 (예시)

학생이 1라운드에서부터 어려운 문제에 집착

1. 타이머가 계속 경고하지만 무시하고 5분 이상 한 문제에 묶임
2. 회고에서:
   - "5분 이상 매달린 문제 3개, 이 문제들이 전부 오답 or 미완성"
   - "그 시간에 다른 쉬운 문제 3개를 풀었다면 +○점이었음"
   - → 이걸 시각화해서 **"집착 패턴 = 점수 손실"**을 명확히 보여줌

## 7. 체크리스트 & 로드맵 요약

### 체크리스트 자동 생성

**□ 실제 작동 여부**
- 세션 중 앱이 백그라운드로 가도 타이머·기록 유지
- 네트워크 끊김 상황에서도 단일 세션 저장 가능

**□ 엣지 케이스 / 오류 처리**
- 문항 수를 잘못 입력했을 때 수정 플로우
- 세션 도중 강제 종료(폰 꺼짐 등) 후 재접속 시 리커버리 로직
- 라운드 시간 오버 시 자동 라운드 전환 처리 규칙

**□ 성능 / 보안 / 확장성**
- 데이터는 유저별로 격리, 시험 이름 정도만 저장
- 나중에 실제 시험지 이미지/OCR 데이터 붙여도 구조 안 깨지게 설계

**□ 배포 준비도**
- 온보딩 튜토리얼
- "이건 점수 보장 앱이 아니라 시간·멘탈 훈련용"이라는 설명 문구
- 학부모/학생용 안내 페이지(웹/문서) 설계 여지
