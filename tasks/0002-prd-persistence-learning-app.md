# Product Requirements Document: 끈기 중심 학습 앱 (Persistence Learning App)

## 1. 앱의 목표 & 컨셉

### 목표 한 줄 요약
**"정답보다 과정에 집착하게 만들어서, 한 문제를 오래 물고 늘어지게 한다."**

### 핵심 원칙
1. 답을 절대 빨리 안 보여준다.
2. 대신 질문·아이디어·시도 기록 을 계속 끌어내준다.
3. "아 몰라 포기…" 지점에서 미세 미션으로 쪼개서 다시 붙잡게 한다.

---

## 2. 전체 플로우 (한 문제 기준)

### 2.1 문제 선택/입력
- 사진 찍기 / 텍스트 입력 / 복붙 중 택1

### 2.2 초기 이해 단계 (3~5분)
- "문제를 자기 말로 다시 써보기"
- "조건·구해야 할 것 분리하기"

### 2.3 집중 생각 단계 (10~25분 블록)
- 타이머 + 방해 차단(다른 문제 못 넘어감)
- 아이디어/시도 기록
- 단계별 힌트 (바로 안 열림, 조건 있음)

### 2.4 막힘 해소 단계
- 감정/상태 체크("헷갈림/짜증/지루함/거의 다 왔다" 등)
- 상태별 개입(미션, 힌트, 잠깐 정리 등)

### 2.5 정리 & 회고 단계
- "내가 시도한 방법들"
- "어디까지 이해했고, 어디서 막혔는지"
- "다음에 비슷한 문제 나오면 어떻게 할지 한 줄 요약"

## 3. 화면/기능 설계

### 3-1. 홈 화면

**오늘의 한 문장:**
> "오늘은 이 문제 하나만 끝까지 물고 늘어져보자."

**버튼:**
- [새 문제 시작]
- [어제(이전) 문제 회고 보기]

### 3-2. 문제 집중 화면 (메인 UX)

**구성 4영역:**

#### 1) 문제 영역
- 문제 이미지 / 텍스트
- 확대/펜/밑줄 기능

#### 2) 생각 메모 영역
- "아이디어 카드" 형태
- 예:
  - 카드1: 처음 떠오른 생각
  - 카드2: 시도한 풀이 1
  - 카드3: 막힌 지점
- 한 줄씩 계속 추가 가능 (채팅처럼)

#### 3) 타이머 & 집중 상태
- 25분 / 15분 블록 선택 (포모도로 느낌)
- 남은 시간 표시 + "이번 블록 목표 한 줄 입력"

#### 4) 힌트/도움 패널
- 바로 열리지 않게 조건 설정:
  - "메모 2개 이상 썼을 때 열림"
  - "타이머 5분 이상 사용 후 열림"

### 3-3. 힌트 시스템 설계

힌트는 5단계로:

#### 레벨 1 – 문제 재구성 질문
- "이 문제에서 '알고 있는 것' 3가지만 써봐."
- "x, y 중에서 이미 값이 정해진 건 뭐야?"

#### 레벨 2 – 구조 파악
- "이건 '무슨 유형'에 제일 가깝다고 느껴져?" (예: 일차방정식/도형넓이/함수 그래프 등)
- "주어진 조건을 그림/표로 바꾸면 어떤 모양이야?"

#### 레벨 3 – 전략 제안
- "여기서 바로 답을 구하지 말고, '간단한 비슷한 예시 숫자'를 넣어보자."
- "식 세우기 전에, 따로 떼어낼 수 있는 부분이 있어?"

#### 레벨 4 – 부분 풀이
- 중간 단계까지만 공식/식 제시
- "여기까지는 이렇게 가. 나머지 계산은 네가 이어서 해봐."

#### 레벨 5 – 전체 풀이
- 정말 끝까지 끈질기게 버틴 뒤에만 공개
- **조건 예:**
  - 총 고민 시간 30분 이상
  - 메모 5개 이상
  - 최소 1번은 "거의 다 왔다" 버튼(스스로 평가) 누른 뒤

### 3-4. 감정/상태 인터페이스

**문제 화면 아래에 작은 바:**
> "지금 상태는?"

- 😕 하나도 모르겠음
- 😵 머리는 아는데 계산에서 꼬임
- 😤 거의 다 온 것 같은데 안 됨
- 😐 집중이 안 됨

**상태별 대응:**
- "하나도 모르겠음" → 개념·조건 재정리 미션 + 레벨1 힌트 추천
- "계산에서 꼬임" → 계산 예시/부분 풀이 제안
- "거의 다 왔는데 안 됨" → 체크리스트 제공
  - 조건 다 썼는지?
  - 단위/부호/괄호 확인했는지?
- "집중 안 됨" → 3분 미니 타이머 + "다음 3분 동안 할 딱 한 가지" 설정

### 3-5. 회고 화면

**세션 끝나면 자동 팝업:**

#### 이 문제에 쓴 총 시간
- "총 고민 시간: 42분"

#### 내가 남긴 메모 요약
- 아이디어 카드를 나란히 보여주기

#### 스스로 평가
- "이 문제에 대해 지금은 어느 정도 이해했어?"
- 0~5 점 슬라이더

#### 한 줄 회고
- "다음에 비슷한 문제 나오면 이렇게 접근하자: ______"

## 4. 간단 로직/알고리즘 설계

### 4-1. 끈기 점수(Persistence Score)

**문제당 점수 계산 예시:**

- **고민 시간**: 최대 40점 (시간이 길수록 ↑, 하지만 너무 과하면 가중치 감소)
- **메모 수**: 최대 30점 (생각 기록을 많이 할수록 ↑)
- **힌트 사용**:
  - 레벨 1~3만 사용: 감점 적게
  - 레벨 5까지 열면: 감점 크지만 "완주 보너스"도 부여
- **재방문 시도**: 최대 10점 (한 문제를 나눠 고민한 횟수)

→ 이 점수를 주간/월간 통계로 보여주면
**"너는 정답률 말고 끈기 자체가 올라가고 있다"**는 피드백 가능.

### 4-2. 힌트 오픈 조건 로직 (예시)

```
if (누적_고민시간 >= 5분 AND 메모수 >= 2) then
    레벨1,2 힌트 오픈
if (누적_고민시간 >= 15분 AND 시도기록 >= 2) then
    레벨3 힌트 오픈
if (누적_고민시간 >= 25분 AND 감정상태: "거의 다 왔다") then
    레벨4 힌트 오픈
if (누적_고민시간 >= 30~40분 AND 레벨1~4 모두 사용) then
    레벨5 전체 풀이 오픈
```

## 5. 체크리스트 (실제 개발 관점)

### □ 실제 작동 여부
- [ ] 문제 입력: 사진/텍스트/복붙 최소 1개 방식부터 구현
- [ ] 타이머 + 문제 잠금: 한 세션 동안 다른 문제 못 열게
- [ ] 메모/아이디어 저장 & 다시 보기
- [ ] 힌트 레벨 1~3까지 먼저 구현 (4~5는 후속)

### □ 엣지 케이스 / 오류 처리
- [ ] 앱 강제 종료 후 재시작 시: 현재 문제·타이머·메모 복구
- [ ] 네트워크 끊김에도 로컬에 기록 저장
- [ ] 문제 사진이 너무 흐릿한 경우(인식 안 되는 경우) 대비: "사진 다시 찍기" 가이드

### □ 성능 / 확장성
- [ ] 모든 기록(시간, 메모, 힌트사용)을 구조화해서 저장 → 나중에 통계/추천에 활용 가능
- [ ] 문제 단위 데이터 구조:
  - problem_id, 입력 방식, 세션 로그, 끈기 점수 등

### □ 배포 준비도
- [ ] 첫 버전은 "한 문제 모드 전용" 심플 버전으로 시작
- [ ] 회원 시스템 없이 "로컬 저장→나중에 계정 연동" 구조도 가능

## 6. 실행 시뮬레이션 (짧게)

1. 학생이 시험 대비하다가 어려운 문제 사진 찍어서 앱에 올림
2. 앱이 묻는다: "네 말로 문제를 다시 써줘"
3. 15분 타이머 시작, 아이디어 메모 3개 작성
4. 막혀서 "하나도 모르겠음" 선택 → 레벨1 힌트 오픈
5. 다시 시도, 그래도 안 돼서 레벨2,3까지 사용
6. 총 35분 고민 후 레벨5 전체 풀이 확인
7. 회고 화면에서 "다음에는 이런 순서로 풀자" 한 줄 작성
8. 끈기 점수 +1 문제 기록

## 7. 확인사항 (설계 고도화용 체크 질문)

1. 이 앱을 쓰는 주 사용자는 초등 / 중등 / 고등 중 어디에 더 가깝게 보고 있어?
2. 한 문제당 현실적으로 허용하고 싶은 최대 고민 시간은 어느 정도로 생각해? (예: 20분 / 40분 / 60분)
3. 이걸 단독 앱으로 만들지, 아니면 기존 공부 시스템에 기능 모듈로 붙일지 어느 쪽에 더 가깝게 보고 있어?
