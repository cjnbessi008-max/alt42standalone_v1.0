## Overview

The One-Second Graph is a visualization feature that displays educational concept graphs with a precisely choreographed 1-second animation sequence. It compresses complex relationship data into an intuitive, engaging visual experience on a virtual smartphone display.

## Problem Statement

Teachers need to quickly understand the concept relationships generated by the AI Education System. Traditional graph visualizations either:
- Appear all at once (overwhelming)
- Animate too slowly (boring)
- Lack clear visual hierarchy (confusing)

The One-Second Graph solves this by presenting information in digestible phases while maintaining engagement.

## Solution

A precisely timed 1000ms animation sequence that progressively reveals:
1. Core concepts (nodes)
2. Relationships (edges)
3. Spatial organization (layout)
4. Interactive capabilities

Displayed within a realistic virtual smartphone frame to simulate the student experience.

## Animation Specification

### Timeline (1000ms total)

| Phase | Time Range | Duration | Purpose | Visual Effect |
|-------|-----------|----------|---------|---------------|
| **Phase 1: Nodes** | 0-250ms | 250ms | Introduce concepts | Fade-in + scale up |
| **Phase 2: Edges** | 250-500ms | 250ms | Show relationships | Draw connections |
| **Phase 3: Stabilize** | 500-750ms | 250ms | Organize layout | Physics simulation |
| **Phase 4: Interactive** | 750-1000ms | 250ms | Enable interaction | Fit to view + enable hover |

### Phase Details

#### Phase 1: Nodes (0-250ms)
**Purpose**: Introduce educational concepts

**Technical Implementation**:
```typescript
nodes.forEach((node) => {
  nodes.update({
    ...node,
    opacity: 0 → 1,
    scaling: { min: 0.5 → 1, max: 0.5 → 1 },
  });
});
```

**Visual Result**:
- All nodes appear simultaneously
- Fade from transparent to opaque
- Scale from 50% to 100%
- Creates "pop-in" effect

**User Experience**:
- Student sees what concepts exist
- Color coding indicates concept types
- Labels are immediately readable

#### Phase 2: Edges (250-500ms)
**Purpose**: Reveal relationships between concepts

**Technical Implementation**:
```typescript
edges.forEach((edge) => {
  edges.update({
    ...edge,
    color: { ...edge.color, opacity: 0 → 1 },
  });
});
```

**Visual Result**:
- Edges draw from source to target
- Arrow indicators appear
- Relationship labels fade in
- Connections become clear

**User Experience**:
- Student understands how concepts relate
- "has-a", "visualized-as", "requires" relationships
- Directional arrows show dependency flow

#### Phase 3: Stabilize (500-750ms)
**Purpose**: Organize graph into readable layout

**Technical Implementation**:
```typescript
network.stabilize(50); // 50 iterations
```

**Physics Settings**:
```typescript
barnesHut: {
  gravitationalConstant: -8000,
  centralGravity: 0.3,
  springLength: 150,
  springConstant: 0.04,
  damping: 0.09,
  avoidOverlap: 0.5,
}
```

**Visual Result**:
- Nodes spread out to avoid overlap
- Related concepts group together
- Layout becomes hierarchical
- Visual balance achieved

**User Experience**:
- Graph becomes readable
- Natural clustering emerges
- Spatial relationships match conceptual ones

#### Phase 4: Interactive (750-1000ms)
**Purpose**: Enable user exploration

**Technical Implementation**:
```typescript
network.fit({
  animation: {
    duration: 250,
    easingFunction: 'easeOutQuad',
  },
});
```

**Enabled Interactions**:
- ✅ Hover over nodes (tooltips appear)
- ✅ Click and drag nodes (repositioning)
- ✅ Zoom in/out (mouse wheel)
- ✅ Pan graph (drag background)

**Visual Result**:
- Graph animates to fit viewport
- Optimal zoom level set
- All nodes visible
- Ready for interaction

**User Experience**:
- Student can explore concepts
- Click to learn more details
- Manipulate to better understand

## Data Model

### GraphData Interface

```typescript
interface GraphData {
  nodes: GraphNode[];
  edges: GraphEdge[];
}
```

### GraphNode Interface

```typescript
interface GraphNode {
  id: string;              // Unique identifier
  label: string;           // Display name (supports \n for multiline)
  title?: string;          // Tooltip text
  level?: number;          // Hierarchy level (1=core, 2=secondary, 3=details)
  color?: string;          // Background color (hex)
}
```

**Example**:
```typescript
{
  id: '1',
  label: 'Fraction\n(분수)',
  title: 'Core concept: Fraction',
  level: 1,
  color: '#667eea',
}
```

### GraphEdge Interface

```typescript
interface GraphEdge {
  id: string;              // Unique identifier
  from: string;            // Source node ID
  to: string;              // Target node ID
  label?: string;          // Relationship type
  arrows?: string;         // 'to', 'from', 'to,from'
}
```

**Example**:
```typescript
{
  id: 'e1',
  from: '1',
  to: '2',
  label: 'has-a',
  arrows: 'to',
}
```

## Performance Optimization

- **Initial Load**: < 2 seconds

### Data Validation

```typescript
function validateGraphData(data: unknown): GraphData {
  // Validate nodes
  if (!Array.isArray(data.nodes)) throw new Error('Invalid nodes');

  // Validate edges
  if (!Array.isArray(data.edges)) throw new Error('Invalid edges');

  // Validate node IDs are unique
  const ids = new Set(data.nodes.map(n => n.id));
  if (ids.size !== data.nodes.length) {
    throw new Error('Duplicate node IDs');
  }

  return data as GraphData;
}
```
