예제 문제 1: 벡터의 기본

벡터 v = (3, 4)의 크기를 구하시오.

벡터는 크기와 방향을 모두 가진 물리량입니다. 벡터의 크기는 |v| = √(x² + y²) 공식으로 구할 수 있습니다.

예제 문제 2: 벡터의 덧셈

두 벡터 A = (2, 3)과 B = (1, -1)의 합벡터를 구하시오.

벡터의 덧셈은 평행사변형 법칙을 따릅니다. 성분별로 더하면: A + B = (2+1, 3+(-1)) = (3, 2)

예제 문제 3: 내적과 외적

벡터 a = (1, 2, 3)과 b = (4, 5, 6)의 내적을 구하시오.

내적(dot product)은 a·b = a₁b₁ + a₂b₂ + a₃b₃로 계산됩니다. 외적(cross product)은 두 벡터에 수직인 새로운 벡터를 생성합니다.
