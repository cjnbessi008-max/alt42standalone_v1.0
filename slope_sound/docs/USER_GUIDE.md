## 시작하기

### Slope Sound란?

Slope Sound는 수학의 도함수 개념을 **시각**과 **청각**을 통해 동시에 학습할 수 있는 교육용 웹 애플리케이션입니다.

**핵심 아이디어**:
- 함수의 각 점에서 **기울기(도함수)**를 계산
- 기울기 값을 **소리의 높낮이**로 변환
- 학습자가 그래프를 탐색하며 직관적으로 도함수 이해

### 접속 방법

1. **Moodle 통합 버전**
   - Moodle에 로그인
   - 코스 페이지에서 "Slope Sound" 활동 클릭
   - 또는 직접 URL: `https://your-moodle.com/local/slopesound/webapp/`

2. **독립 실행 버전**
   - 브라우저에서 직접 접속
   - URL: `https://your-site.com/slope-sound/`

## 기본 사용법

### 1단계: 문제 선택

좌측 상단 "문제 선택" 영역에서 학습하고 싶은 함수를 클릭합니다.

**문제 정보**:
- **제목**: 함수 타입 (예: Basic Quadratic)
- **함수식**: f(x) = x^2 형태
- **난이도**: ⭐ (쉬움) ~ ⭐⭐⭐ (어려움)
- **범위**: 함수의 정의역 [최소, 최대]

**예시**:
```
Basic Quadratic
함수: f(x) = x^2
난이도: ⭐
범위: [-5, 5]
```

### 2단계: 그래프 탐색

우측 하단 가상 스마트폰 화면에 함수 그래프가 표시됩니다.

**마우스 사용** (데스크톱):
- 그래프 위에 마우스를 **올려놓으면** 자동으로 소리 재생
- 원하는 부분을 **드래그**하며 탐색

**터치 사용** (모바일/태블릿):
- 그래프를 **손가락으로 터치**
- **드래그**하며 여러 점 탐색

### 3단계: 사운드 듣기

각 점을 터치/마우스오버할 때마다:

🎵 **사운드 규칙**:
- **기울기 > 0** (증가) → 높은 음 ↗
- **기울기 = 0** (평평) → 중간 음 →
- **기울기 < 0** (감소) → 낮은 음 ↘

**기울기 크기**와 **음 높이** 비례:
- 기울기 +10 → 880 Hz (높은 소리)
- 기울기 0 → 440 Hz (기준음 A4)
- 기울기 -10 → 220 Hz (낮은 소리)

### 4단계: 정보 확인

화면 하단 정보 패널에서 실시간 값을 확인:

| 항목 | 설명 | 예시 |
|------|------|------|
| **X** | 현재 x 좌표 | 2.50 |
| **f(x)** | 함수 값 (y 좌표) | 6.25 |
| **기울기** | 도함수 값 f'(x) | 5.00 |
| **주파수** | 재생 중인 소리 주파수 | 650 Hz |

### 5단계: 진행도 확인

화면 최하단의 진행도 바:
- 탐색한 영역의 비율 표시
- 80% 이상 탐색 시 "완료" 상태

**색상 코드**:
- 🟣 보라색 바: 탐색한 영역
- ⬜ 회색 바: 아직 탐색 안한 영역

## 고급 기능

### 버튼 기능

#### ▶ 소리 재생
- 현재 선택된 점의 기울기를 **500ms 동안 재생**
- 소리를 더 길게 들어보고 싶을 때 사용

#### 🔄 초기화
- 탐색 기록 초기화
- 진행도 0%로 리셋
- 그래프는 그대로 유지

#### ← 뒤로가기
- 문제 선택 화면으로 돌아가기
- 다른 문제 선택 가능

### 탐색 전략

#### 전체 파악하기
1. 왼쪽 끝에서 오른쪽 끝까지 **천천히 드래그**
2. 소리가 어떻게 변하는지 귀 기울이기
3. 전체적인 패턴 파악

#### 특정 구간 집중 분석
1. 흥미로운 구간 찾기 (소리가 급격히 변하는 곳)
2. 해당 구간을 **반복해서 탐색**
3. 기울기 값 확인하며 이해

#### 극값 찾기
- **소리가 중간 음**이 되는 곳 = 기울기 0 = **극값**
- 증가 → 평평 → 감소: **극대값**
- 감소 → 평평 → 증가: **극소값**

### 다양한 함수 타입별 특징

#### x^2 (이차 함수)
- 대칭적인 U자 모양
- 중앙(x=0)에서 기울기 0 (극소)
- 좌측: 낮은 음 (음수 기울기)
- 우측: 높은 음 (양수 기울기)

#### x^3 - 3x (삼차 함수)
- S자 모양
- 2개의 극값 (극대, 극소)
- 변곡점에서 기울기 변화율 최대

#### sin(x) (삼각 함수)
- 파동 형태
- 주기적으로 반복되는 패턴
- 극값이 여러 개 (주기적)

#### exp(x/2) (지수 함수)
- 계속 증가
- 기울기도 계속 증가
- 소리가 점점 높아짐

### 학습자용 활동지

#### 활동 1: 소리와 기울기

**목표**: 기울기와 소리의 관계 이해

1. x^2 함수를 선택하세요
2. 다음 점들을 탐색하고 표를 완성하세요:

| x | f(x) | 기울기 | 주파수 | 소리 높낮이 |
|---|------|--------|--------|-------------|
| -3 | 9 | | | |
| 0 | 0 | | | |
| 3 | 9 | | | |

3. **질문**: 왜 x = -3과 x = 3에서 소리가 다를까요?

#### 활동 2: 극값 탐험가

**목표**: 극값 개념 이해

1. x^3 - 3x 함수를 선택하세요
2. 소리가 **중간 음**(약 440 Hz)이 되는 점을 찾으세요
3. 찾은 점의 x 좌표: ________, ________
4. 이 점들이 극대인지 극소인지 판단하고 이유를 설명하세요

#### 활동 3: 함수 예측

**목표**: 도함수 패턴 예측

1. sin(x) 함수를 먼저 **보지 말고** 예측하세요:
   - 주기 함수라면 소리 패턴도 반복될까요?
2. 실제로 탐색하고 예측과 비교하세요
3. 발견한 패턴을 기록하세요

### 학부모용 안내

**집에서 함께 하는 수학 놀이**

Slope Sound는 게임처럼 재미있게 수학을 배울 수 있습니다:

1. **함께 탐색하기**
   - 자녀와 함께 그래프를 탐색하며 소리 들어보기
   - "소리가 높아지네!", "여기서 평평해!" 등 대화하기

2. **퀴즈 게임**
   - 부모: 특정 x 좌표 제시
   - 자녀: 해당 점의 기울기 예측 후 확인

3. **음악과 연결**
   - 도레미파솔라시도와 기울기 값 연결하기
   - 멜로디처럼 들리는 구간 찾기

## FAQ

### 기술 관련

**Q: 소리가 나지 않아요**
A:
- 브라우저의 소리 설정을 확인하세요
- 한 번 클릭한 후 다시 시도하세요 (자동재생 정책)
- Chrome, Firefox, Safari 최신 버전 사용 권장

**Q: 그래프가 표시되지 않아요**
A:
- 페이지를 새로고침하세요
- 브라우저 Console에서 에러 확인 (F12)
- JavaScript가 활성화되어 있는지 확인

**Q: 모바일에서도 사용할 수 있나요?**
A:
- 네! 터치스크린 완벽 지원
- 가로/세로 모드 모두 사용 가능
- 권장 화면 크기: 최소 360px

### 학습 관련

**Q: 도함수를 모르는데 사용할 수 있나요?**
A:
- 네! 오히려 도함수를 배우기 전에 사용하면 좋습니다
- 직관적으로 "기울기"를 먼저 체험한 후
- 나중에 공식으로 배우면 이해가 쉬워집니다

**Q: 어떤 순서로 학습하면 좋나요?**
A:
1. x^2 (기본 개념)
2. sin(x) (주기성)
3. x^3 - 3x (극값)
4. exp(x/2) (지수)
5. 복잡한 다항식

**Q: 진행도 100%를 달성해야 하나요?**
A:
- 필수는 아니지만 권장합니다
- 80% 이상이면 충분한 탐색
- 중요한 건 개념 이해, 완성도는 참고 지표

### 기타

**Q: 오프라인에서 사용할 수 있나요?**
A:

A:

## 접근성

Slope Sound는 다양한 학습자를 위해 설계되었습니다:

- **시각 학습자**: 그래프 시각화
- **청각 학습자**: 사운드 피드백
- **운동감각 학습자**: 인터랙티브 터치/드래그

**특수 교육 지원**:
- 고대비 모드 (설정 필요)
- 스크린 리더 호환 (부분 지원)
- 키보드만으로 조작 가능

## 학습 효과 극대화 팁

1. **반복 학습**: 같은 함수를 여러 번 탐색
2. **비교 학습**: 유사한 함수들 번갈아 탐색
3. **예측 후 확인**: 미리 예상하고 확인하는 습관
4. **소리 집중**: 시각 정보 없이 소리만 듣기 시도
5. **토론 활동**: 친구들과 발견 내용 공유
