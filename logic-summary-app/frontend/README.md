# Logic Summary Frontend

React + TypeScript frontend for the Logic Summary application.

## Features

- Problem input form with multilingual support (Korean/English)
- Real-time logic analysis and proposition extraction
- Interactive logic summary display
- Virtual smartphone UI (bottom-right corner) showing mobile view
- Responsive design with TailwindCSS

## Setup

### Prerequisites

- Node.js 18+ and npm

### Installation

1. Install dependencies:
```bash
cd frontend
npm install
```

2. Configure environment (optional):
```bash
cp .env.example .env
# Edit .env if backend is not on localhost:8000
```

### Running the Development Server

```bash
npm run dev
```

The app will be available at http://localhost:5173

### Building for Production

```bash
npm run build
```

The production build will be in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```

## Features Explained

### Virtual Smartphone Display

The bottom-right corner displays a virtual smartphone showing how the logic summary would appear on a mobile device. This provides:
- Mobile-optimized view of analysis results
- Real device simulation with notch and home indicator
- Responsive proposition cards
- Progress bars for confidence scores

### Logic Summary Display

The main display shows:
- Extracted propositions with type badges
- Confidence scores for each proposition
- Logical relationships between propositions
- Human-readable summary generated by AI
