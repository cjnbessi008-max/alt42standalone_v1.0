# 🎨 Existence Color - 근의 존재 시각화 웹앱

근의 존재 여부를 색감으로 판단하는 수학 학습 애플리케이션입니다.

## 📱 기능

### 1. Existence Color (존재 색상)
방정식의 근 존재 여부와 유형을 직관적인 색상으로 표현합니다:

- 🟢 **초록색**: 서로 다른 실근 2개 (D > 0)
- 🔵 **파란색**: 중근 또는 실근 1개 (D = 0)
- 🟣 **보라색**: 복소근 2개 (D < 0)
- 🟠 **주황색**: 서로 다른 실근 3개 (삼차방정식)
- 🔴 **빨간색**: 실근 1개 + 복소근 2개 (삼차방정식)

### 2. 지원 방정식
- **이차방정식**: ax² + bx + c = 0
- **삼차방정식**: ax³ + bx² + cx + d = 0

### 3. 시각화 기능
- 가상 스마트폰 화면에 앱 UI 표시
- 실시간 방정식 분석
- 판별식 계산 및 표시
- 근 목록 표시 (실근 및 복소근)
- 그래프 그리기 (실근 위치 강조)

## 🚀 사용 방법

### 실행
1. `index.html` 파일을 웹 브라우저에서 엽니다
2. 또는 로컬 서버를 실행합니다:
   ```bash
   # Python 3
   python -m http.server 8000

   # 브라우저에서 접속
   # http://localhost:8000
   ```

### 방정식 입력
1. **방정식 타입 선택**: 이차방정식 또는 삼차방정식
2. **계수 입력**: 각 항의 계수를 입력 (소수점 가능)
3. **분석하기 버튼 클릭**: 근을 분석하고 색상으로 표시

### 예제 사용
화면 왼쪽의 "예제" 섹션에서 미리 준비된 예제를 클릭하면 자동으로 분석됩니다:

#### 이차방정식 예제:
- `x² - 5x + 6 = 0` → 🟢 서로 다른 실근 2개 (x=2, x=3)
- `x² - 4x + 4 = 0` → 🔵 중근 (x=2)
- `x² + 1 = 0` → 🟣 복소근 2개 (x=±i)

#### 삼차방정식 예제:
- `x³ - 8 = 0` → 🔴 실근 1개 + 복소근 2개
- `x³ - 4x = 0` → 🟠 실근 3개

## 📐 수학 알고리즘

### 이차방정식 (Quadratic Equation)
- **판별식**: D = b² - 4ac
- **근의 공식**: x = (-b ± √D) / (2a)
- **분류**:
  - D > 0: 서로 다른 실근 2개
  - D = 0: 중근
  - D < 0: 복소근 2개

### 삼차방정식 (Cubic Equation)
- **Cardano's Formula** 사용
- **판별식**: Δ = -4p³ - 27q²
- **분류**:
  - Δ > 0: 서로 다른 실근 3개
  - Δ = 0: 중근 포함
  - Δ < 0: 실근 1개 + 복소근 2개
