# LMS 학습 참여도 자동 감지 및 알림 시스템 설치 가이드

Moodle 3.7 LMS에서 학습자의 집중력 저하(DMN drift)를 자동으로 감지하고 알림을 보내는 플러그인입니다.

## 주요 기능

### 🎯 실시간 참여도 추적
- 마우스 움직임, 키보드 활동, 스크롤, 페이지 포커스 모니터링
- 비활성 또는 주의 분산 구간 자동 감지
- 실시간 참여도 점수 계산

### 🔔 지능형 알림 시스템
- **학습자 알림**: 집중력이 떨어질 때 부드러운 화면 알림
- **교사 알림**: 학생의 참여도 저하 시 실시간 알림
- 알림 임계값 및 쿨다운 시간 설정 가능
- 심각도 기반 알림 시스템 (1-5 단계)

### 📊 종합 리포트
- 코스 전체 참여도 통계
- 개별 학생 참여 이력
- 세션 기반 추적 및 참여도 점수
- 분석용 데이터 내보내기 기능

## 시스템 요구사항

- **Moodle**: 3.7 이상
- **PHP**: 7.1.9 이상
- **MySQL**: 5.7 이상
- 최신 웹 브라우저 (Chrome, Firefox, Safari, Edge)

## 설치 방법

### 방법 1: 수동 설치 (권장)

1. **플러그인 파일 복사**
   ```bash
   cd /var/www/html/moodle/local/
   # 플러그인 파일을 engagementalert 폴더에 복사
   cp -r /path/to/engagementalert ./
   ```

2. **권한 설정**
   ```bash
   cd engagementalert
   chmod -R 755 .
   chown -R www-data:www-data .
   ```

3. **Moodle 관리자 페이지에서 설치**
   - 관리자로 로그인
   - 사이트 관리 → 알림 메뉴로 이동
   - "지금 Moodle 데이터베이스 업그레이드" 클릭
   - 플러그인이 자동으로 데이터베이스 테이블 생성

### 방법 2: ZIP 파일 업로드

1. 플러그인을 ZIP 파일로 압축
2. Moodle 관리자로 로그인
3. 사이트 관리 → 플러그인 → 플러그인 설치
4. ZIP 파일 업로드
5. 설치 마법사 따라가기

## 설정 방법

### 관리자 설정

**경로**: 사이트 관리 → 플러그인 → 로컬 플러그인 → Engagement Alert System

| 설정 항목 | 기본값 | 설명 |
|-----------|--------|------|
| **비활성 임계값** | 120초 | 사용자를 비활성으로 간주하기 전 대기 시간 |
| **포커스 상실 임계값** | 60초 | 포커스 상실(탭 전환, 창 블러) 후 알림까지 시간 |
| **학습자 알림 활성화** | 예 | 집중력 저하 감지 시 학생에게 팝업 알림 표시 |
| **교사 알림 활성화** | 예 | 학생 집중력 저하 시 교사에게 알림 전송 |
| **추적 간격** | 30초 | 서버로 추적 데이터 전송 주기 |
| **알림 쿨다운** | 300초 | 동일 사용자에 대한 최소 알림 간격 |

### 학년별 권장 설정

**초등/중학교 (높은 관리 감독)**
- 비활성 임계값: 90초
- 학습자 알림: 활성화
- 교사 알림: 활성화
- 알림 쿨다운: 180초

**고등학교/대학교 (중간 관리 감독)**
- 비활성 임계값: 120초
- 학습자 알림: 활성화
- 교사 알림: 선택적 활성화
- 알림 쿨다운: 300초

**자기주도 학습 (낮은 관리 감독)**
- 비활성 임계값: 180초
- 학습자 알림: 활성화
- 교사 알림: 비활성화
- 알림 쿨다운: 600초

## 사용 방법

### 학습자용

플러그인은 자동으로 백그라운드에서 작동합니다:

1. 코스 학습 자료에 접속하면 자동으로 추적 시작
2. 오랫동안 비활성 상태이거나 집중력을 잃으면 부드러운 알림 표시
3. "확인" 버튼을 클릭하여 알림을 닫고 학습 계속
4. 참여도 데이터는 교사가 수업 참여도를 파악하는 데 도움

**개인정보 안내**: 참여 패턴만 추적됩니다 (마우스/키보드 활동, 포커스 상태). 키 입력 내용이나 화면 캡처는 기록되지 않습니다.

### 교사용

**참여도 리포트 보기:**

1. 본인의 코스로 이동
2. 코스 관리 → 리포트 → Engagement Report
3. 확인 가능한 정보:
   - 모든 학생의 참여도 지표 목록
   - 총 세션 수, 알림 수, 참여도 점수
   - 마지막 활동 시간
   - 추가 분석을 위한 데이터 내보내기

**알림 받기:**

1. 플러그인 설정에서 교사 알림 활성화 (관리자)
2. 학생이 집중력 저하 징후를 보이면:
   - 팝업 알림 (온라인 상태인 경우)
   - 이메일 알림 (설정된 경우)
3. 메시지 내용: 학생 이름, 코스, 알림 유형

**지표 이해하기:**

- **참여도 점수 (0-100)**:
  - 80-100: 우수한 참여도
  - 60-79: 양호한 참여도
  - 40-59: 보통 참여도 (일부 집중력 저하)
  - 0-39: 낮은 참여도 (빈번한 집중력 저하)

- **알림 유형**:
  - **Inactive (비활성)**: 마우스/키보드 활동 없음
  - **Unfocused (포커스 상실)**: 탭 전환 또는 창 블러
  - **Slow Progress (느린 진행)**: 활동에 비정상적으로 오랜 시간 소요

## 데이터베이스 스키마

### 생성되는 테이블

1. **mdl_local_engagement_events**: 개별 추적 이벤트 (마우스, 키보드, 포커스 등)
2. **mdl_local_engagement_alerts**: 감지된 집중력 저하 사건
3. **mdl_local_engagement_sessions**: 세션 요약 데이터

### 저장 공간 요구사항

- 이벤트당 약 500 바이트
- 알림당 약 1KB
- 100명 학생 × 주당 5시간 학습: 연간 약 50MB

## 문제 해결

### 추적이 작동하지 않는 경우

**확인 사항:**
1. 브라우저에서 JavaScript 활성화 여부
2. 사용자에게 `local/engagementalert:view` 권한 있는지
3. 브라우저 콘솔에서 오류 확인 (F12 → Console 탭)
4. Moodle cron이 실행 중인지

**해결 방법:**
```bash
# Moodle 캐시 삭제
php admin/cli/purge_caches.php

# JavaScript 컴파일 확인
php admin/cli/build_theme.php
```

### 알림이 발생하지 않는 경우

**확인 사항:**
1. 임계값이 너무 높지 않은지 (테스트: 30초 비활성으로 설정)
2. 알림 쿨다운이 만료되지 않았는지
3. 권한이 올바르게 설정되었는지
4. 메시지 출력이 활성화되었는지: 사이트 관리 → 메시징 → 메시지 출력

### 교사가 알림을 받지 못하는 경우

**확인 사항:**
1. 교사에게 `local/engagementalert:receivealerts` 권한 있는지
2. 메시지 제공자 활성화:
   - 사이트 관리 → 메시징 → 알림 설정
   - "Engagement Alert" 찾기
   - 원하는 출력 활성화 (팝업, 이메일)
3. 교사의 메시지 환경설정이 알림을 허용하는지

## 개인정보 보호 및 GDPR 준수

### 수집되는 데이터
- 사용자 ID (Moodle 사용자와 연결)
- 접속 중인 코스/모듈
- 이벤트 유형 (마우스, 키보드, 포커스, 스크롤) - 타임스탬프만
- 세션 메타데이터 (시작 시간, 종료 시간, 이벤트 수)

### 수집되지 않는 데이터
- ❌ 키 입력 내용
- ❌ 마우스 좌표
- ❌ 화면 캡처
- ❌ Moodle 외부 브라우징 기록

### 데이터 보존 정책

자동 데이터 삭제 설정:
```php
// 예약된 작업 또는 cron에 추가
$days = 90; // 90일 보관
$cutoff = time() - ($days * 24 * 60 * 60);
$DB->delete_records_select('local_engagement_events', 'timestamp < ?', [$cutoff]);
```
