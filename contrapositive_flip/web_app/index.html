대우 학습 (Contrapositive)

💡 대우란?

논리학에서 대우(contrapositive)는 명제를 논리적으로 동치인 형태로 변환한 것입니다.

원명제: P → Q
(만약 P이면 Q이다)
⬇️
대우: ¬Q → ¬P
(만약 Q가 아니면 P도 아니다)
난이도: 1
원명제 (Original)
P: x > 5
→
Q: x > 3
만약 x > 5이면, x > 3이다
👆 카드를 탭하여 대우를 확인하세요
대우 (Contrapositive)
¬Q: x ≤ 3
→
¬P: x ≤ 5
만약 x ≤ 3이면, x ≤ 5이다
👆 카드를 다시 탭하여 원명제 보기
