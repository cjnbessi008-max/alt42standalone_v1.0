🚀 빠른 시작

1. 저장소 클론

git clone https://github.com/your-repo/alt42standalone_v1.0.git cd alt42standalone_v1.0

2. 백엔드 설정

# MySQL 데이터베이스 생성 mysql -u root -p < backend/sql/create_tables.sql # 설정 파일 복사 cd backend/config cp config.example.php config.php

3. 프론트엔드 실행

cd frontend npm install npm start

4. 브라우저에서 확인

http://localhost:3000

📖 사용 예시

Moodle 퀴즈 연동

<iframe src="http://alt42.local?quiz_id=123" width="100%" height="800" frameborder="0"> </iframe>

API 호출

// 문제 데이터 가져오기 fetch('http://localhost/alt42/backend/api/get-problem.php?quiz_id=1') .then(res => res.json()) .then(data => console.log(data)); // 응답 예시 { "success": true, "data": { "function": "1/x", "asymptotes": { "vertical": [0], "horizontal": [0] } } }
