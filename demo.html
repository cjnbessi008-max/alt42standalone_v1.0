🌊 Wavy Integral

물결치는 적분 시각화 웹 애플리케이션

📱 프로젝트 소개

Wavy Integral은 구간이 확장되면 넓이가 물결처럼 흔들리는 혁신적인 적분 시각화 웹 애플리케이션입니다. Moodle LMS와 연동하여 교육 현장에서 바로 활용할 수 있습니다.

✨ 주요 기능

  • 물결치는 적분 애니메이션 - 구간 확장 시 넓이가 파동처럼 흔들림
  • 가상 스마트폰 화면 - 우측 하단에 모바일 UI 표시
  • Moodle 3.7 LMS 연동 - 문제 정보 수신 및 답안 제출
  • 실시간 적분 계산 - 리만 합을 이용한 정적분 계산
  • 인터랙티브 컨트롤 - 구간 설정, 파동 강도 조절
  • 키보드 단축키 지원 - E(확장), R(초기화), Space(애니메이션 토글)

🚀 빠른 시작

1. 데이터베이스 설정

mysql -u root -p
source database/schema.sql

2. 설정 파일 수정

# api/db_config.php 파일에서 데이터베이스 정보 수정
define('DB_HOST', 'localhost');
define('DB_USER', 'your_username');
define('DB_PASS', 'your_password');

3. 서버 실행

php -S localhost:8000

📚 사용 예시

LMS에서 호출

http://localhost:8000?problem_id=PROB_001&student_id=STU_001

JavaScript API

// 애니메이션 시작
wavyIntegral.startAnimation();

// 구간 확장
wavyIntegral.expandInterval(0, 4);

// 파동 강도 설정
wavyIntegral.setWaveIntensity(0.8);

// LMS에 답안 제출
submitIntegralAnswer();

📊 데이터베이스 스키마

  • wavy_problems - 문제 정보 (ID, 제목, 파라미터, 정답)
  • wavy_students - 학생 정보 (ID, 이름, 이메일)
  • wavy_submissions - 답안 제출 기록 (점수, 시간)
  • wavy_progress - 학습 진행 상황 (시도 횟수, 최고 점수)
