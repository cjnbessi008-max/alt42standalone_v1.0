# 🚀 빠른 시작 가이드

## 5분 안에 시작하기

### 1️⃣ 파일 열기

웹 브라우저로 `index.html` 파일을 열거나, 로컬 웹 서버를 실행하세요.

**간단한 방법 (Python 있는 경우):**
```bash
cd log-tree-app
python -m http.server 8000
```

그 다음 브라우저에서: `http://localhost:8000`

### 2️⃣ 데모 모드로 시작

1. 설정 모달이 나타나면
2. **"데모 모드 사용"** 버튼 클릭
3. 끝! 바로 시작

### 3️⃣ 문제 풀기

1. 화면 왼쪽에 로그 함수 문제가 표시됩니다
   - 예: `log₂(8) = ?`

2. 답을 입력하고 제출
   - 정답: `3` (왜냐하면 2³ = 8)

3. 우측 하단 스마트폰 화면의 나무가 자라는 것을 확인!

## 📱 데모 문제 예시

| 문제 | 답 | 설명 |
|------|-----|------|
| log₂(8) = ? | 3 | 2³ = 8 |
| log₁₀(100) = ? | 2 | 10² = 100 |
| log₂(16) = ? | 4 | 2⁴ = 16 |
| log₅(25) = ? | 2 | 5² = 25 |
| log₃(27) = ? | 3 | 3³ = 27 |

## 🎯 이해하기

### 로그 함수란?

```
log₂(8) = 3  ←→  2³ = 8
```

"2를 몇 번 곱해야 8이 될까?" → 3번!

### 나무 성장 공식

```
나무 높이 = 50 × log₂(문제 수 + 1)
```

- 처음에는 빠르게 자라지만
- 점점 성장 속도가 느려집니다
- 이것이 바로 **로그 함수의 특성**!

## 🎮 팁

1. **Enter 키로 빠른 제출**: 답 입력 후 Enter 키를 누르세요
2. **진행 상황 자동 저장**: 브라우저를 닫아도 진행 상황이 유지됩니다
3. **초기화**: 콘솔에서 `resetApp()` 실행
4. **레벨 업**: 5문제당 레벨 1씩 상승
5. **나무 관찰**: 문제를 풀수록 가지와 잎이 많아집니다

## 🔧 문제 해결

### 화면이 이상해요
- 브라우저를 최신 버전으로 업데이트하세요
- Chrome, Firefox, Safari, Edge 권장

### 나무가 안 자라요
- F12 → Console에서 오류 확인
- 페이지 새로고침 (Ctrl+F5)

### 진행 상황이 사라졌어요
- 브라우저 시크릿 모드를 사용하면 저장 안 됨
- 쿠키/LocalStorage 삭제 시 초기화됨
