# Inverse Mirror 사용 가이드

## 개요

Inverse Mirror는 역함수 미분의 관계를 시각적으로 학습할 수 있는 교육용 웹 애플리케이션입니다.

## 주요 기능

### 1. 거울 효과 시각화
- 함수 f(x)와 역함수 f⁻¹(x)의 y=x 대칭 관계 표시
- 실시간 인터랙티브 그래프
- 확대/축소 및 팬 기능

### 2. 미분 관계 시각화
- 원함수의 접선과 기울기 표시
- 역함수의 접선과 기울기 표시
- 미분계수의 역수 관계 자동 계산

### 3. 모바일 시뮬레이터
- 우측 하단 가상 스마트폰 화면
- 핵심 개념 요약
- 수식 및 관계식 표시

### 4. Moodle 연동
- Moodle LMS에서 문제 자동 가져오기
- 학습 진행도 자동 제출
- 성적 동기화

## 사용 방법

### 기본 사용

#### 1. 함수 입력
```
함수 f(x): x^2
```

지원되는 함수:
- 다항식: `x^2`, `x^3`, `2*x + 1`
- 지수/로그: `exp(x)`, `log(x)`
- 삼각함수: `sin(x)`, `cos(x)`, `tan(x)`
- 제곱근: `sqrt(x)`

#### 2. 정의역 설정
```
정의역 최소: -3
정의역 최대: 3
```

**주의**: 역함수가 존재하려면 함수가 단조증가 또는 단조감소해야 합니다.

#### 3. 점 선택
슬라이더를 움직여 미분을 계산할 점을 선택합니다.

#### 4. 옵션 선택
- ☑ **역함수 표시**: 역함수 그래프 표시/숨김
- ☑ **미분 표시**: 접선 표시/숨김
- ☑ **거울선 (y=x)**: 대칭축 표시/숨김

### Moodle 문제 가져오기

1. **"Moodle에서 문제 가져오기"** 버튼 클릭
2. 백엔드가 Moodle에서 문제 정보 가져옴
3. 자동으로 함수, 정의역, 점이 설정됨
4. 문제 풀이 시작

### 그래프 상호작용

#### 확대/축소
- 마우스 휠: 스크롤하여 확대/축소
- 더블 클릭: 자동 맞춤

#### 이동
- 드래그: 그래프 이동

#### 정보 보기
- 그래프 위에 마우스 오버: 좌표 표시

## 수학 개념

### 역함수

함수 f(x)가 일대일 대응일 때, 역함수 f⁻¹(x)가 존재합니다.

```
f(a) = b  ⟺  f⁻¹(b) = a
```

**그래프 특징**: f(x)와 f⁻¹(x)는 y=x에 대해 대칭

### 역함수의 미분

점 (a, b)에서 f'(a) ≠ 0이면:

```
(f⁻¹)'(b) = 1 / f'(a)
```

**의미**:
- 역함수의 미분계수는 원함수 미분계수의 역수
- 접선의 기울기가 역수 관계

### 예제

**함수**: f(x) = x²  (정의역 [0, 3])
**점**: x = 2

1. **함수값**: f(2) = 4
2. **미분계수**: f'(2) = 2×2 = 4
3. **역함수**: f⁻¹(x) = √x
4. **역함수 미분**: (f⁻¹)'(4) = 1/4 = 0.25

**확인**:
```
d/dx(√x) at x=4 = 1/(2√4) = 1/4 ✓
```

## 학습 시나리오

### 시나리오 1: 기본 이해

1. 간단한 함수 `x^2` 입력 (정의역 [0, 3])
2. 거울선 표시 확인
3. 역함수가 y=x를 중심으로 대칭임을 관찰
4. 다양한 점에서 대칭 확인

### 시나리오 2: 미분 관계

1. 미분 표시 활성화
2. 점을 이동하면서 접선 변화 관찰
3. 원함수 접선 기울기 확인
4. 역함수 접선 기울기가 역수임을 확인
5. 모바일 화면에서 수치 확인

### 시나리오 3: 다양한 함수

다양한 함수로 실험:
- `exp(x)`: 지수함수와 로그함수
- `sin(x)`: 삼각함수 (제한된 정의역)
- `x^3`: 3차 함수

## 모바일 시뮬레이터

우측 하단 스마트폰 화면에 표시되는 정보:

### 표시 내용
1. **함수**: 현재 함수 표현식

3. **미분계수**: f'(x) 값
4. **역함수 미분계수**: (f⁻¹)'(y) 값

6. **핵심 개념**: 학습 포인트

### 활용 방법
- 그래프와 수치를 함께 확인
- 관계식 이해
- 개념 복습

## 문제 해결

### 역함수가 표시되지 않음

**원인**: 함수가 단조함수가 아님

**해결**:
- 정의역을 단조 구간으로 제한
- 예: sin(x)는 [-π/2, π/2]로 제한

### 그래프가 이상하게 표시됨

**원인**: 함수 표현식 오류

**해결**:
- 문법 확인 (예: `x^2` 올바름, `x²` 오류)
- 지원되는 함수인지 확인
- 괄호 사용 확인 (예: `sin(2*x)`)

### Moodle 문제를 가져올 수 없음

**원인**: 백엔드 연결 오류

**해결**:
1. 백엔드 서버 실행 확인
2. Moodle 설정 확인 (`.env` 파일)
3. 네트워크 연결 확인
