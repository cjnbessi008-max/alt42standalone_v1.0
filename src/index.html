🔄

여러 번의 시도 추적

여러 번 시도 후 정답을 맞춘 패턴을 분석하여 불안정성을 파악합니다.

📉

퇴행 패턴 감지

이전에 맞췄던 문제를 나중에 틀리는 경우 즉시 알림을 제공합니다.

⚡

시간 불일치 분석

같은 유형의 문제를 푸는데 걸리는 시간이 일관되지 않은 경우를 감지합니다.

😰

자신감 레벨 추적

정답을 맞췄지만 자신감이 낮은 경우를 파악하여 복습을 권장합니다.

📊

실시간 대시보드

학생별, 개념별 실시간 분석 결과를 시각화하여 제공합니다.

🚀 시작하기

1. 데이터베이스 설치

php src/database/install.php

2. 웹 서버 설정

Apache 또는 Nginx를 설정하여 /src 디렉토리를 DocumentRoot로 지정합니다.

3. 대시보드 접속

  • 교사용: /frontend/views/teacher-dashboard.html
  • 학생용: /frontend/views/student-dashboard.html

샘플 데이터

설치 시 자동으로 샘플 학생, 개념, 문제 데이터가 생성됩니다.

  • 학생 3명 (홍길동, 김영희, 이철수)
  • 개념 6개 (분수, 곱셈 구구단 등)
  • 문제 6개
  • 불안정성 패턴 샘플 응답 데이터

💡 핵심 기능

  • 실시간 안정성 분석: 학생 응답이 기록될 때마다 자동 분석
  • 다차원 지표: 6가지 이상의 지표를 종합하여 판단
  • 맞춤형 권장 사항: 학생별로 적합한 학습 방법 제안
  • 교사 알림: 주의가 필요한 학생 즉시 알림
  • RESTful API: 다른 시스템과 쉽게 연동 가능
