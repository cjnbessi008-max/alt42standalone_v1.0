# ALT42 PWA Icons

## Icon Generation

To generate icons for this PWA:

1. Open `generate-icons.html` in your browser
2. Click "모든 아이콘 생성" button
3. Download each icon size by clicking the download button

## Required Sizes

- 72x72
- 96x96
- 128x128
- 144x144
- 152x152
- 192x192
- 384x384
- 512x512

## Manual Icon Creation

If you prefer to create icons manually, use the following specifications:

- **Design**: Graph visualization with nodes and burst effects
- **Colors**: Gradient from #4A90E2 to #7B68EE
- **Format**: PNG with transparency
- **Maskable**: Icons should work as maskable icons (80% safe zone)

## Icon Design Elements

- Center node (gold/yellow #FFD700)
- 4 outer nodes (white)
- Connecting lines
- Burst effect particles
- Gradient background

Place generated icons in this directory with the naming convention:
`icon-[size]x[size].png`

Example: `icon-192x192.png`
