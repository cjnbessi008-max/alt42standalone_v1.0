# Chance Mood 빠른 시작 가이드 🚀

## 개요

**Chance Mood**는 Moodle에서 경우의 수/확률 문제를 감정 컬러로 요약하여 보여주는 블록 플러그인입니다.

## 5분 안에 시작하기

### 1단계: 설치 (관리자)

```bash
cd /moodle경로/blocks/
git clone <저장소URL> chancemood
```

또는 ZIP 파일을 다운로드하여 압축 해제

### 2단계: Moodle 업그레이드

1. 관리자로 로그인
2. **사이트 관리** → **알림** 클릭
3. **Moodle 데이터베이스 지금 업그레이드** 클릭

### 3단계: 설정 (선택사항)

**사이트 관리** → **플러그인** → **블록** → **Chance Mood**

- ✅ Chance Mood 활성화: 예
- 📍 화면 위치: 우측 하단 (기본값)
- 🔄 자동 새로고침: 5분
- 🎯 샘플 데이터 사용: 예 (테스트용)

### 4단계: 과목에 추가 (교사)

1. 과목으로 이동
2. **편집 모드 켜기** 클릭
3. **블록 추가** → **Chance Mood** 선택
4. 우측 하단에 가상 스마트폰 화면 나타남! 🎉

## 작동 원리

### 감정 컬러 시스템

| 감정 | 색상 | 의미 |
|-----|------|------|
| 😊 기쁨 | 초록 | 쉬운 문제 (성공률 80% 이상) |
| 😎 자신감 | 파랑 | 적당한 문제 (60-80%) |
| 🤔 도전 | 주황 | 어려운 문제 (40-60%) |
| 😰 고군분투 | 진한 주황 | 매우 어려움 (20-40%) |
| 😫 좌절 | 빨강 | 극도로 어려움 (20% 미만) |

### 문제 자동 감지

다음 키워드를 포함한 퀴즈 문제를 자동으로 찾습니다:
- **한국어**: 확률, 경우의 수, 조합, 순열
- **English**: probability, chance, combination, permutation

## 주요 기능

### 🎨 감정 기반 색상 분석
- 문제 난이도를 5가지 감정으로 분류
- 직관적인 색상 심리학 적용
- 학습 현황을 한눈에 파악

### 📱 가상 스마트폰 UI
- 우측 하단에 고정 표시
- 드래그로 위치 이동 가능
- 토글 버튼으로 숨기기/보이기

### 📊 실시간 분석
- 자동으로 문제 데이터 수집
- 학생 성공률 계산
- 5분마다 자동 업데이트

### 🌏 다국어 지원
- 한국어 (ko)
- English (en)

## 사용 방법

### 학생용

1. **보기**: 과목에 접속하면 자동으로 표시됩니다
2. **이동**: 스마트폰 화면을 클릭하여 드래그
3. **숨기기**: 📊 버튼 클릭
4. **다시 보기**: ✕ 버튼 클릭

### 교사용

1. **블록 추가**: 편집 모드에서 블록 추가
2. **데이터 확인**: 학생들의 전체 학습 현황 파악
3. **문제 조정**: 어려운 영역 식별 후 교육 방향 수정
4. **피드백 제공**: 감정 분포를 기반으로 개별 지도

## 문제 해결

### 스마트폰 화면이 안 보여요
- ✅ 브라우저 캐시 삭제 후 새로고침
- ✅ JavaScript가 활성화되어 있는지 확인
- ✅ F12 눌러서 콘솔 오류 확인

### "문제 없음" 메시지가 나와요
- ✅ 설정에서 "샘플 데이터 사용" 활성화 (테스트용)
- ✅ 퀴즈 문제에 키워드 포함 여부 확인
- ✅ 과목에 퀴즈가 있는지 확인

### 위치를 변경하고 싶어요
- ✅ 관리자: **사이트 관리** → **Chance Mood** → **화면 위치** 변경
- ✅ 사용자: 스마트폰 화면을 드래그하여 이동

## 실제 사용 예시

### 예시 1: 중학교 1학년 확률 단원

**상황**: 20명의 학생이 확률 단원 퀴즈 완료

**Chance Mood 결과**:
- 😊 기쁨 (30%): 기본 동전/주사위 문제
- 😎 자신감 (40%): 카드 뽑기 문제
- 🤔 도전 (20%): 복잡한 경우의 수
- 😰 고군분투 (10%): 조건부 확률

**교사 액션**: 조건부 확률 부분 추가 설명 진행

### 예시 2: 고등학교 순열/조합

**상황**: 어려운 조합 문제 출제

**Chance Mood 결과**:
- 😫 좌절 (60%): 매우 낮은 성공률

**교사 액션**: 기초 개념 다시 복습 + 단계별 문제 재구성
