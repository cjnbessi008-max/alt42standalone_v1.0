# Example Usage: Reasoning Path Grading System

## 사용 시나리오 예시

### 시나리오 1: 대수학 - 방정식 풀이

#### 교사 설정

```
문제 제목: 일차방정식 풀이
문제 내용: 다음 방정식을 풀이하고, 각 단계를 설명하시오: 3(x - 2) + 5 = 14

최소 단계 수: 4
AI 채점 활성화: 예
여러 풀이 방법 허용: 예

채점 비중:
- 완성도: 40%
- 논리성: 30%
- 방법: 20%
- 명확성: 10%

예상 풀이 단계:
[
  {
    "description": "괄호를 풉니다",
    "content": "3x - 6 + 5 = 14"
  },
  {
    "description": "좌변을 정리합니다",
    "content": "3x - 1 = 14"
  },
  {
    "description": "양변에 1을 더합니다",
    "content": "3x = 15"
  },
  {
    "description": "양변을 3으로 나눕니다",
    "content": "x = 5"
  }
]
```

#### 우수 학생 답안 (95점)

**단계 1 - 계산**
- 설명: "분배법칙을 적용하여 괄호를 풉니다"
- 내용: `3(x - 2) + 5 = 14` → `3x - 6 + 5 = 14`

**단계 2 - 계산**
- 설명: "좌변의 상수항을 정리합니다"
- 내용: `3x - 6 + 5 = 14` → `3x - 1 = 14`

**단계 3 - 계산**
- 설명: "양변에 1을 더해 3x를 분리합니다"
- 내용: `3x - 1 + 1 = 14 + 1` → `3x = 15`

**단계 4 - 계산**
- 설명: "양변을 3으로 나누어 x의 값을 구합니다"
- 내용: `3x ÷ 3 = 15 ÷ 3` → `x = 5`

**단계 5 - 결론**
- 설명: "검산으로 답을 확인합니다"
- 내용: `3(5 - 2) + 5 = 3(3) + 5 = 9 + 5 = 14 ✓`

**AI 피드백:**
```
종합 점수: 95/100

완성도: 95/100
모든 핵심 단계가 포함되어 있으며, 검산까지 수행한 점이 우수합니다.

논리적 일관성: 95/100
각 단계가 명확하게 연결되어 있고, 등식의 성질을 올바르게 적용했습니다.

방법의 적절성: 95/100
가장 효율적이고 표준적인 풀이 방법을 사용했습니다.

명확성: 95/100
각 단계의 설명이 매우 명확하고, 수학적 표기가 정확합니다.

✅ 강점:
- 분배법칙을 정확하게 적용
- 각 단계에 대한 명확한 설명 제공
- 검산을 통한 답 확인
- 올바른 등식 변형 과정

💡 개선점:
- 이미 매우 우수한 답안입니다!
```

#### 보통 학생 답안 (70점)

**단계 1**
- 내용: `3x - 6 + 5 = 14`

**단계 2**
- 내용: `3x - 1 = 14`

**단계 3**
- 내용: `3x = 15`

**단계 4**
- 내용: `x = 5`

**AI 피드백:**
```
종합 점수: 70/100

완성도: 80/100
모든 핵심 단계가 있지만, 각 단계에 대한 설명이 부족합니다.

논리적 일관성: 85/100
단계 간 연결은 논리적이나, 명시적인 설명이 없어 추론 과정이 불명확합니다.

방법의 적절성: 75/100
올바른 방법이지만, 왜 그 방법을 사용했는지 설명이 없습니다.

명확성: 40/100
계산 과정만 있고 설명이 거의 없어 이해하기 어렵습니다.

✅ 강점:
- 올바른 풀이 순서
- 계산이 정확함

💡 개선점:
- 각 단계에서 무엇을 했는지 설명 추가 필요
- 왜 그 연산을 수행했는지 이유를 설명하세요
- 등식의 성질(양변에 같은 수를 더하기 등)을 명시하세요
```

### 시나리오 2: 기하학 - 도형의 넓이

#### 교사 설정

```
문제 제목: 복합 도형의 넓이
문제 내용:
직사각형(가로 8cm, 세로 6cm) 안에 반지름 2cm인 원이 내접해 있습니다.
색칠된 부분(직사각형에서 원을 뺀 영역)의 넓이를 구하시오.

최소 단계 수: 3
```

#### 우수 답안

**단계 1 - 설명**
- 설명: "문제를 이해하고 필요한 공식을 확인합니다"
- 내용:
  - 직사각형 넓이 = 가로 × 세로
  - 원의 넓이 = π × r²
  - 색칠 부분 = 직사각형 넓이 - 원의 넓이

**단계 2 - 계산**
- 설명: "직사각형의 넓이를 구합니다"
- 내용: `직사각형 넓이 = 8 × 6 = 48 cm²`

**단계 3 - 계산**
- 설명: "원의 넓이를 구합니다"
- 내용: `원의 넓이 = π × 2² = 4π ≈ 12.56 cm²`

**단계 4 - 계산**
- 설명: "색칠된 부분의 넓이를 구합니다"
- 내용: `색칠 부분 = 48 - 12.56 = 35.44 cm²`

**단계 5 - 결론**
- 설명: "답을 정리합니다"
- 내용: `답: 35.44 cm² (또는 48 - 4π cm²)`

### 시나리오 3: 확률과 통계

#### 문제

```
주사위를 두 번 던질 때, 나온 눈의 합이 7이 될 확률을 구하시오.
```

#### 우수 답안

**단계 1 - 설명**
- 설명: "전체 경우의 수를 파악합니다"
- 내용: "주사위 2개를 던지면 6 × 6 = 36가지 경우가 있습니다"

**단계 2 - 계산**
- 설명: "합이 7이 되는 경우를 나열합니다"
- 내용:
  ```
  (1,6), (2,5), (3,4), (4,3), (5,2), (6,1)
  총 6가지
  ```

**단계 3 - 계산**
- 설명: "확률을 계산합니다"
- 내용:
  ```
  P(합=7) = 유리한 경우의 수 / 전체 경우의 수
          = 6/36
          = 1/6
  ```

**단계 4 - 결론**
- 내용: "답: 1/6 (약 16.67%)"

## 다양한 학생 반응 패턴

### 패턴 1: 완벽한 답안
- 모든 단계 완비
- 명확한 설명
- 올바른 계산
- → **90-100점**

### 패턴 2: 논리적이지만 설명 부족
- 단계는 올바름
- 설명이 간략
- → **70-85점**

### 패턴 3: 단계 누락
- 중요한 중간 단계 생략
- 논리적 비약
- → **50-70점**

### 패턴 4: 잘못된 접근
- 부적절한 방법
- 논리적 오류
- → **30-50점**

### 패턴 5: 불완전한 답안
- 최소 단계 미달
- 명확한 결론 없음
- → **0-30점**

## AI 피드백 품질 예시

### 우수한 피드백

```
✅ 강점:
- 분배법칙을 정확하게 적용했습니다
- 각 단계에서 등식의 성질을 명시적으로 설명했습니다
- 검산을 통해 답의 정확성을 확인했습니다
- 수학적 표기법이 정확하고 일관됩니다

💡 개선점:
- 첫 번째 단계에서 "양변에 같은 수를 더한다"는 등식의 성질을
  명시하면 더 좋습니다
- LaTeX 수식 표기를 사용하면 더 전문적으로 보입니다
```

### 건설적인 피드백

```
⚠️ 주요 문제점:
- 단계 2와 3 사이에 논리적 연결이 부족합니다
- 왜 양변을 2로 나누었는지 설명이 필요합니다
- 음수 처리에서 부호 오류가 있습니다

💡 개선 방법:
1. 각 단계에서 "왜"를 설명하세요
2. 등식의 성질을 명시적으로 언급하세요
3. 부호 변화가 있을 때는 특별히 주의하세요
```

## 교사 활용 팁

### 1. 문제 설계
- **명확한 문제 제시**: 학생이 무엇을 해야 하는지 명확히
- **적절한 최소 단계 설정**: 너무 많거나 적지 않게
- **모범 답안 제공**: AI 채점의 기준점

### 2. 가중치 조정
- **개념 이해 중심**: 완성도 50%, 논리성 30%
- **방법론 중심**: 방법 40%, 완성도 30%
- **의사소통 중심**: 명확성 30%, 논리성 30%

### 3. 결과 활용
- **학습 데이터 분석**: 학생들이 자주 놓치는 단계 파악
- **맞춤형 피드백**: AI 피드백을 보완하는 교사 코멘트
- **교육 개선**: 공통적인 오류 패턴으로 수업 개선

## 학생 활용 팁

### 1. 효과적인 답안 작성
- ✅ 각 단계를 명확히 구분
- ✅ "왜"를 항상 설명
- ✅ 수학적 표기법 정확히 사용
- ✅ 중간 과정 생략하지 않기

### 2. 피드백 활용
- 📖 AI 피드백을 꼼꼼히 읽기
- 🔄 개선점을 다음 문제에 적용
- ❓ 이해 안 되는 부분은 교사에게 질문

### 3. 학습 전략
- 💭 답을 아는 것보다 과정을 이해하는 것이 중요
- 📝 다른 학생의 우수 답안 참고 (익명)
- 🎯 약한 기준에 집중 (예: 명확성이 낮으면 설명 연습)
