💬 피드백

벡터를 드래그하여 평행이동시켜보세요!

📱 우측 하단의 가상 스마트폰을 확인하세요

스마트폰 화면에서 벡터를 드래그하여 평행이동을 수행하고, 이동 경로가 Trail로 표시됩니다.

🎯 학습 목표

  • 벡터의 평행이동 개념 이해
  • 이동 거리와 방향 계산
  • Trail을 통한 경로 시각화

📝 사용 방법

  1. 스마트폰 화면의 벡터를 클릭하여 드래그
  2. 원하는 위치로 벡터 이동
  3. 이동 경로가 Trail로 표시됨
  4. 정보 패널에서 이동 데이터 확인
  5. 제출 버튼으로 답안 제출

🔧 추가 기능

  • Trail 색상/두께: 원하는 스타일로 변경
  • 애니메이션: Trail 재생으로 복습
  • 초기화: 처음부터 다시 시작
  • 저장: 진행 상황 자동 저장
