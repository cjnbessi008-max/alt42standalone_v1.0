# Mistake Category Frontend

React frontend for the mistake category selection system.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

The app will be available at http://localhost:3000

## Features

- **문제 풀이**: 다양한 수학 문제 풀이
- **실수 카테고리 선택**: 틀린 문제에 대해 실수 유형 선택
- **AI 추천**: 답변 분석 기반 실수 유형 추천
- **학습 현황**: 개인별 통계 및 실수 유형 분석

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Axios
