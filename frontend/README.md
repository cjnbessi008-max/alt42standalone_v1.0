# MathFlow Frontend

Next.js 14 기반 MathFlow 프론트엔드 애플리케이션

## 개발 서버 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인

## 기술 스택

- Next.js 14 (App Router)
- React 18
- TypeScript
- TailwindCSS
- Framer Motion
- KaTeX
- Zustand
- React Query

## 프로젝트 구조

```
frontend/
├── app/              # Next.js App Router
├── components/       # React 컴포넌트
├── lib/             # 유틸리티
└── public/          # 정적 파일
```
