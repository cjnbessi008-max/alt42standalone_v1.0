# Edge Melody 사용 가이드

## 시작하기

Edge Melody는 Moodle LMS의 문제를 3D 시각화로 표현하는 혁신적인 학습 도구입니다.

---

## 주요 기능

### 1. 3D Edge Melody 시각화

문제의 특성에 따라 정육면체의 모서리가 음악적 패턴으로 점등됩니다.

#### 시각화 원리

- **모서리 활성화**: 답변 선택지 개수만큼 모서리가 점등
- **색상**: 문제 카테고리에 따라 색상 스킴 변경
- **애니메이션 속도**: 문제 배점에 비례
- **난이도 표시**: 점등 패턴의 복잡도로 난이도 표현

#### 인터랙션

- **회전**: 마우스 드래그로 큐브 회전
- **줌**: 마우스 휠로 확대/축소
- **자동 회전**: 비활성화 (OrbitControls 설정)

---

### 2. 문제 선택 패널

왼쪽 패널에서 문제를 선택할 수 있습니다.

#### 기능

- **검색**: 문제 제목이나 내용으로 검색
- **필터링**: 카테고리별 필터 (향후 추가 예정)
- **정렬**: 최신순, 배점순 (향후 추가 예정)

#### 문제 정보

각 문제 카드에는 다음 정보가 표시됩니다:
- 문제 제목
- 카테고리
- 배점
- 문제 유형
- 작성 날짜

---

### 3. 가상 스마트폰 화면

우측 하단에 실제 모바일 기기처럼 표시됩니다.

#### 특징

- **노치**: 최신 스마트폰 디자인 반영
- **홈 인디케이터**: iOS 스타일
- **측면 버튼**: 전원, 볼륨 버튼
- **반응형**: 화면 크기에 따라 적응

---

## 사용 시나리오

### 교사용

#### 1. 문제 미리보기

```
1. Edge Melody 웹앱 실행
2. 왼쪽 패널에서 문제 선택
3. 3D 시각화로 문제 특성 파악
4. 학생들에게 공유할 문제 선정
```

#### 2. 문제 난이도 분석

- **Easy**: 천천히 점등, 적은 모서리, 단순한 패턴
- **Medium**: 중간 속도, 중간 복잡도
- **Hard**: 빠른 점등, 많은 모서리, 복잡한 패턴

---

### 학생용

#### 1. 학습 준비

```
1. 모바일 기기나 PC에서 접속
2. 오늘의 문제 확인
3. 3D 시각화로 문제 탐색
```

#### 2. 문제 풀이

```
1. 문제 내용 읽기
2. 선택지 확인
3. 정답 선택 (향후 기능)
4. 즉시 피드백 받기 (향후 기능)
```

## 고급 기능

### API 직접 사용

JavaScript로 API를 직접 호출할 수 있습니다:

```javascript
import { getQuestionEdgeMelody } from './services/api'

// 문제 ID 1번의 Edge Melody 데이터 가져오기
const data = await getQuestionEdgeMelody(1)

console.log(data.visualization.edges)
console.log(data.visualization.animation)
```

### 커스터마이징

#### 색상 스킴 변경

`backend/api/questions.php`의 `getColorScheme()` 메서드 수정:

```php
private function getColorScheme($categoryId) {
    $schemes = [
        'math' => ['#YOUR_COLOR_1', '#YOUR_COLOR_2', '#YOUR_COLOR_3'],
        // ...
    ];
}
```

#### 애니메이션 속도 조정

`backend/api/questions.php`의 `calculateAnimationSpeed()` 메서드 수정:

```php
private function calculateAnimationSpeed($points) {
    return max(0.5, min(2.0, YOUR_FORMULA));
}
```

## 모바일 사용

### 터치 제스처

- **한 손가락 드래그**: 3D 큐브 회전
- **두 손가락 핀치**: 확대/축소
- **스와이프**: 문제 전환 (향후 추가)

### 반응형 레이아웃

- **태블릿**: 패널과 스마트폰 화면이 세로 배치
- **모바일**: 전체 화면으로 확장

## 문제 해결

### 3D가 표시되지 않음

1. WebGL 지원 확인:
   - 브라우저 주소창에 `about:gpu` 입력
   - WebGL이 활성화되어 있는지 확인

2. 그래픽 드라이버 업데이트

### 문제가 로드되지 않음

1. API 서버 상태 확인:
   ```bash
   curl http://localhost:8080/api/questions
   ```

2. 브라우저 콘솔에서 에러 메시지 확인

### 느린 성능

1. 브라우저 하드웨어 가속 활성화
2. 다른 탭 닫기
3. 그래픽 품질 설정 낮추기 (향후 추가)

## 팁 & 트릭

### 1. 최적의 시각화를 위한 문제 구조

- **선택지**: 3-5개가 가장 시각적으로 균형잡힘
- **배점**: 1-5점 범위가 애니메이션에 적합
- **카테고리**: 명확한 카테고리 분류로 색상 구분

### 2. 효율적인 문제 탐색

- 검색 기능을 활용하여 특정 주제 문제 찾기
- 배점 순으로 정렬하여 중요도 파악

### 3. 3D 시각화 활용

- 문제의 복잡도를 직관적으로 파악
- 유사한 문제들의 패턴 비교
- 학습 진도에 맞는 난이도 선택
