# Assets Directory

이 디렉토리는 PWA 아이콘 및 스크린샷을 위한 공간입니다.

## 필요한 아이콘 크기

다음 크기의 아이콘을 준비해주세요:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png (필수)
- icon-384x384.png
- icon-512x512.png (필수)

## 아이콘 생성 방법

### 1. 온라인 도구 사용
- https://www.pwabuilder.com/
- https://realfavicongenerator.net/

### 2. 직접 생성
원본 이미지(1024x1024 PNG 권장)를 준비하고 다양한 크기로 리사이즈합니다.

아이콘 디자인 가이드:
- Root Glow 로고 또는 수학 기호 사용
- 명확하고 단순한 디자인
- 밝은 배경(#667eea) 추천
- 중앙에 흰색 또는 밝은 색상의 심볼

## 스크린샷

앱 사용 화면을 캡처하여 다음 이미지를 생성하세요:

- screenshot-desktop.png (1280x720)
- screenshot-mobile.png (720x1280)

## 임시 대체

아이콘이 없는 경우, 브라우저 기본 아이콘이 사용됩니다.
PWA 기능은 정상 작동하지만 사용자 경험이 저하됩니다.
