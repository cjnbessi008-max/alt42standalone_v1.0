📝 아이콘 생성 방법

  1. 위의 SVG를 캡처하거나 저장합니다
  2. 온라인 이미지 변환 도구 사용 (예: ezgif.com)
  3. 다음 크기로 PNG 파일 생성:
    • icon-72x72.png
    • icon-96x96.png
    • icon-128x128.png
    • icon-144x144.png
    • icon-152x152.png
    • icon-192x192.png
    • icon-384x384.png
    • icon-512x512.png
  4. 생성된 PNG 파일들을 assets/icons/ 폴더에 저장

🚀 빠른 생성 (ImageMagick 사용)

ImageMagick이 설치되어 있다면 다음 명령어를 사용하세요:

# SVG를 PNG로 변환
for size in 72 96 128 144 152 192 384 512; do
  convert icon.svg -resize ${size}x${size} icon-${size}x${size}.png
done
