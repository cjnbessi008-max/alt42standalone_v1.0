# 수학 문제 풀이 단계 추적 및 건너뛰기 탐지 시스템

## 개요
Moodle 3.7 LMS와 연동 가능한 독립형 웹앱으로, 학생들이 수학 문제를 풀 때 논리적 중간단계를 건너뛰었는지 탐지하는 시스템입니다.

## 기술 스택
- **Backend**: PHP 7.1.9
- **Database**: MySQL 5.7
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla + Chart.js)
- **Integration**: Moodle 3.7 REST API

## 핵심 기능

### 1. 단계별 문제 풀이 추적
- 학생이 각 문제의 모든 중간 단계를 입력
- 각 단계별 소요 시간, 시도 횟수, 정확성 기록
- 힌트 사용 여부 및 빈도 추적

### 2. 건너뛰기 탐지 알고리즘
다음 4가지 지표로 건너뛰기를 탐지합니다:

#### a) 시간 이상 탐지
- **초고속 완료**: 평균 대비 50% 이하 시간 소요 (의심)
- **비정상적 균일성**: 모든 단계를 동일한 시간에 완료 (복사 의심)

#### b) 논리적 불일치 탐지
- 이전 단계의 출력과 다음 단계의 입력이 일치하지 않음
- 예: 통분 단계에서 4/6를 입력했는데, 다음 덧셈 단계에서 2/3 + 1/2를 계산

#### c) 순서 위반 탐지
- 필수 단계를 건너뛰고 최종 답안으로 점프
- 정의된 단계 순서를 따르지 않음

#### d) 힌트 의존도 분석
- 힌트 없이 막히다가 힌트 후 즉시 정답 (이해 없는 복사 의심)
- 모든 단계에서 힌트를 먼저 보는 패턴

### 3. 문제 유형별 단계 정의
시스템은 다음 수학 문제 유형을 지원합니다:

- **분수 덧셈/뺄셈**: 통분 → 분자 연산 → 약분
- **방정식 풀이**: 정리 → 이항 → 계산 → 검산
- **도형 넓이**: 공식 선택 → 값 대입 → 계산 → 단위 확인
- **확장 가능**: 새로운 문제 유형 추가 가능

### 4. 교사 대시보드
- 학생별 건너뛰기 빈도 및 패턴
- 문제 유형별 취약점 분석
- 클래스 전체 통계
- 개별 학생 상세 풀이 과정 리플레이

### 5. Moodle 연동
- Moodle 사용자 인증 연동
- 성적 자동 동기화 (Grade Book)
- 학습 활동 로그 전송

## 데이터베이스 스키마

### 주요 테이블
1. **problems**: 문제 정의
2. **problem_steps**: 각 문제의 단계 정의
3. **students**: 학생 정보 (Moodle 연동)
4. **student_solutions**: 학생 풀이 세션
5. **step_submissions**: 각 단계별 제출 기록
6. **skip_detections**: 건너뛰기 탐지 결과

## 건너뛰기 탐지 점수 산출

각 학생의 풀이에 대해 0-100점의 **신뢰도 점수**를 계산합니다:
- **100점**: 완전히 정상적인 풀이 과정
- **70-99점**: 약간의 의심스러운 패턴
- **40-69점**: 중간 수준의 건너뛰기 의심
- **0-39점**: 높은 확률의 건너뛰기/부정행위

### 점수 계산 공식
```
신뢰도 점수 = 100 - (시간이상 페널티 + 논리불일치 페널티 + 순서위반 페널티 + 힌트의존 페널티)
```
