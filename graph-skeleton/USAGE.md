# Graph Skeleton Visualizer - 사용 가이드

## 빠른 시작

### 1. 개발 서버 실행

```bash
cd graph-skeleton
npm install  # 이미 설치되었다면 생략 가능
npm run dev
```

브라우저에서 http://localhost:3000 접속

### 2. 프로덕션 빌드 및 배포

```bash
npm run build
npm run preview  # 빌드된 파일 미리보기
```

빌드된 파일은 `dist/` 폴더에 생성됩니다.

## 주요 기능

### 📊 지원하는 함수 형식

#### 기본 연산자
- `+` : 덧셈
- `-` : 뺄셈
- `*` : 곱셈
- `/` : 나눗셈
- `^` : 거듭제곱

#### 수학 함수
- `sin(x)`, `cos(x)`, `tan(x)` : 삼각함수
- `asin(x)`, `acos(x)`, `atan(x)` : 역삼각함수
- `sqrt(x)` : 제곱근
- `exp(x)` : 지수함수 (e^x)
- `ln(x)`, `log(x)` : 자연로그, 상용로그
- `abs(x)` : 절댓값

#### 상수
- `e` : 자연상수 (2.71828...)
- `pi` : 원주율 (3.14159...)

### 📝 함수 입력 예제

#### 다항함수
```
x^2 - 4*x + 3          # 이차함수
x^3 - 6*x^2 + 9*x      # 삼차함수
x^4 - 4*x^3 + 4*x^2    # 사차함수
```

#### 삼각함수
```
sin(x)
cos(x) + sin(x)
2*sin(x) * cos(x)
```

#### 지수/로그 함수
```
e^x
e^(-x)
e^(-x^2/2)             # 정규분포 모양
ln(x)
```

#### 복합 함수
```
x^2 * sin(x)
e^(-x) * cos(2*x)
sqrt(x) + ln(x)
```

### 🎯 분석 결과 읽기

#### 1. 증가/감소 구간
- **증가 구간 (↗)**: 함수값이 커지는 구간 (f'(x) > 0)
- **감소 구간 (↘)**: 함수값이 작아지는 구간 (f'(x) < 0)

#### 2. 극값 (Critical Points)
- **극대 (Maximum)**: 주변보다 높은 점 (빨간색 원)
  - f'(x) = 0 이고 f''(x) < 0
- **극소 (Minimum)**: 주변보다 낮은 점 (초록색 원)
  - f'(x) = 0 이고 f''(x) > 0

#### 3. 변곡점 (Inflection Points)
- 그래프의 오목/볼록이 바뀌는 점 (노란색 삼각형)
- f''(x) = 0인 점

## 활용 사례

### 교육용 시나리오

#### 시나리오 1: 이차함수 극값 학습
```
함수: x^2 - 4*x + 3
범위: x = [-2, 6]

학습 포인트:
- 극소값 위치 확인: (2, -1)
- 대칭축 이해: x = 2
- 증가/감소 구간 파악
```

#### 시나리오 2: 삼차함수 변곡점 이해
```
함수: x^3 - 6*x^2 + 9*x + 1
범위: x = [-1, 5]

학습 포인트:
- 극대와 극소 동시 존재
- 변곡점에서 오목/볼록 변화
- S자 형태 관찰
```

#### 시나리오 3: 삼각함수 주기성
```
함수: sin(x) + cos(x)
범위: x = [-10, 10]

학습 포인트:
- 주기적 극값 반복
- 합성 삼각함수의 진폭
```

## 문제 해결

### 함수 파싱 오류
```
오류: "Failed to parse expression"

해결:
1. 곱셈 기호(*) 명시: x^2 (X) → x^2 또는 x*x (O)
2. 괄호 확인: (x+1)(x-1) (X) → (x+1)*(x-1) (O)
3. 함수 이름 확인: sine(x) (X) → sin(x) (O)
```

### 극값을 찾지 못함
```
원인:
- 정의역이 너무 좁음
- 함수가 단조증가/단조감소

해결:
- 정의역 범위를 넓혀보세요
- 다른 함수로 시도
```

### 그래프가 표시되지 않음
```
원인:
- 함수값이 너무 큼/작음 (발산)
- 정의되지 않은 영역 (예: sqrt(-1))

해결:
- 정의역 조정
- 함수 확인
```
