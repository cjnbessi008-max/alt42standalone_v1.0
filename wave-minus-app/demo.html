📱 1. 독립 실행 모드

별도의 설정 없이 바로 실행할 수 있는 모드입니다. 랜덤 문제가 자동 생성됩니다.

독립 모드로 실행
http://localhost/wave-minus-app/index.html

🔗 2. Moodle 연동 모드

URL 파라미터를 통해 Moodle에서 전달받은 문제를 표시합니다.

예제 1: 기본 문제 예제 2: 짝수 집합 예제 3: 홀수 집합

URL 파라미터 형식:

index.html?problemId=100&userId=50&setA=[1,2,3]&setB=[2,3,4]

파라미터 설명:

  • problemId: Moodle 문제 ID (정수)
  • userId: 학생 사용자 ID (정수, 선택사항)
  • setA: 집합 A의 원소 (JSON 배열, 선택사항)
  • setB: 집합 B의 원소 (JSON 배열, 선택사항)

🎨 3. 주요 기능

Wave 애니메이션 차집합에서 제거되는 원소들이 파도처럼 순차적으로 밀려나가는 효과
스마트폰 UI 우측 하단에 가상 스마트폰 화면으로 표시되는 반응형 UI
실시간 시각화 집합 A, B 및 차집합 결과를 색상과 애니메이션으로 표현
인터랙티브 제어 애니메이션 실행, 초기화, 새 문제 생성 등 다양한 컨트롤

🔧 4. API 테스트

Moodle 연동 API를 테스트합니다. PHP 서버 필요

문제 조회 API:

GET /php/get_problem.php?problemId=100&userId=50

답안 제출 API:

POST /php/submit_answer.php Body: {"problemId": 100, "userId": 50, "answer": [1,2,3]}
