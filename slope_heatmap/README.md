# Slope Heatmap - 기울기 히트맵

LMS(Moodle)와 연동하여 학생들의 기기 기울기 패턴을 추적하고 히트맵으로 시각화하는 교육용 웹 애플리케이션입니다.

## 📱 주요 기능

### 1. 가상 스마트폰 인터페이스
- **우측 하단 고정 위치**: 화면 우측 하단에 가상 스마트폰 표시
- **실시간 센서 시뮬레이션**: Alpha(Z축), Beta(X축), Gamma(Y축) 3축 기울기 센서
- **시각적 피드백**: 기울기 변화를 실시간으로 시각화

### 2. Slope Heatmap (기울기 열지도)
- **실시간 데이터 수집**: 0.1초마다 기울기 데이터 수집
- **히트맵 시각화**: 기울기 변화 패턴을 색상 그라데이션으로 표시
- **집계 및 분석**: 데이터 집계 및 통계 분석 제공

### 3. Moodle LMS 연동
- **활동 모듈**: Moodle 활동 모듈로 설치
- **성적 연동**: 자동 성적 계산 및 성적부 연동
- **세션 관리**: 학생별 세션 추적 및 이력 관리

## 🛠️ 기술 스택

### Backend
- **PHP 7.1.9+**: Moodle 플러그인 개발
- **MySQL 5.7**: 데이터베이스
- **Moodle 3.7+**: LMS 플랫폼

### Frontend
- **HTML5/CSS3**: 반응형 웹 인터페이스
- **Vanilla JavaScript**: 프레임워크 없는 순수 자바스크립트
- **Canvas API**: 히트맵 시각화
- **Device Orientation API**: 실제 기기 센서 지원 (모바일)

## 📦 설치 방법

### 1. Moodle 플러그인 설치

```bash
# Moodle 설치 디렉토리로 이동
cd /path/to/moodle

# 플러그인 복사
cp -r slope_heatmap/moodle_plugin/mod_slopeheatmap mod/slopeheatmap

# 권한 설정
chmod -R 755 mod/slopeheatmap
```

### 2. 데이터베이스 설정

Moodle 관리자 페이지에서 자동으로 설치되지만, 수동 설치가 필요한 경우:

```bash
# MySQL 접속
mysql -u root -p moodle

# 스키마 실행
source slope_heatmap/database/schema.sql
```

### 3. Moodle에서 플러그인 활성화

1. Moodle 관리자 로그인
2. **사이트 관리 > 알림** 접속
3. 새 플러그인 설치 확인
4. **업그레이드** 버튼 클릭

### 4. 웹앱 배포

```bash
# 웹앱 파일 복사
cp -r slope_heatmap/webapp mod/slopeheatmap/webapp
```

## 🎮 사용 방법

### 교사 (코스 관리자)

1. **활동 추가**
   - 코스 페이지에서 "활동 추가" 선택
   - "기울기 히트맵" 선택
   - 활동 이름 및 설명 입력

2. **문제 설정**
   - 데이터베이스에서 직접 문제 추가 또는
   - 샘플 문제 사용 (기본 제공)

3. **학생 결과 확인**
   - 활동 페이지에서 "보고서" 탭
   - 각 학생의 세션 이력 및 히트맵 확인

### 학생

1. **문제 선택**
   - 활동 페이지 접속
   - 제공된 문제 목록에서 하나 선택

2. **활동 시작**
   - "시작" 버튼 클릭
   - 우측 하단 가상 스마트폰 조작
   - 슬라이더로 기울기 조정 또는
   - 실제 모바일 기기에서 기울이기

3. **완료 및 결과 확인**
   - "완료" 버튼 클릭 또는 목표 달성 시 자동 완료
   - 점수 및 히트맵 확인

## 📊 데이터베이스 구조

### 주요 테이블

1. **mdl_slopeheatmap**: 활동 인스턴스
2. **mdl_slopeheatmap_sessions**: 학생 세션
3. **mdl_slopeheatmap_sensor_data**: 원시 센서 데이터
4. **mdl_slopeheatmap_aggregated**: 집계된 히트맵 데이터
5. **mdl_slopeheatmap_problems**: 문제 정의

자세한 스키마는 `database/schema.sql` 참조

## 🎨 UI 컴포넌트

### 가상 스마트폰
- **위치**: 화면 우측 하단 고정
- **크기**: 280px × 580px
- **기능**:
  - 센서 값 실시간 표시
  - 슬라이더로 수동 조작
  - 시각적 기울기 인디케이터
  - 제어 버튼 (시작/완료/리셋)

### 히트맵
- **크기**: 400px × 300px
- **축**: Beta (앞뒤 기울기) × Gamma (좌우 기울기)
- **색상 범위**: 파랑(낮음) → 초록 → 노랑 → 빨강(높음)
- **그리드**: 5도 단위 구간

## 📱 모바일 지원

### Device Orientation API
- iOS 13+ 사용자는 권한 승인 필요
- Android 기기는 자동으로 작동
- 데스크톱에서는 슬라이더 사용

### 반응형 디자인
- 모바일: 전체 화면 스마트폰 인터페이스
- 태블릿/데스크톱: 우측 하단 고정 위치

## 🧪 테스트

### 샘플 문제

1. **기본 균형** (쉬움)
   - 10초 동안 수평 유지
   - Beta: -5° ~ 5°
   - Gamma: -5° ~ 5°

2. **앞으로 기울이기** (보통)
   - 15초 동안 45도 앞으로 기울이기
   - Beta: 40° ~ 50°
   - Gamma: -10° ~ 10°

3. **원 그리기** (어려움)
   - 30초 동안 자유롭게 움직이기
   - 목표 범위 없음

## 🐛 문제 해결

### 센서 데이터가 저장되지 않음
- 브라우저 콘솔에서 네트워크 오류 확인
- sesskey가 올바른지 확인
- API 엔드포인트 경로 확인

### 히트맵이 표시되지 않음
- Canvas API 지원 브라우저 사용
- JavaScript 콘솔에서 오류 확인

### 모바일에서 센서가 작동하지 않음
- HTTPS 사용 여부 확인 (필수)
- iOS에서 권한 승인 여부 확인
