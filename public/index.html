🧱 Component Lego

성분을 레고처럼 조립하는 인터랙티브 학습 시스템

📱 프로젝트 소개

Component Lego는 Moodle LMS와 연동하여 문제를 받아 성분을 레고 블록처럼 조립하는 인터랙티브 학습 인터페이스입니다. 우측 하단의 가상 스마트폰 화면에서 드래그 앤 드롭으로 화학 분자, 수학 분수, 방정식 등을 직관적으로 조립할 수 있습니다.

PHP 7.1.9 MySQL 5.7 Moodle 3.7 JavaScript ES6 HTML5 & CSS3

✨ 주요 기능

🔗 Moodle 연동

Moodle Web Services API를 통해 문제 정보를 자동으로 가져오고 동기화합니다.

🧩 성분 분해

화학식, 분수, 방정식 등을 자동으로 분석하여 레고 블록 형태의 컴포넌트로 변환합니다.

📱 가상 스마트폰

우측 하단에 모바일 스타일 UI로 표시되어 실제 앱처럼 사용할 수 있습니다.

🎯 드래그 앤 드롭

직관적인 드래그 앤 드롭 인터페이스로 컴포넌트를 조립하고 정답을 확인합니다.

💾 자동 저장

30초마다 자동으로 진행 상황을 저장하여 데이터 손실을 방지합니다.

📊 학습 분석

학생의 모든 인터랙션을 기록하여 학습 패턴을 분석합니다.

🚀 데모

샘플 문제로 Component Lego를 체험해보세요!

💡 사용 방법:
1. 위의 버튼을 클릭하여 문제를 로드합니다
2. 우측 하단 스마트폰 화면에서 컴포넌트를 확인합니다
3. 컴포넌트를 드래그하여 조립 영역에 배치합니다
4. Submit 버튼을 눌러 정답을 확인합니다

🛠️ 설치 및 설정

1. 데이터베이스 설정

mysql -u root -p < src/config/database.sql

2. 환경 변수 설정

export DB_HOST=localhost export DB_NAME=component_lego export DB_USER=component_lego_user export DB_PASS=your_password export MOODLE_URL=https://your-moodle-site.com export MOODLE_TOKEN=your_moodle_token

3. PHP 서버 실행

cd public php -S localhost:8000

4. 브라우저에서 접속

http://localhost:8000

📚 API 문서

주요 엔드포인트:

GET /api/v1/questions/{id} - 문제 정보 가져오기 GET /api/v1/questions/{id}/components - 컴포넌트 목록 POST /api/v1/assembly/validate - 조립 검증 POST /api/v1/assembly/save - 자동 저장 POST /api/v1/moodle/sync/{id} - Moodle 동기화 GET /api/v1/students/{id}/progress - 학습 진행 상황
