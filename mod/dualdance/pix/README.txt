Icon Directory for Dual Dance Module
=====================================

This directory should contain the module icon.

Required File:
--------------
icon.png (or icon.svg)
- Size: 24x24 pixels (will be scaled automatically by Moodle)
- Format: PNG or SVG
- Transparent background recommended
- Design: Should represent exponential/logarithmic functions or "dancing" curves

Icon Design Suggestions:
------------------------
1. Two intersecting curves (one exponential, one logarithmic)
2. Mathematical symbols: e^x and ln(x)
3. Graph with grid and crossing functions
4. Abstract wave/dance pattern

Creating the Icon:
------------------
You can create the icon using:
- Adobe Illustrator / Inkscape (for SVG)
- Photoshop / GIMP (for PNG)
- Online icon generators
- AI image generators with prompt: "icon for math education app showing exponential and logarithmic functions, simple, 24x24px, transparent background"

Placeholder:
------------
Until you create a custom icon, Moodle will use a default activity icon.
To add your icon, simply place it here as "icon.png" or "icon.svg".

------------------------------------
