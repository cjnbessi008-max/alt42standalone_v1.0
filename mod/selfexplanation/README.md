# Self-Explanation Prompts for Moodle

## 개요

이 Moodle 활동 모듈은 학생들에게 메타인지 학습을 촉진하는 자기설명(self-explanation) 프롬프트를 제공합니다. "나는 이걸 왜 아는가?" (Why do I know this?)와 같은 질문을 통해 학생들이 자신의 사고 과정을 명시적으로 설명하도록 유도하여 더 깊은 학습을 달성할 수 있습니다.

## 주요 기능

### 학생 기능
- **자기설명 프롬프트**: "나는 이걸 왜 아는가?", "나는 이걸 어떻게 아는가?" 등 다양한 메타인지 프롬프트
- **실시간 단어 수 카운터**: 한글과 영어 모두 지원
- **임시 저장**: 응답을 임시 저장하고 나중에 계속 작성 가능
- **피드백 보기**: 교사 피드백 및 평가 확인

### 교사 기능
- **사용자 정의 프롬프트**: 학습 목표에 맞는 프롬프트 생성
- **응답 모니터링**: 모든 학생 응답을 한 곳에서 확인
- **품질 분석**: 자동 품질 점수 계산 (단어 수, 메타인지 키워드 등)
- **피드백 제공**: 개별 학생에게 피드백 및 평가 제공
- **분석 대시보드**: 완료율, 평균 응답 길이, 품질 점수 등 통계

### 분석 기능
- 단어 수 자동 계산 (한글/영어)
- 메타인지 키워드 탐지 (왜, 어떻게, 때문에, why, because 등)
- 품질 점수 자동 계산
- 문장 수 및 평균 문장 길이 분석

## 시스템 요구사항

- **Moodle**: 3.7 이상
- **PHP**: 7.1.9 이상
- **MySQL**: 5.7 이상
- **브라우저**: 최신 Chrome, Firefox, Safari, Edge

## 설치 방법

### 1. 파일 복사
```bash
# Moodle의 mod 디렉토리에 selfexplanation 폴더 복사
cp -r mod/selfexplanation /path/to/moodle/mod/
```

### 2. 권한 설정
```bash
# 웹 서버가 읽을 수 있도록 권한 설정
chown -R www-data:www-data /path/to/moodle/mod/selfexplanation
chmod -R 755 /path/to/moodle/mod/selfexplanation
```

### 3. Moodle 관리자 페이지 접속
1. Moodle 관리자로 로그인
2. 사이트 관리 → 알림으로 이동
3. 데이터베이스 업그레이드 진행
4. 플러그인 설치 완료

### 4. 플러그인 활성화 확인
- 사이트 관리 → 플러그인 → 활동 모듈 → Self-Explanation Prompt 확인

## 사용 방법

### 교사용 가이드

#### 1. 활동 생성
1. 코스에서 "활동 추가" 클릭
2. "Self-Explanation Prompt" 선택
3. 다음 설정 구성:
   - **활동 이름**: 활동의 제목
   - **설명**: 활동에 대한 설명
   - **프롬프트 유형**:
     - "나는 이걸 왜 아는가?" (why_know)
     - "나는 이걸 어떻게 아는가?" (how_know)
     - "만약에...라면?" (what_if)
     - "당신의 추론을 설명하세요" (explain)
     - 사용자 정의 (custom)
   - **최소 단어 수**: 학생이 작성해야 할 최소 단어 수 (기본값: 20)
   - **재제출 허용**: 학생이 응답을 수정할 수 있도록 허용
   - **피드백 표시**: 교사 피드백을 학생에게 표시

#### 2. 학생 응답 확인
1. 활동 페이지에서 "모든 응답 보기" 클릭
2. 학생별 응답, 단어 수, 품질 점수 확인
3. 각 응답에 피드백 및 평가 제공 가능

#### 3. 분석 데이터 활용
- 품질 점수: 자동 계산된 응답 품질 (0-100점)
- 메타인지 키워드: 학생이 사용한 메타인지 관련 단어 수
- 완료율: 제출한 학생 수 / 전체 학생 수

### 학생용 가이드

#### 1. 활동 참여
1. 코스에서 Self-Explanation Prompt 활동 클릭
2. 프롬프트 질문 읽기 (예: "나는 이걸 왜 아는가?")
3. 텍스트 영역에 자신의 생각과 추론 작성

#### 2. 응답 작성 팁
- 구체적으로 작성: "왜 그렇게 생각하는지" 명확히 설명
- 예시 사용: 구체적인 예시로 설명 보완
- 연결 고리 찾기: 이전 학습과 어떻게 연결되는지 설명
- 최소 단어 수 확인: 화면에 표시되는 단어 수 확인

#### 3. 제출 옵션
- **임시 저장**: 작성 중인 응답을 저장하고 나중에 계속 작성
- **제출**: 응답을 최종 제출 (재제출 허용 시 수정 가능)

## 데이터베이스 스키마

### selfexplanation
- 활동 인스턴스 정보 저장
- 프롬프트 텍스트, 유형, 설정 등

### selfexplanation_responses
- 학생 응답 저장
- 응답 텍스트, 단어 수, 소요 시간, 상태, 평가, 피드백

### selfexplanation_analytics
- 응답 분석 데이터
- 품질 점수, 키워드 수, 문장 수, 평균 문장 길이

## 교육학적 배경

자기설명(Self-Explanation)은 검증된 학습 전략으로:

1. **메타인지 향상**: 자신의 사고 과정을 인식하고 모니터링
2. **깊은 처리**: 정보를 단순 암기가 아닌 의미 있게 처리
3. **지식 통합**: 새로운 정보와 기존 지식 연결
4. **오개념 발견**: 자신의 이해 오류를 스스로 발견

연구에 따르면 자기설명은 특히 STEM 과목에서 학습 효과를 크게 향상시킵니다.
