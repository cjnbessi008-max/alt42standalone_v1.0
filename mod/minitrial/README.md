# Mini Trial Game - Moodle Activity Plugin

확률 실험을 미니게임처럼 시뮬레이션하는 Moodle 활동 플러그인입니다.

## 📱 기능

- **4가지 확률 게임**
  - 🎲 주사위 굴리기
  - 🪙 동전 던지기
  - 🃏 카드 뽑기
  - 🎯 회전판 돌리기

- **실시간 통계**
  - 실험적 확률 vs 이론적 확률 비교
  - 빈도수 및 확률 계산
  - 시각적 통계 표시

- **스마트폰 화면 UI**
  - 우측 하단 가상 스마트폰 프레임
  - 반응형 디자인
  - 모바일 친화적 인터페이스

- **Moodle 통합**
  - 성적부 자동 연동
  - 진행 상황 추적
  - 활동 완료 추적

## 🔧 시스템 요구사항

- **Moodle**: 3.7 이상
- **PHP**: 7.1.9 이상
- **MySQL**: 5.7 이상
- **브라우저**: 최신 Chrome, Firefox, Safari, Edge

## 📦 설치 방법

### 방법 1: ZIP 파일 업로드

1. Moodle 관리자로 로그인
2. **사이트 관리 > 플러그인 > 플러그인 설치**로 이동
3. `mod_minitrial` ZIP 파일 업로드
4. 설치 진행

### 방법 2: 수동 설치

1. 이 디렉토리를 Moodle 설치 경로의 `mod/` 폴더에 복사:
   ```bash
   cp -r minitrial /path/to/moodle/mod/
   ```

2. Moodle 관리자로 로그인

3. **사이트 관리 > 알림**으로 이동하여 데이터베이스 업그레이드 진행

4. 플러그인 설치 완료

## 🎮 사용 방법

### 교사용

1. **활동 추가**
   - 코스로 이동
   - "편집 모드 켜기" 클릭
   - "활동 또는 리소스 추가" > "미니 시행 게임" 선택

2. **설정 구성**
   - **활동 이름**: 활동 제목 입력
   - **설명**: 활동 설명 입력
   - **게임 종류**: 주사위/동전/카드/회전판 선택
   - **필요한 시행 횟수**: 학생이 완료해야 할 시행 수 (기본: 10)
   - **최대 점수**: 성적부에 기록될 최대 점수 (기본: 100)

3. **저장**

### 학생용

1. **게임 시작**
   - 활동 클릭
   - 우측 하단 스마트폰 화면에서 "시행 실행" 버튼 클릭

2. **시행 진행**
   - 각 클릭마다 무작위 결과 생성
   - 실시간 통계 업데이트
   - 진행 상황 표시

3. **완료**
   - 요구된 시행 횟수 완료 시 자동으로 성적부에 기록
   - 결과 통계 확인 가능

## 📊 데이터베이스 구조

### 테이블

1. **mdl_minitrial**
   - 활동 인스턴스 정보
   - 게임 종류, 요구 시행 횟수 등

2. **mdl_minitrial_attempts**
   - 개별 시행 기록
   - 학생별 시행 결과 저장

3. **mdl_minitrial_progress**
   - 학생 진행 상황
   - 완료 횟수, 성적, 통계 등

## 📈 성적 계산

성적은 완료 비율에 따라 자동 계산됩니다:

```
성적 = (완료한 시행 / 요구된 시행) × 최대 점수
```

예시:
- 요구 시행: 10회
- 최대 점수: 100점
- 완료 시행: 7회
- 성적: 70점

## 🐛 문제 해결

### 플러그인이 나타나지 않음
- Moodle 캐시 정리: **사이트 관리 > 개발 > 캐시 삭제**
- 파일 권한 확인: `chmod -R 755 mod/minitrial`

### 데이터베이스 오류
- **사이트 관리 > 알림**에서 업그레이드 재시도
- MySQL 로그 확인

### 스마트폰 프레임이 표시되지 않음
- 브라우저 콘솔에서 CSS 로드 확인
- `styles.css` 파일 존재 확인
