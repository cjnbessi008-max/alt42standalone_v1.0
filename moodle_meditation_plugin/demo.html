💡 기능 소개

  • 복잡한 문제 시작 전 자동으로 명상 루틴 표시
  • 호흡 가이드 애니메이션
  • 한국어/영어 이중 언어 지원
  • 맞춤 설정 가능 (시간, 복잡도 임계값)
  • 건너뛰기 옵션
  • 사용 통계 추적

📚 기술 사양

기술 스택:
MySQL 5.7 | PHP 7.1.9 | Moodle 3.7
JavaScript (ES6) | CSS3 Animations

Moodle 통합:

  • 플러그인 타입: local
  • 이벤트 훅: mod_quiz_attempt_started
  • 웹 서비스: AJAX API 지원
  • 데이터베이스: 2개 테이블 (sessions, settings)

📦 설치 방법

  1. 플러그인 폴더를 Moodle의 local/ 디렉토리에 복사
  2. Moodle 관리자 페이지에서 "Notifications" 방문
  3. 데이터베이스 업그레이드 실행
  4. 퀴즈 설정에서 명상 루틴 활성화

자세한 내용은 설치 가이드를 참조하세요.
