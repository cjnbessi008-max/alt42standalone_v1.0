# 🚀 Term Growth - 빠른 시작 가이드

## 5분 안에 시작하기

### 1단계: 파일 확인

다음 파일들이 있는지 확인하세요:

```
term-growth-app/
├── index.html
├── css/style.css
├── js/
│   ├── term-growth.js
│   └── moodle-integration.js
├── README.md
└── QUICKSTART.md (이 파일)
```

### 2단계: 웹 서버 실행

**방법 1: Python 사용 (권장)**

터미널에서 다음 명령어 실행:

```bash
cd term-growth-app
python3 -m http.server 8000
```

**방법 2: Node.js 사용**

```bash
cd term-growth-app
npx http-server -p 8000
```

**방법 3: VS Code Live Server**

VS Code에서 `index.html` 파일을 우클릭 → "Open with Live Server"

### 3단계: 브라우저에서 열기

웹 브라우저에서 다음 주소로 접속:

```
http://localhost:8000
```

### 4단계: 사용해보기

#### 👨‍🏫 교사 패널 (좌측)

1. **다음 항 추가** 버튼 클릭
2. 우측 스마트폰 화면에서 그래프가 변화하는 것 확인
3. **자동 재생** 버튼으로 자동 데모 실행
4. **초기화** 버튼으로 처음부터 다시 시작

#### 📱 학생 화면 (우측 스마트폰)

1. 그래프 영역에서 함수 변화 관찰
2. 현재 추가된 항과 설명 읽기
3. **다음 단계** 버튼으로 스스로 학습 진행

## 📊 데모 문제 설명

현재 로드된 문제: **2차 다항식 이해하기**

| 단계 | 항 | 설명 |
|------|-----|------|
| 1 | `3` | 상수항 - 그래프를 y축으로 이동 |
| 2 | `2x` | 1차항 - 기울기 추가 |
| 3 | `x²` | 2차항 - 포물선으로 변화 |

**최종 함수**: f(x) = x² + 2x + 3

## 🔧 문제 해결

### 그래프가 보이지 않는 경우

1. 브라우저 콘솔 열기 (F12)
2. 에러 메시지 확인
3. 인터넷 연결 확인 (CDN 라이브러리 로드 필요)
4. 캐시 삭제 후 새로고침 (Ctrl+Shift+R)

### CDN 로드 실패 시

`index.html` 파일을 열고 CDN URL 확인:

```html
<!-- Chart.js -->
<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js"></script>

<!-- Math.js -->
<script src="https://cdn.jsdelivr.net/npm/mathjs@12.2.0/lib/browser/math.min.js"></script>
```

인터넷 연결을 확인하거나 라이브러리를 로컬로 다운로드하세요.
