# Moodle 핵심 조건 선택 모듈 설치 가이드

## 시스템 요구사항

- **Moodle 버전**: 3.7 이상
- **PHP 버전**: 7.1.9 이상
- **MySQL 버전**: 5.7 이상

## 설치 방법

### 1. 플러그인 파일 복사

```bash
# Moodle 설치 디렉토리로 이동
cd /path/to/moodle

# 플러그인 디렉토리 생성
mkdir -p mod/coreconditions

# 플러그인 파일 복사
cp -r /path/to/moodle-plugin/mod/coreconditions/* mod/coreconditions/
```

### 2. 파일 권한 설정

```bash
# 웹 서버 사용자에게 소유권 부여 (일반적으로 www-data 또는 apache)
chown -R www-data:www-data mod/coreconditions

# 적절한 권한 설정
chmod -R 755 mod/coreconditions
```

### 3. Moodle 데이터베이스 업그레이드

1. 관리자 계정으로 Moodle에 로그인
2. 다음 경로로 이동: `사이트 관리 > 알림`
3. Moodle이 새 플러그인을 감지하고 업그레이드를 요청합니다
4. "지금 Moodle 데이터베이스 업그레이드" 버튼 클릭
5. 설치 과정을 확인하고 완료

### 4. 설치 확인

1. `사이트 관리 > 플러그인 > 활동 모듈` 로 이동
2. 목록에 "Core Conditions" (핵심 조건)이 표시되는지 확인

## 사용 방법

### 교사용 가이드

#### 활동 생성

1. 코스에서 "편집 모드 켜기" 클릭
2. "활동 또는 리소스 추가" 선택
3. "Core Conditions" (핵심 조건) 선택
4. 활동 이름, 설명, 최대 점수 입력
5. "저장하고 표시" 클릭

#### 문제 추가

1. 활동 페이지에서 "새 문제 추가" 클릭
2. 문제 정보 입력:
   - 문제 이름
   - 설명
   - 문제 유형 (분수, 대수, 기하, 산술 등)
   - 난이도 (1-10)
   - 정답
3. "문제 만들기" 클릭

#### 핵심 조건 선택 (3개 필수)

각 문제마다 정확히 3개의 핵심 조건을 설정해야 합니다:

**조건 1 예시** (검증):
- 유형: `검증 (Validation)`
- 이름: `올바른 분수 형식`
- 설명: `답은 분수 형식(분자/분모)이어야 합니다`
- 규칙: `denominator != 0`
- 가중치: `33.33%`

**조건 2 예시** (계산):
- 유형: `계산 (Calculation)`
- 이름: `정확한 결과`
- 설명: `계산이 수학적으로 정확해야 합니다`
- 규칙: `answer == correct_answer`
- 가중치: `33.33%`

**조건 3 예시** (진행):
- 유형: `진행 (Progression)`
- 이름: `문제 해결 과정`
- 설명: `학생이 해결 방법에 대한 이해를 보여줍니다`
- 규칙: `check_methodology(answer)`
- 가중치: `33.34%`

### 학생용 가이드

#### 문제 풀이

1. 코스에서 "Core Conditions" 활동 클릭
2. 풀고 싶은 문제 선택
3. 문제 설명과 3가지 핵심 조건 확인
4. 답안 입력
5. "답안 제출" 클릭

#### 결과 확인

제출 후 다음 정보를 확인할 수 있습니다:
- **점수**: 충족한 조건에 따른 백분율
- **충족한 조건**: 3개 중 몇 개의 조건을 만족했는지
- **피드백**: 충족하지 못한 조건에 대한 상세 설명
- **시도 기록**: 이전 시도 내역과 점수

## 데이터베이스 구조

### 1. mdl_coreconditions
메인 활동 테이블

### 2. mdl_coreconditions_problems
각 활동 내의 문제들

### 3. mdl_coreconditions_conditions
핵심 조건 (문제당 정확히 3개)

### 4. mdl_coreconditions_attempts
학생 시도 추적

## 채점 방식

- 각 조건은 가중치를 가집니다 (기본값: 각 33.33%)
- 총 가중치는 100%가 되어야 합니다
- 학생은 일부 조건만 충족해도 부분 점수를 받습니다

**예시**:
- 조건 1 충족: 33.33%
- 조건 2 미충족: 0%
- 조건 3 충족: 33.33%
- **총점**: 66.66%

## 문제 해결

### 플러그인이 표시되지 않음

```bash
# 파일 권한 확인
chmod -R 755 mod/coreconditions

# Moodle 캐시 삭제
# 관리 > 개발 > 모든 캐시 삭제
```

### 데이터베이스 오류

```sql
-- MySQL 버전 확인
SELECT VERSION();

-- 문자 세트 확인
SHOW VARIABLES LIKE 'character_set%';
```

### 조건이 저장되지 않음

```bash
# PHP 설정 확인
php -i | grep max_input_vars

# php.ini에서 값 증가
max_input_vars = 3000
```
