# 🚀 미래직업 탐험대 - AI 시대 직업 추천 앱

중학생을 위한 재미있는 대화형 미래 직업 추천 웹 애플리케이션입니다.

## ✨ 주요 기능

- **재미있는 대화형 인터페이스**: 챗봇 스타일의 친근한 대화로 진행
- **AI 시대 맞춤 직업 추천**: 16가지 미래 직업 중 사용자에게 맞는 직업 추천
- **핵심 능력 설명**: AI 시대에 필요한 4가지 핵심 능력 설명
- **실용적인 조언**: 각 능력을 키우는 구체적인 방법 제시
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원

## 🎯 앱의 특징

### 1. AI 시대 정보 반영
- 실제로 등장할 가능성이 높은 미래 직업들 소개
- AI와 인간의 협력 관계 설명
- 자동화 시대에도 중요한 인간 고유의 능력 강조

### 2. 중학생 눈높이에 맞춘 콘텐츠
- 쉽고 친근한 언어 사용
- 이모지를 활용한 시각적 재미
- 적절한 예시와 설명

### 3. 교육적 가치
- 사고력과 창의력의 중요성 강조
- 비판적 사고 능력 설명
- 공감과 소통의 가치 전달
- 평생 학습의 중요성 인식

## 🎮 사용 방법

1. **파일 열기**: `index.html` 파일을 웹 브라우저에서 열기
2. **질문에 답하기**: 4가지 질문에 버튼을 클릭하여 답변
3. **결과 확인**: 자신에게 맞는 미래 직업과 핵심 능력 확인
4. **다시 시작**: 다른 선택지로 다시 테스트 가능

## 📋 기술 스택

- **HTML5**: 웹 페이지 구조
- **CSS3**: 현대적이고 반응형 디자인
- **Vanilla JavaScript**: 대화 엔진 및 로직 구현
- **완전 하드코딩**: 모든 대화와 직업 정보는 하드코딩되어 있음

## 🗂️ 앱 구조

### 대화 흐름
```
시작 → AI 시대 설명(선택) → Q1(활동) → Q2(관심) → Q3(스타일) → Q4(능력) → 결과
```

### 직업 카테고리
- **카테고리**: 창의형, 분석형, 소셜형, 자연형 (4가지)
- **관심 분야**: 환경, 건강, 기술, 교육 (4가지)
- **총 직업 수**: 16가지 조합

### AI 시대 핵심 능력
1. **창의적 사고** 💭: AI가 할 수 없는 인간만의 능력
2. **비판적 사고** 🔬: AI의 결과를 판단하고 검증하는 능력
3. **공감과 소통** 💝: AI가 대신할 수 없는 인간 관계의 핵심
4. **적응력과 학습** 📖: 변화하는 세상에서 가장 중요한 능력

## 🎨 디자인 특징

## 🚀 실행하기

### 로컬에서 실행
```bash
# 저장소 클론 또는 파일 다운로드
cd alt42standalone_v1.0

# 웹 브라우저에서 열기
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```
