# 수학 공식 학습 앱 (Math Formula Learning App) 🎓

수학 공식을 효과적으로 암기하기 위한 **독립형 웹 애플리케이션**입니다. 애니메이션과 반복적인 질문을 통해 능동적 회상(Active Recall)을 유도하여 장기 기억을 강화합니다.

![License](https://img.shields.io/badge/license-MIT-green)
![PWA](https://img.shields.io/badge/PWA-Ready-purple)

## ✨ 주요 기능

### 🎯 핵심 기능
- **25+ 수학 공식**: 대수, 기하, 삼각함수, 미적분, 물리, 통계 포함
- **카테고리별 분류**: 6개 주요 카테고리로 체계적 학습
- **난이도 표시**: 초급/중급/고급으로 구분
- **검색 기능**: 공식 이름, 내용, 설명으로 즉시 검색
- **학습 통계**: 학습 시간, 완료한 공식, 진도율 실시간 추적
- **다크 모드**: 눈의 피로 감소를 위한 다크 테마
- **PWA 지원**: 오프라인 접근 및 홈 화면 설치

### 📊 학습 추적
- 총 학습 세션 수
- 완료한 공식 개수
- 총 학습 시간
- 전체 진행률 (%)
- 최근 학습 기록 (최대 10개)
- localStorage 기반 영구 저장

### 🎨 사용자 경험
- 반응형 디자인 (모바일/태블릿/데스크톱)
- 부드러운 애니메이션 (Framer Motion)
- 색상 코딩된 공식 구성 요소
- 직관적인 네비게이션
- 터치 최적화 인터페이스

## 📖 사용 방법

### 1. 공식 선택하기

#### 방법 A: 카테고리별 탐색
1. 상단 탭에서 원하는 카테고리 선택
   - 🔢 대수학 (4개)
   - 📐 기하학 (5개)
   - 📊 삼각함수 (3개)
   - ∫ 미적분 (2개)
   - ⚡ 물리학 (4개)
   - 📈 통계 (3개)
2. 원하는 공식 카드 클릭

#### 방법 B: 검색
- 검색창에 공식 이름, 내용, 또는 설명 입력
- 실시간 필터링으로 원하는 공식 찾기

#### 방법 C: 직접 입력
- 상단의 "공식 직접 입력" 섹션에 공식 입력
- Enter 키 또는 "학습 시작" 버튼 클릭

### 2. 학습하기

**자동 학습 플로우**:
```
1. 공식 표시 (3초) → 전체 형태 관찰
   ↓
2. 질문 제시 → 마음속으로 답 떠올리기
   ↓
3. "공식 다시 보기" 클릭 → 답 확인 (2.5초)
   ↓
4. 다음 질문으로 이동
   ↓
5. 모든 질문 완료 후 처음부터 반복 (총 3회)
   ↓
6. 학습 완료! 🎉
```

**질문 유형**:
- 변수 식별: "어떤 변수들이 사용되나요?"
- 연산자 파악: "어떤 연산이 수행되나요?"
- 상수 확인: "공식에 포함된 상수는 무엇인가요?"
- 전체 구조: "공식의 전체적인 형태를 떠올려보세요"
- 의미 이해: "이 공식은 무엇을 계산하나요?"

### 3. 통계 확인

- 우측 상단 "📊 학습 통계" 버튼 클릭
- 학습 진행률, 시간, 완료한 공식 확인
- 최근 학습 기록 검토

### 4. 다크 모드

- 우측 상단 ☀️/🌙 버튼으로 테마 전환
- 설정은 자동으로 저장됨

## 🎓 학습 과학 원리

### 1. 능동적 회상 (Active Recall)
단순 반복이 아닌 질문을 통해 기억을 능동적으로 인출하여 신경 회로 강화

### 2. 간격 반복 (Spaced Repetition)
같은 공식을 3회 반복하되, 질문과 확인을 번갈아 진행하여 효과 극대화

### 3. 분산 학습 (Interleaving)
공식의 다양한 측면(변수, 연산, 구조, 의미)을 교차 학습하여 깊은 이해 유도

### 4. 시각적 부호화 (Visual Encoding)
- 색상 코딩: 변수(파란색), 연산자(보라색), 상수(초록색), 함수(주황색)
- 애니메이션: 주의 집중 및 기억 강화
- 하이라이트: 관련 부분 강조로 선택적 주의 유도

## 📈 포함된 공식 (25개)

### 대수학 (4개)
- 이차방정식 근의 공식
- 직선의 기울기
- 이항정리
- 제곱의 차

### 기하학 (5개)
- 피타고라스 정리
- 원의 넓이
- 원의 둘레
- 구의 부피
- 삼각형의 넓이

### 삼각함수 (3개)
- 삼각함수 항등식
- 탄젠트 정의
- 코사인 법칙

### 미적분 (2개)
- 거듭제곱 미분
- 거듭제곱 적분

### 물리학 (4개)
- 질량-에너지 등가원리 (E=mc²)
- 뉴턴의 제2법칙
- 운동 에너지
- 만유인력의 법칙

### 통계 (3개)
- 산술 평균
- 분산
- 표준편차

## 🐛 문제 해결

### 공식이 제대로 파싱되지 않아요
현재는 기본 텍스트 파싱만 지원합니다:
- 제곱: `²` 또는 `^2`
- 제곱근: `sqrt()`
- 분수: `/`

### 통계가 사라졌어요
브라우저 캐시를 지우면 통계도 삭제됩니다. 정기적으로 백업하세요.

### 다크 모드가 작동하지 않아요
페이지를 새로고침해보세요. localStorage 권한을 확인하세요.
