# 🎵 플레이리스트 매칭 앱

AI를 활용한 스마트 플레이리스트 추천 웹 애플리케이션입니다. 오늘의 키워드를 입력하면 OpenAI API가 가장 적합한 플레이리스트를 자동으로 매칭해줍니다.

## ✨ 주요 기능

- **AI 기반 매칭**: OpenAI API를 사용하여 키워드와 플레이리스트를 지능적으로 매칭
- **플레이리스트 관리**: 쉽게 플레이리스트를 추가, 제거, 복구
- **파일 업로드**: JSON 파일로 여러 플레이리스트를 한 번에 등록
- **숨김 기능**: 제거된 플레이리스트를 숨김 처리하고 필요시 복구
- **로컬 저장**: 브라우저의 로컬 스토리지에 데이터 자동 저장
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원

## 🚀 시작하기

### 1. 파일 다운로드

프로젝트 파일을 다운로드하거나 클론합니다.

```bash
git clone <repository-url>
cd alt42standalone_v1.0
```

### 2. 웹 브라우저에서 실행

`index.html` 파일을 웹 브라우저에서 엽니다.

- 더블 클릭으로 직접 열기
- 또는 로컬 서버 실행 (권장):

```bash
# Python 3 사용
python -m http.server 8000

# Node.js 사용
npx http-server

# VS Code Live Server 사용
# VS Code에서 index.html 우클릭 → "Open with Live Server"
```

그 후 브라우저에서 `http://localhost:8000` 접속

### 3. OpenAI API 키 설정

1. [OpenAI 플랫폼](https://platform.openai.com/)에서 API 키 발급
2. 앱의 "설정" 섹션에 API 키 입력 후 저장

## 📖 사용 방법

### 플레이리스트 추가하기

#### 방법 1: 수동 입력

1. "플레이리스트 관리" 섹션으로 이동
2. 플레이리스트 이름, 설명, 링크 입력
3. "플레이리스트 추가" 버튼 클릭

예시:
- **이름**: 코딩할때
- **설명**: 설계 감각 끌어올릴 때, 집중력이 필요한 프로그래밍 작업
- **링크**: https://www.youtube.com/playlist?list=...

#### 방법 2: JSON 파일 업로드

`data/sample-playlists.json` 파일을 참고하여 JSON 형식으로 작성:

```json
[
  {
    "name": "플레이리스트 이름",
    "description": "상세 설명 및 키워드",
    "link": "URL 링크"
  }
]
```

"또는 JSON 파일 업로드" 버튼을 클릭하여 파일 업로드

### 키워드로 검색하기

1. "키워드로 플레이리스트 찾기" 섹션의 입력창에 키워드 입력
   - 예: "집중력", "창의성", "편안함", "운동"
2. "검색" 버튼 클릭 또는 Enter 키 입력
3. AI가 분석하여 가장 적합한 플레이리스트 추천
4. 매칭 점수와 추천 이유 확인

### 플레이리스트 관리

- **제거하기**: 각 플레이리스트 카드의 "제거" 버튼 클릭
  - 플레이리스트가 숨김 처리됩니다
  - 데이터는 삭제되지 않고 보관됩니다

- **복구하기**:
  1. "숨김 보기" 버튼 클릭
  2. 숨겨진 플레이리스트가 표시됩니다
  3. "복구" 버튼을 클릭하여 다시 활성화

## 💡 JSON 파일 형식

플레이리스트를 JSON 파일로 저장할 때 다음 형식을 사용하세요:

### 배열 형식 (권장)

```json
[
  {
    "name": "코딩할때",
    "description": "설계 감각 끌어올릴 때",
    "link": "https://example.com/playlist1"
  },
  {
    "name": "공부할때",
    "description": "집중력이 필요한 학습",
    "link": "https://example.com/playlist2"
  }
]
```

### 객체 형식

```json
{
  "playlists": [
    {
      "name": "코딩할때",
      "description": "설계 감각 끌어올릴 때",
      "link": "https://example.com/playlist1"
    }
  ]
}
```

## 🔒 보안 및 개인정보

- API 키는 브라우저의 로컬 스토리지에만 저장됩니다
- 모든 데이터는 사용자의 브라우저에만 저장되며, 외부 서버로 전송되지 않습니다
- OpenAI API와의 통신만 이루어집니다

## ⚠️ 주의사항

1. **API 키 관리**
   - API 키를 안전하게 보관하세요
   - 공개 저장소에 API 키를 커밋하지 마세요
   - API 사용량에 따른 비용이 발생할 수 있습니다

2. **브라우저 호환성**
   - 최신 버전의 Chrome, Firefox, Safari, Edge 사용 권장
   - LocalStorage를 지원하는 브라우저 필요

3. **데이터 백업**
   - 브라우저 캐시를 지우면 데이터가 삭제될 수 있습니다
   - 중요한 플레이리스트는 JSON 파일로 내보내기 권장

## 🐛 문제 해결

### API 키 관련 오류

- API 키가 올바르게 입력되었는지 확인
- OpenAI 계정의 크레딧 잔액 확인
- API 키의 권한 설정 확인

### 플레이리스트가 표시되지 않음

- 브라우저의 콘솔(F12)에서 오류 메시지 확인
- 로컬 스토리지 데이터 확인
- 페이지 새로고침 시도

### JSON 파일 업로드 실패

- JSON 형식이 올바른지 확인
- 파일 인코딩이 UTF-8인지 확인
- 필수 필드(name, description, link)가 모두 포함되었는지 확인
