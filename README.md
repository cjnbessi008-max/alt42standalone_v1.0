# 수학 공식 학습 앱 (Math Formula Learning App)

수학 공식을 효과적으로 암기하기 위한 인터랙티브 학습 애플리케이션입니다. 애니메이션과 반복적인 질문을 통해 능동적 회상(Active Recall)을 유도하여 장기 기억을 강화합니다.

## 🎯 주요 기능

### 1. 공식 입력
- **직접 입력**: 텍스트로 수학 공식 입력
- **예제 선택**: 미리 준비된 유명한 수식들 (피타고라스 정리, 이차방정식 근의 공식, E=mc² 등)
- **이미지 업로드** (향후 구현 예정): 공식 이미지를 업로드하여 OCR로 인식

### 2. 학습 프로세스

#### 단계 1: 초기 공식 표시
- 공식이 부드러운 애니메이션과 함께 나타남
- 3초간 공식을 관찰하며 전체적인 형태 파악

#### 단계 2: 질문 단계
공식의 각 부분에 대한 질문이 순차적으로 제시됩니다:
- 어떤 변수들이 사용되었나요?
- 어떤 연산이 수행되나요?
- 상수는 무엇인가요?
- 공식의 전체 구조는 어떻게 되나요?
- 이 공식의 의미는 무엇인가요?

#### 단계 3: 공식 재확인
- 마음속으로 답을 떠올린 후 버튼을 눌러 공식 확인
- 해당 질문과 관련된 부분이 하이라이트되어 표시

#### 단계 4: 반복 학습
- 모든 질문을 3회 반복하여 공식을 완전히 내재화
- 각 반복마다 진행 상황 표시

### 3. 시각적 효과
- **애니메이션**: Framer Motion을 사용한 부드러운 전환 효과
- **색상 코딩**:
  - 🔵 변수 (파란색)
  - 🟣 연산자 (보라색)
  - 🟢 상수 (초록색)
  - 🟠 함수 (주황색)
- **하이라이트**: 질문과 관련된 부분을 동적으로 강조

## 🚀 시작하기

### 필요 조건
- Node.js 18 이상
- npm 또는 yarn

### 설치

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 미리보기
```

### 개발 서버
개발 서버는 기본적으로 http://localhost:3000 에서 실행됩니다.

## 🎓 학습 원리

이 앱은 다음의 학습 과학 원리에 기반합니다:

### 1. 능동적 회상 (Active Recall)
단순히 공식을 보는 것이 아니라, 질문을 통해 스스로 떠올리게 함으로써 기억을 강화합니다.

### 2. 간격 반복 (Spaced Repetition)
공식을 여러 번 반복하되, 질문과 확인을 번갈아 진행하여 효과적인 학습을 유도합니다.

### 3. 분산 학습 (Interleaving)
공식의 다양한 측면(변수, 연산자, 구조, 의미)을 교차하여 학습함으로써 깊은 이해를 돕습니다.

### 4. 시각적 강화
색상 코딩과 애니메이션을 통해 시각적 기억을 활용하여 기억 효과를 증대시킵니다.
