# Alternative Solutions Learning System for Moodle 3.7

## 개요 (Overview)
Moodle 3.7 LMS와 연동하여 학생들이 문제 해결 시 각 단계에서 대안적 풀이를 떠올리게 유도하는 교육용 웹앱입니다.

## 시스템 요구사항
- **Moodle**: 3.7
- **PHP**: 7.1.9
- **MySQL**: 5.7
- **웹서버**: Apache 2.4+ 또는 Nginx

## 주요 기능
1. **단계별 문제 해결**: 복잡한 문제를 여러 단계로 나누어 접근
2. **대안적 풀이 유도**: 각 단계마다 다양한 접근 방법 제시 및 사고 촉진
3. **사고 과정 추적**: 학생의 문제 해결 전략 및 대안 탐색 기록
4. **즉각적 피드백**: 각 단계별 피드백 제공
5. **성찰 활동**: 다양한 풀이 방법 비교 및 최적 전략 학습

## 프로젝트 구조
```
moodle_plugin/          # Moodle 활동 모듈
├── mod/
│   └── altsolutions/   # 대안적 풀이 모듈
│       ├── version.php
│       ├── db/
│       ├── lang/
│       ├── classes/
│       └── templates/
└── docs/              # 문서
```

## 설치 방법
1. Moodle의 `mod/` 디렉토리에 플러그인 복사
2. Moodle 관리자 페이지에서 플러그인 설치
3. 데이터베이스 자동 설정 완료

## 사용 방법
1. 코스에 "대안적 풀이 활동" 추가
2. 문제와 단계별 힌트 설정
3. 학생들이 각 단계에서 대안적 접근 방법 탐색
4. 교사는 학생들의 사고 과정 모니터링
