# AI 페이스메이커 - 학습 플레이리스트 매칭 웹앱

"난 죽을힘을 다해 달리고 있다. 넌 공부해라!" 🏃‍♂️💨

달리는 AI 페이스메이커가 학생들의 학습을 응원하는 플레이리스트 매칭 웹 애플리케이션입니다.

## 주요 기능

### 1. 🎯 스마트 플레이리스트 매칭
- **키워드 기반 자동 매칭**: 학습 키워드를 입력하면 최적의 플레이리스트를 추천
- **OpenAI API 통합**: AI가 상황에 맞는 최고의 음악을 선택
- **폴백 매칭**: API 없이도 키워드 기반 기본 매칭 지원

### 2. 🎵 플레이리스트 관리
- **플레이리스트 제거**: 원하지 않는 플레이리스트를 숨김 처리
- **숨김 보기/숨기기**: 숨긴 플레이리스트를 다시 확인하고 복원 가능
- **로컬 저장소 활용**: 숨김 상태가 브라우저에 저장되어 유지됨

### 3. 💪 학생 응원 디자인
- **달리는 AI 애니메이션**: 페이스메이커가 끊임없이 달리는 모습
- **응원 메시지**: 매칭 시마다 랜덤한 응원 메시지 표시
- **생동감 있는 UI**: 그라디언트, 애니메이션, 펄스 효과

### 4. 🎨 세련된 디자인
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원
- **다크/라이트 그라디언트**: 보라색 계열의 고급스러운 디자인
- **부드러운 애니메이션**: 모든 인터랙션에 자연스러운 전환 효과

## 설치 및 실행

### 1. 파일 다운로드
모든 파일을 같은 폴더에 저장합니다.

### 2. 플레이리스트 데이터 수정
`playlists.json` 파일을 열어 자신만의 플레이리스트를 추가/수정합니다:

```json
{
  "id": 1,
  "name": "플레이리스트 이름",
  "keywords": ["키워드1", "키워드2", "키워드3"],
  "link": "유튜브 또는 음악 링크",
  "description": "플레이리스트 설명",
  "hidden": false
}
```

### 3. 웹 브라우저로 실행
`index.html` 파일을 더블클릭하거나 브라우저로 엽니다.

### 4. OpenAI API 키 설정 (선택사항)
- 첫 실행 시 API 키 입력 모달이 표시됩니다
- OpenAI API 키를 입력하면 AI 기반 스마트 매칭 활성화
- 건너뛰기를 선택하면 기본 키워드 매칭으로 동작

## 사용 방법

### 플레이리스트 매칭하기
1. 키워드 입력란에 학습 상황을 입력 (예: "수학", "코딩", "집중")
2. "매칭하기 🎵" 버튼 클릭 또는 Enter 키 입력
3. AI가 최적의 플레이리스트를 추천
4. 추천된 플레이리스트의 "재생하기" 버튼 클릭

### 플레이리스트 관리하기
- **제거**: 각 플레이리스트 카드의 "제거" 버튼 클릭
- **복원**: "숨김 보기" 버튼을 눌러 숨긴 플레이리스트를 확인하고 "복원" 버튼 클릭
- **숨김 숨기기**: 다시 "숨김 숨기기" 버튼을 눌러 숨긴 플레이리스트를 감춤

## 기술 스택

- **HTML5**: 시맨틱 마크업
- **CSS3**: 그라디언트, 애니메이션, Flexbox, Grid
- **JavaScript (ES6+)**: 비동기 처리, LocalStorage, Fetch API
- **OpenAI API**: GPT-3.5-turbo 모델 사용

## OpenAI API 키 발급 방법

1. [OpenAI 웹사이트](https://platform.openai.com/signup) 접속
2. 계정 생성 또는 로그인
3. API Keys 메뉴로 이동
4. "Create new secret key" 클릭
5. 생성된 키를 복사하여 앱에 입력

**참고**: API 사용에 따라 요금이 부과될 수 있습니다. [가격 정책](https://openai.com/pricing)을 확인하세요.
