# 🌊 Recurrence Wave Visualizer

점화식(재귀 관계식)의 구조를 파도 애니메이션으로 시각화하는 독립형 웹앱입니다.

## ✨ 주요 기능

- **파도 시각화**: 재귀 호출의 각 깊이를 파도 층으로 표현
- **가상 스마트폰**: 우측 하단에 스마트폰 프레임으로 결과 표시
- **다양한 예제**: 피보나치, 팩토리얼, 합 계산, 거듭제곱
- **인터랙티브 컨트롤**: 실시간으로 값 변경 및 애니메이션 제어
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 지원

## 🚀 시작하기

## 🎮 사용 방법

1. **문제 선택**: 4가지 점화식 중 하나를 선택
2. **입력 값 조정**: 슬라이더로 계산할 값 설정 (1-10)
3. **애니메이션 제어**: 재생/일시정지 버튼으로 애니메이션 제어
4. **속도 조절**: 애니메이션 속도를 0.5x ~ 3x로 조정
5. **시각화 관찰**: 우측 하단 스마트폰 화면에서 파도 애니메이션 확인

## 📊 지원하는 점화식

### 1. 피보나치 수열
- **점화식**: F(n) = F(n-1) + F(n-2)
- **기저 사례**: F(0) = 0, F(1) = 1
- **예시**: F(5) = 5

### 2. 팩토리얼
- **점화식**: n! = n × (n-1)!
- **기저 사례**: 0! = 1, 1! = 1
- **예시**: 5! = 120

### 3. 합 계산
- **점화식**: Sum(n) = n + Sum(n-1)
- **기저 사례**: Sum(0) = 0
- **예시**: Sum(5) = 15

### 4. 거듭제곱
- **점화식**: 2^n = 2 × 2^(n-1)
- **기저 사례**: 2^0 = 1, 2^1 = 2
- **예시**: 2^5 = 32

## 🎨 시각화 특징

- 각 재귀 깊이는 고유한 색상과 파장을 가진 파도로 표현
- 노드는 파도 위에 원으로 표시되며, 계산 중인 값을 표시
- 기저 사례(base case)에 도달하면 결과 값이 녹색으로 표시
- 부드러운 애니메이션과 그림자 효과로 깊이감 표현
