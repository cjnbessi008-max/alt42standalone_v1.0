# 🎵 Rhythm Seq - Standalone Edition

**리듬감 있게 배우는 수열 학습 웹 앱**

완전히 독립적으로 작동하는 Progressive Web App(PWA)입니다. 별도의 백엔드 서버나 데이터베이스 없이 브라우저에서 바로 실행됩니다!

## ✨ 주요 기능

### 🎨 현대적인 UI/UX
- **3패널 레이아웃**: 문제 선택 | 스마트폰 디스플레이 | 정보 패널
- **가상 스마트폰**: 실제 스마트폰처럼 작동하는 UI
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 완벽 지원
- **다크 테마**: 눈의 피로를 줄이는 테마 옵션

### 🎵 리듬 애니메이션
- **Canvas 기반**: 부드럽고 성능 좋은 애니메이션
- **4가지 스타일**: Wave, Bounce, Spiral, Random
- **10단계 속도**: 매우 느림 ~ 초고속
- **숫자 크기 비례**: 큰 숫자는 큰 원으로 표시
- **색상 그라데이션**: 값에 따른 자동 색상 변화

### 🔊 음향 효과
- **Web Audio API**: 브라우저 기본 사운드
- **음계 맵핑**: 숫자를 음계로 변환
- **멜로디 재생**: 수열을 멜로디로 들을 수 있음
- **효과음**: 정답, 오답, 클릭, 업적 등

### 🎯 게임화 시스템
- **점수 시스템**: 문제 해결 시 점수 획득
- **연속 정답**: 연속으로 맞추면 보너스
- **5가지 업적**: 다양한 달성 조건
- **레벨 시스템**: 1~5단계 난이도
- **진행률 추적**: 어떤 문제를 풀었는지 기록

### 💾 로컬 저장소
- **진행상황 저장**: LocalStorage로 자동 저장
- **오프라인 지원**: 인터넷 없이도 작동
- **데이터 백업**: JSON 형식으로 내보내기/가져오기
- **설정 유지**: 테마, 속도, 사운드 등

### 📱 PWA (Progressive Web App)
- **홈 화면 설치**: 앱처럼 설치 가능
- **오프라인 작동**: Service Worker로 캐싱
- **빠른 로딩**: 자원 사전 캐싱
- **자동 업데이트**: 새 버전 자동 감지

## 🚀 빠른 시작

### 1. 파일 배포

```bash
# 웹 서버 디렉토리로 복사
cp -r rhythm-seq-standalone /var/www/html/

# 또는 Python 간이 서버
cd rhythm-seq-standalone
python3 -m http.server 8000
```

### 2. 브라우저에서 열기

```
http://localhost:8000/
```

### 3. 사용 시작!

1. 왼쪽 패널에서 문제 선택
2. ▶️ 버튼 클릭하여 애니메이션 시작
3. 패턴 파악 후 답 입력
4. 정답을 맞추고 점수 획득!

## 🎮 게임 방법

### 기본 조작

| 버튼 | 기능 |
|------|------|
| ▶️ 시작 | 애니메이션 재생 |
| ⏸️ 일시정지 | 애니메이션 멈춤 |
| 🔄 초기화 | 처음부터 다시 |
| 💡 힌트 | 힌트 보기 (점수 감소) |

### 점수 시스템

- **기본 점수**: 문제별 10~40점
- **첫 시도 보너스**: +50% (힌트 미사용 시)
- **힌트 페널티**: -30%
- **연속 정답 보너스**: 연속으로 맞추면 불꽃 아이콘(🔥) 증가

### 업적 목록

| 업적 | 조건 | 아이콘 |
|------|------|--------|
| 첫 해결! | 첫 번째 문제 해결 | 🎯 |
| 5연속 정답 | 5문제 연속 정답 | 🔥 |
| 만점왕 | 힌트 없이 첫 시도 정답 | ⭐ |
| 수열 마스터 | 모든 문제 해결 | 👑 |
| 스피드 데몬 | 10초 안에 문제 풀기 | ⚡ |

## ⚙️ 설정

### 테마
- **기본**: 밝은 테마 (기본값)
- **다크**: 어두운 테마
- **컬러풀**: 화려한 색상

### 애니메이션 스타일
- **Wave**: 원형으로 파동치는 애니메이션
- **Bounce**: 튕기는 애니메이션
- **Spiral**: 나선형 패턴
- **Random**: 무작위 위치

### 기타 옵션
- **사운드 ON/OFF**: 소리 효과 켜기/끄기
- **자동 재생**: 문제 선택 시 자동으로 애니메이션 시작
- **속도 조절**: 1(매우 느림) ~ 10(초고속)

## 🆚 Moodle 버전과의 차이

| 기능 | Moodle 버전 | Standalone 버전 |
|------|-------------|-----------------|
| 백엔드 | PHP + MySQL | 없음 (클라이언트만) |
| 데이터 저장 | 서버 DB | LocalStorage |
| 문제 관리 | Moodle 관리자 | JSON 파일 |
| 사용자 인증 | Moodle 계정 | 없음 (로컬) |
| 오프라인 | 불가능 | 완전 지원 |
| 설치 | 서버 필요 | 브라우저만 |
| PWA | 미지원 | 완전 지원 |
| 음향 효과 | 없음 | Web Audio API |
| 게임화 | 없음 | 점수/업적 시스템 |
| 애니메이션 | 기본 | Canvas 고급 |

## 🐛 문제 해결

### 문제가 표시되지 않음
- 브라우저 콘솔 확인 (F12)
- `data/sequences.json` 파일 경로 확인
- CORS 에러 시 웹 서버 사용 (file:// 프로토콜 비권장)

### 애니메이션이 느림
- 속도를 높임 (슬라이더 조정)
- 다른 브라우저 탭 닫기
- 하드웨어 가속 활성화

### 소리가 나지 않음
- 사운드 토글 켜기
- 브라우저 음소거 해제
- Web Audio API 지원 브라우저 사용

### 저장이 안 됨
- LocalStorage 활성화 확인
- 사생활 보호 모드 비활성화
- 쿠키/저장소 차단 해제
