Linear Stairs 데모 페이지

등차수열 계단 시각화 - 다양한 사용 예제

💡 사용법: 아래 예제들을 확인하고, URL 파라미터를 수정하여 다양한 등차수열을 시각화해보세요.

🎛️ 인터랙티브 컨트롤

아래 값을 변경하여 실시간으로 시각화를 확인하세요:

📊 예제 1: 기본 등차수열

첫째항: 1, 공차: 2, 항: 5개

수열: 1, 3, 5, 7, 9

index.html?a1=1&d=2&n=5

📉 예제 2: 감소하는 수열

첫째항: 20, 공차: -3, 항: 7개

수열: 20, 17, 14, 11, 8, 5, 2

index.html?a1=20&d=-3&n=7

📈 예제 3: 빠르게 증가하는 수열

첫째항: 5, 공차: 10, 항: 6개

수열: 5, 15, 25, 35, 45, 55

index.html?a1=5&d=10&n=6

🎨 예제 4: 사용자 정의

위 컨트롤 패널에서 값을 변경하고 '업데이트' 버튼을 클릭하세요.

index.html?a1=1&d=2&n=5

🔗 Moodle 연동 예제

Moodle에서 사용하려면 다음과 같이 iframe을 삽입하세요:

HTML 코드:

<iframe
  src="http://your-domain.com/linear-stairs/index.html?a1=3&d=5&n=7&moodle=1"
  width="100%"
  height="900px"
  frameborder="0"
  style="max-width: 375px; margin: 0 auto; display: block;">
</iframe>

Moodle 퀴즈 활동에서 사용:

  1. Moodle 코스에서 "활동 추가" → "레이블" 또는 "페이지" 선택
  2. HTML 편집 모드로 전환
  3. 위 iframe 코드를 붙여넣기
  4. URL의 파라미터(a1, d, n)를 문제에 맞게 수정
  5. 저장 후 학생들이 시각화를 볼 수 있습니다

URL 파라미터:

  • a1: 첫째항 (기본값: 1)
  • d: 공차 (기본값: 2)
  • n: 항의 개수 (기본값: 5)
  • moodle: Moodle 연동 모드 활성화 (1 또는 생략)
