# Venn Glow 기능 설명

## 핵심 기능

### 1. 빛나는 벤다이어그램 (Venn Glow)

집합 A와 B를 두 개의 빛나는 원으로 시각화합니다.

**특징:**
- **실시간 펄스 애니메이션**: 원이 살아있는 것처럼 부드럽게 숨쉬듯이 움직입니다
- **그라데이션 글로우**: 각 원 주변에 다층 글로우 효과로 감성적인 분위기 연출
- **색상 구분**: 집합 A는 핑크, 집합 B는 블루로 명확히 구분
- **교집합 강조**: 두 원이 겹치는 영역을 특별한 효과로 강조

### 2. 교집합 애니메이션

교집합 영역을 감성적으로 강조하는 애니메이션입니다.

**특징:**
- **무지개 색상 전환**: 교집합 영역이 여러 색상으로 변하며 아름답게 빛남
- **중심 광점**: 교집합 중심에서 밝은 빛이 발산
- **부드러운 Ease-in-out**: 자연스러운 가속/감속 효과
- **자동 페이드 아웃**: 애니메이션 후 천천히 원래 상태로 복귀

### 3. 스마트폰 뷰포트

우측 하단에 고정된 가상 스마트폰 화면입니다.

**특징:**
- **실제 스마트폰 디자인**: 노치, 베젤, 라운드 코너 등 실제 스마트폰 모양
- **반응형 위치**: 화면 크기에 따라 자동으로 크기와 위치 조정
- **슬라이드 인 애니메이션**: 페이지 로드 시 우측에서 부드럽게 등장
- **드롭 쉐도우**: 입체감 있는 그림자 효과

### 4. Moodle LMS 연동

Moodle 데이터베이스에서 직접 문제를 가져옵니다.

**특징:**
- **실시간 데이터 연동**: Moodle의 question 테이블에서 문제 로드
- **자동 파싱**: 문제 텍스트에서 집합 정보를 자동으로 추출
- **무작위 문제**: 카테고리별로 무작위 문제 선택 가능
- **답안 검증**: 학생 답안을 자동으로 검증

### 5. 인터랙티브 컨트롤

사용자가 직접 조작할 수 있는 다양한 컨트롤을 제공합니다.

**특징:**
- **새 문제 버튼**: 클릭하면 무작위로 새로운 문제 로드
- **샘플 문제 버튼**: 데모용 샘플 문제 로드
- **애니메이션 재생 버튼**: 교집합 애니메이션을 수동으로 재생
- **체크박스 컨트롤**:
  - 합집합 보기 On/Off
  - 교집합 강조 On/Off

## 기술적 특징

### Canvas 기반 렌더링

HTML5 Canvas를 사용하여 부드러운 애니메이션과 효과를 구현합니다.

**장점:**
- 60FPS 부드러운 애니메이션
- GPU 가속 렌더링
- 복잡한 그래픽 효과 가능
- 브라우저 호환성 우수

### 객체지향 설계

코드가 명확하게 모듈화되어 있습니다.

**주요 클래스:**
- `VennGlow`: 벤다이어그램 렌더링 및 애니메이션
- `SmartphoneViewport`: 스마트폰 뷰포트 관리
- `VennGlowApp`: 전체 애플리케이션 로직

### RESTful API

표준 REST API 설계 원칙을 따릅니다.

**특징:**
- JSON 데이터 형식
- 명확한 HTTP 상태 코드
- CORS 지원
- 오류 처리

## 사용자 경험 (UX)

### 시각적 피드백

모든 사용자 액션에 즉각적인 시각적 피드백을 제공합니다.

- **버튼 호버**: 마우스를 올리면 버튼이 살짝 위로 이동
- **버튼 클릭**: 클릭 시 눌리는 효과
- **로딩 상태**: 데이터 로드 중 표시
- **오류 메시지**: 명확한 오류 안내

### 감성적 디자인

교육적이면서도 아름다운 디자인을 추구합니다.

- **그라데이션 배경**: 보라색 계열의 부드러운 그라데이션
- **빛나는 효과**: 모든 요소에 은은한 글로우
- **부드러운 애니메이션**: 급격한 움직임 없이 자연스러운 전환
- **라운드 코너**: 날카롭지 않은 친근한 느낌

### 접근성

다양한 사용자를 위한 접근성을 고려했습니다.

- **키보드 내비게이션**: 마우스 없이도 사용 가능
- **고대비 모드 지원**: 시각 장애인 고려
- **명확한 라벨**: 모든 UI 요소에 명확한 설명
- **터치 지원**: 태블릿 및 모바일 기기 지원

## 교육적 가치

### 시각적 학습

추상적인 집합 개념을 시각적으로 이해할 수 있습니다.

- **구체화**: 추상적인 집합을 구체적인 원으로 표현
- **색상 구분**: 각 집합을 명확히 구분
- **겹침 표현**: 교집합을 직관적으로 이해

### 상호작용 학습

학생이 직접 조작하며 배울 수 있습니다.

- **능동적 참여**: 버튼을 클릭하고 옵션을 변경
- **즉각적 피드백**: 액션에 대한 즉각적인 반응
- **반복 학습**: 여러 문제를 풀며 연습

### 감성 자극

아름다운 애니메이션으로 학습 동기를 부여합니다.

- **흥미 유발**: 화려한 시각 효과로 주의 집중
- **긍정적 경험**: 학습을 즐거운 경험으로 만듦
- **성취감**: 정답 시 화려한 애니메이션으로 보상

## 성능

### 최적화

부드러운 애니메이션을 위한 다양한 최적화가 적용되었습니다.

- **RequestAnimationFrame**: 브라우저 최적화 애니메이션
- **캔버스 리사이징**: Device Pixel Ratio 고려
- **이벤트 디바운싱**: 리사이즈 이벤트 최적화

### 브라우저 호환성

모던 브라우저에서 모두 작동합니다.

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 79+

- HTTPS 권장
