# 기능 상세 설명

## 1. 접선 경사도 색감 표현 (Gradient Color)

### 핵심 개념
함수의 접선 경사도(기울기)를 직관적인 색상으로 표현하여 학생들이 미분의 개념을 시각적으로 이해할 수 있도록 합니다.

### 색상 매핑 알고리즘

#### 1.1 수학적 원리
```
경사도(slope) → 각도(angle) → Hue 값 → HSL 색상

1. 경사도를 각도로 변환:
   angle = arctan(slope) × (180/π)

2. 각도를 0-1로 정규화:
   normalized = (angle + 90) / 180

3. Hue 값 계산 (240 → 0):
   hue = 240 - (normalized × 240)
```

#### 1.2 색상 구간

| 경사도 범위 | 각도 | Hue | 색상 | 의미 |
|------------|------|-----|------|------|
| < -3 | -72° ~ -90° | 216-240 | 진한 파랑 | 매우 급격한 하강 |
| -3 ~ -1 | -45° ~ -72° | 180-216 | 하늘색 | 급격한 하강 |
| -1 ~ -0.3 | -17° ~ -45° | 150-180 | 청록색 | 완만한 하강 |
| -0.3 ~ 0 | -17° ~ 0° | 120-150 | 연두색 | 약간 하강 |
| 0 | 0° | 120 | 초록 | 평평 (극값) |
| 0 ~ 0.3 | 0° ~ 17° | 90-120 | 노랑-초록 | 약간 상승 |
| 0.3 ~ 1 | 17° ~ 45° | 60-90 | 노랑 | 완만한 상승 |
| 1 ~ 3 | 45° ~ 72° | 30-60 | 주황 | 급격한 상승 |
| > 3 | 72° ~ 90° | 0-30 | 빨강 | 매우 급격한 상승 |

#### 1.3 실시간 업데이트
- 슬라이더를 움직이면 즉시 색상 변화
- 애니메이션 모드에서 자동으로 경사도 변화 시각화
- 색상 범례로 현재 경사도 표시

## 3. 그래프 시각화

### 3.1 Canvas 렌더링
```javascript
// 렌더링 파이프라인
clearCanvas()      // 배경 초기화
  ↓
drawGrid()         // 격자 그리기
  ↓
drawAxes()         // 좌표축 그리기
  ↓
drawFunction()     // 함수 곡선 (색상 포함)
  ↓
drawTangentLine()  // 접선 (점선)
  ↓
drawTangentPoint() // 접점 (원)
```

### 3.2 함수 그리기 알고리즘

```javascript
// 200개 세그먼트로 나누어 그리기
for (let x = xMin; x < xMax; x += step) {
  // 각 세그먼트 중간점에서 경사도 계산
  midX = (x1 + x2) / 2
  slope = derivative(midX)

  // 경사도 → 색상 변환
  color = gradientColorMapper.getColor(slope)

  // 해당 색상으로 선 그리기
  drawLine(x1, y1, x2, y2, color)
}
```

이 방식으로 함수 곡선 전체가 그라디언트 색상으로 표현됩니다.

### 3.3 접선 그리기

```javascript
// 접선 방정식: y - y₀ = m(x - x₀)
const x0 = currentX
const y0 = func(x0)
const m = derivative(x0)

// y = mx + b 형태로 변환
const b = y0 - m * x0

// 화면 전체에 걸쳐 그리기
drawLine(xMin, m*xMin + b, xMax, m*xMax + b)
```

## 4. 수학 함수 지원

### 4.1 내장 함수

#### 이차함수 (Quadratic)
```javascript
f(x) = x²
f'(x) = 2x
```
- 가장 기본적인 미분 학습
- 경사도가 선형적으로 증가
- 극값: x = 0 (최솟값)

#### 삼차함수 (Cubic)
```javascript
f(x) = x³ - 2x
f'(x) = 3x² - 2
```
- 변곡점과 극값 학습
- 경사도가 포물선 형태
- 극값: x = ±√(2/3)

#### 사인함수 (Sine)
```javascript
f(x) = sin(x)
f'(x) = cos(x)
```
- 주기 함수의 미분
- 경사도가 주기적으로 변화
- 극값: x = π/2 + nπ

#### 지수함수 (Exponential)
```javascript
f(x) = e^(x/2)
f'(x) = 0.5·e^(x/2)
```
- 항상 증가하는 함수
- 경사도도 지수적으로 증가
- 극값 없음

### 4.2 사용자 정의 함수 (계획)
- JavaScript 표현식 입력
- Math.js 라이브러리로 파싱
- 수치 미분 계산

## 6. Moodle LMS 연동

### 6.1 문제 불러오기
```javascript
// API 호출
POST /api/moodle-connector.php
{
  "action": "get_problem",
  "problem_id": 1  // 선택사항
}

// 응답 처리
→ 함수 타입 설정
→ 접선 위치 설정
→ 그래프 자동 렌더링
```

### 6.2 답안 제출
```javascript
// 학생 답안 전송
POST /api/moodle-connector.php
{
  "action": "submit_answer",
  "problem_id": 1,
  "answer": 4.0,
  "user_id": 123
}

// 즉시 채점
→ 정답 여부 판정
→ 피드백 표시
→ 시도 기록 저장
```

### 6.3 상태 표시
```
● 노랑   - 대기중 (Moodle 미연결)
● 초록   - 연결됨 (문제 로드 완료)
● 빨강   - 오류 (연결 실패)
```

## 7. 교육적 효과

### 7.1 학습 목표
1. **미분의 기하학적 의미 이해**
   - 접선 = 순간 변화율
   - 경사도 = 미분값

2. **시각적 직관 개발**
   - 색상으로 경사도 빠르게 인식
   - 극값 위치 색상으로 확인 (초록색)

3. **함수의 특성 파악**
   - 증가/감소 구간 (색상 패턴)
   - 변곡점 (색상 변화 최대인 지점)

### 7.2 상호작용 학습
- **탐구 학습**: 슬라이더로 자유롭게 탐색
- **즉시 피드백**: 실시간 색상 변화
- **게임화**: Moodle 퀴즈와 연동

## 사용 예시

### 예시 1: 극값 찾기
1. 이차함수 (y = x²) 선택
2. 슬라이더를 좌우로 움직임
3. 초록색 지점 찾기 → x = 0 (극솟값)
4. 경사도가 0임을 확인

### 예시 2: 증가율 비교
1. 지수함수 (y = eˣ/²) 선택
2. x = -2와 x = 2에서 색상 비교
3. 오른쪽이 훨씬 더 빨간색 → 증가율이 더 큼

### 예시 3: 변곡점 찾기
1. 삼차함수 (y = x³ - 2x) 선택
2. 애니메이션 모드 켜기
3. 색상 변화가 가장 급격한 지점 관찰
4. x = 0 근처 (변곡점)
