# ALT42 사용자 가이드

점근선 애니메이션 학습 도구 사용법

## 🎯 주요 기능

### 1. 점근선 Reveal 애니메이션

점근선이 천천히 나타나는 3가지 효과:

1. **선 그리기 효과** (기본)
   - 점근선이 중앙에서 양쪽으로 그려짐
   - 부드러운 ease-in-out 애니메이션
   - 기본 속도: 2초

2. **페이드인 효과**
   - 투명도가 0에서 1로 증가
   - 자연스러운 등장

3. **점선 패턴**
   - 수학 교과서 스타일
   - 명확한 구분

### 2. 대화형 그래프

#### 터치 제스처 (모바일)

- **핀치 줌**: 두 손가락으로 확대/축소
- **팬 (드래그)**: 한 손가락으로 그래프 이동
- **더블 탭**: 점근선 표시/숨기기

#### 마우스 제어 (데스크톱)

- **마우스 휠**: 확대/축소 (향후 추가)
- **드래그**: 그래프 이동 (향후 추가)

### 3. 모바일 최적화

- 우측 하단 가상 스마트폰 화면
- 실제 앱처럼 보이는 디자인
- 터치 친화적 인터페이스

## 🎓 학습 가이드

### 점근선 이해하기

#### 수직 점근선 (Vertical Asymptote)

함수 값이 무한대로 발산하는 x 값

**예시:**
- `f(x) = 1/x` → x = 0
- `f(x) = 1/(x-2)` → x = 2
- `f(x) = 1/(x^2-4)` → x = -2, x = 2

**그래프 특징:**
- 빨간 점선 (수직)
- 그래프가 선에 가까워지지만 닿지 않음

#### 수평 점근선 (Horizontal Asymptote)

x가 무한대로 갈 때 y가 접근하는 값

**예시:**
- `f(x) = 1/x` → y = 0
- `f(x) = (2x+1)/(x+1)` → y = 2
- `f(x) = x/(x^2+1)` → y = 0

**그래프 특징:**
- 빨간 점선 (수평)
- 그래프가 선에 가까워짐

#### 경사 점근선 (Oblique Asymptote)

기울기가 있는 점근선

**예시:**
- `f(x) = (x^2+1)/x` → y = x
- `f(x) = (2x^2+3x)/(x+1)` → y = 2x + 1

## 🔧 설정 옵션

### URL 파라미터

```
# Moodle 퀴즈 문제
http://alt42.local?quiz_id=123

# 커스텀 문제
http://alt42.local?custom_id=5

# 애니메이션 속도 (ms)
http://alt42.local?duration=3000

# 점근선 숨김
http://alt42.local?show_asymptotes=false
```

### 키보드 단축키 (향후 추가)

- **Space**: 애니메이션 재생/일시정지
- **R**: 애니메이션 리셋
- **+/-**: 확대/축소
- **Arrow Keys**: 그래프 이동

## ❓ FAQ

### Q1: 애니메이션이 너무 빠릅니다.

**A:** URL에 `?duration=5000` 추가 (5초)

### Q2: 점근선이 안 보입니다.

**A:** 브라우저 콘솔 확인, API 응답 데이터 확인

### Q3: 모바일에서 터치가 안 됩니다.

**A:** 최신 브라우저 사용, JavaScript 활성화 확인

### Q4: Moodle 연동이 안 됩니다.

**A:**
- DB 권한 확인
- Moodle 버전 확인 (3.7)
- PHP 오류 로그 확인
