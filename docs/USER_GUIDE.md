## 개요

**대안적 풀이(Alternative Solutions)** 활동은 학생들이 문제를 해결할 때 여러 접근 방법을 탐색하도록 유도하는 Moodle 활동 모듈입니다.

### 핵심 개념

- **발산적 사고**: 한 가지 답이 아닌 여러 접근 방법 탐색
- **단계별 분해**: 복잡한 문제를 관리 가능한 단계로 나누기
- **메타인지**: 자신의 사고 과정에 대한 성찰
- **창의적 문제 해결**: 다양한 관점에서 문제 접근

## 교사 가이드

### 활동 생성하기

#### 1단계: 활동 추가

1. 코스 페이지에서 **활동 또는 리소스 추가** 클릭
2. **대안적 풀이** 선택
3. 다음 정보 입력:
   - **활동 이름**: 예) "분수의 덧셈 - 다양한 접근법"
   - **소개**: 활동의 목적과 기대 설명
   - **문제 설명**: 학생들이 해결할 문제

#### 2단계: 설정 구성

**최소 단계 수**
- 학생들이 문제를 몇 개의 단계로 나누어야 하는지
- 권장: 3-5 단계
- 예시:
  - 3단계: 문제 이해 → 풀이 전략 → 실행 및 검증
  - 5단계: 문제 분석 → 정보 정리 → 전략 수립 → 실행 → 검증

**최소 대안 수**
- 각 단계에서 탐색해야 할 최소 대안 접근 방법 수
- 권장: 2-3개
- 너무 많으면 학생 부담, 너무 적으면 효과 감소

#### 3단계: 단계 설정

1. 활동 생성 후 **단계 관리** 클릭
2. 각 단계마다:
   - **단계 제목**: 명확하고 간결하게
   - **단계 설명**: 이 단계에서 무엇을 해야 하는지
   - **힌트**: (선택) 막힐 때 도움이 될 힌트

### 효과적인 문제 설계

#### 좋은 문제의 특징

✅ **다양한 접근 가능**: 한 가지 방법만 있는 문제는 부적합
✅ **적절한 복잡도**: 단계별 분해가 필요한 수준
✅ **현실 맥락**: 학생들이 관련성을 느낄 수 있는 상황
✅ **명확한 목표**: 무엇을 찾아야 하는지 분명함

#### 예시: 분수 문제

**문제**
```
민수는 피자 3/4를 가지고 있고, 지영이는 피자 2/3를 가지고 있습니다.
두 사람이 가진 피자를 합치면 몇 판이 될까요?
```

**단계 설계**
1. **문제 이해하기**
   - 힌트: 주어진 정보와 구해야 할 것을 정리해보세요
2. **전략 세우기**
   - 힌트: 분수를 더하려면 무엇이 같아야 할까요?
3. **계산 실행하기**
   - 힌트: 각 단계의 계산 과정을 명확히 쓰세요
4. **답 검증하기**
   - 힌트: 답이 합리적인지 확인해보세요

### 학생 진행 상황 모니터링

**진행 상황 확인**
- 활동 페이지에서 **학생 진행 상황** 클릭
- 각 학생의 완료 단계 확인
- 탐색한 대안의 수 확인

**피드백 제공**
- 학생이 탐색한 대안 방법 검토
- 성찰 내용 확인
- 개별 피드백 또는 전체 공유

## 학생 가이드

### 활동 시작하기

1. 활동 페이지 접속
2. 문제 설명 읽기
3. **풀이 시작** 버튼 클릭

### 각 단계에서 해야 할 일

#### 1. 대안적 접근 방법 탐색

**최소 2-3개의 다른 방법을 생각해보세요!**

예시: 분수 덧셈 문제
- 대안 1: 통분해서 더하기
- 대안 2: 소수로 변환해서 더하기
- 대안 3: 그림으로 그려서 시각화하기

각 대안마다:
- **설명**: 이 방법이 무엇인지
- **이유**: 왜 이 방법이 효과적일 수 있는지

#### 2. 접근 방법 선택

탐색한 대안 중 **가장 좋다고 생각하는 방법** 선택

선택 기준:
- 가장 이해하기 쉬운가?
- 실수할 가능성이 적은가?
- 시간이 적게 걸리는가?
- 확실하게 답을 구할 수 있는가?

#### 3. 풀이 작성

선택한 방법으로 **단계별로 자세히** 풀이

좋은 풀이의 특징:
- 각 계산 과정 명시
- 이유 설명
- 중간 답 확인

#### 4. 자신감 수준 표시

이 단계의 풀이에 대한 자신감:
- ⭐ 매우 낮음: 잘 모르겠어요
- ⭐⭐ 낮음: 확신이 없어요
- ⭐⭐⭐ 보통: 아마 맞을 거예요
- ⭐⭐⭐⭐ 높음: 거의 확실해요
- ⭐⭐⭐⭐⭐ 매우 높음: 완전히 확신해요

### 성찰 작성하기

모든 단계 완료 후 **성찰** 페이지

#### 질문 1: 어떤 접근이 가장 효과적이었나요?

예시 답변:
```
통분 방법이 가장 효과적이었습니다. 처음에는 소수로 바꾸는 것도
생각했지만, 통분이 더 정확하고 실수가 적었습니다.
```

#### 질문 2: 대안을 탐색하면서 무엇을 배웠나요?

예시 답변:
```
한 문제를 여러 방법으로 풀 수 있다는 것을 알았습니다.
각 방법마다 장단점이 있고, 상황에 따라 더 좋은 방법이
다를 수 있다는 것도 배웠습니다.
```

#### 질문 3: 다시 푼다면 무엇을 바꾸시겠습니까?

예시 답변:
```
처음부터 그림을 그려서 시각적으로 이해한 후에 계산했다면
더 빨리 풀 수 있었을 것 같습니다.
```

### 팁과 전략

💡 **브레인스토밍**: 처음엔 판단하지 말고 떠오르는 모든 방법 적기

💡 **시각화**: 그림, 도표, 다이어그램 활용

💡 **단순화**: 복잡하면 더 간단한 예시로 시작

💡 **역으로 생각**: 답에서 시작해서 거꾸로 가기

💡 **패턴 찾기**: 비슷한 문제를 풀었던 경험 떠올리기

## 교육적 효과

### 21세기 역량 개발

1. **비판적 사고**
   - 여러 접근 방법 비교 분석
   - 최적 전략 선택

2. **창의성**
   - 다양한 관점에서 문제 접근
   - 독창적 해결 방법 발견

3. **메타인지**
   - 자신의 사고 과정 인식
   - 학습 전략 개선

4. **문제 해결 능력**
   - 복잡한 문제 분해
   - 체계적 접근

### 수학적 사고력 향상

- **개념적 이해**: 절차가 아닌 원리 이해
- **유연한 사고**: 상황에 맞는 전략 선택
- **추론 능력**: 방법의 타당성 판단
- **연결성**: 다양한 수학 개념 간 관계 파악

## FAQ

### 학생 질문

**Q: 대안이 정말 2개 이상이어야 하나요?**
A: 네, 최소 요구사항입니다. 다양한 관점에서 생각하는 것이 학습 목표입니다.

**Q: 대안이 모두 완벽해야 하나요?**
A: 아니요. 일부 대안은 작동하지 않을 수도 있습니다. 왜 작동하지 않는지 설명하는 것도 학습입니다.

**Q: 시간이 너무 오래 걸려요.**
A: 처음엔 그럴 수 있지만, 연습하면 빨라집니다. 깊이 생각하는 과정이 중요합니다.

**Q: 답을 틀려도 괜찮나요?**
A: 네, 과정이 더 중요합니다. 여러 방법을 시도하고 반성하는 것 자체가 학습입니다.

### 교사 질문

**Q: 채점은 어떻게 하나요?**
A: 현재는 자동 채점이 없습니다. 교사가 수동으로 검토하며:
  - 대안의 다양성
  - 추론의 질
  - 성찰의 깊이
를 평가합니다.

**Q: 모든 과목에 사용 가능한가요?**
A: 네, 수학뿐 아니라 과학, 공학, 인문학 등 문제 해결이 필요한 모든 분야에 적용 가능합니다.

**Q: 그룹 활동으로 할 수 있나요?**
A: 현재는 개별 활동만 지원합니다. 그룹 협력은 향후 버전에서 지원 예정입니다.
