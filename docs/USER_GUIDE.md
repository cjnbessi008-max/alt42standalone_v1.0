## 교사 가이드

### 시스템 접속

1. Moodle 코스 페이지에서 "Math Self-Grading" 외부 도구를 클릭
2. LTI 인증 후 교사 대시보드로 자동 이동
3. 대시보드에서 전체 통계 및 문제 목록 확인

### 문제 출제하기

#### 1. 새 문제 만들기

1. **대시보드에서 "Create New Problem" 클릭**

2. **기본 정보 입력**
   - **제목**: 문제를 식별할 수 있는 명확한 제목
     - 예: "분수 덧셈 - 피자 조각"

   - **설명** (선택사항): 교사용 메모
     - 예: "3학년 분수 단원 기본 문제"

3. **문제 내용 작성**
   - **문제 지문**: 학생에게 보여질 문제
   - LaTeX 수식 사용 가능
     ```
     예시:
     철수는 피자 \( \frac{1}{2} \)을, 영희는 \( \frac{1}{3} \)을 먹었습니다.
     두 사람이 먹은 피자는 모두 몇 조각일까요?
     ```

4. **정답 입력**
   - 정답을 정확히 입력 (시스템이 자동으로 정규화하여 비교)
   - 예: `5/6` 또는 `0.833`

5. **문제 설정**
   - **문제 유형**: 산술, 대수, 기하, 문장제 등
   - **난이도**: 1~5 (⭐~⭐⭐⭐⭐⭐)
   - **배점**: 기본 10점
   - **제한시간**: 선택사항 (분 단위)

6. **요구사항 설정**
   - ✓ **풀이 과정 필수**: 학생이 풀이 과정을 작성해야 함
   - ✓ **자기평가 필수**: 학생이 검산 근거를 작성해야 함 (권장)
   - ✓ **활성화**: 즉시 학생에게 공개

7. **저장**

#### 2. 문제 관리

**문제 목록에서:**
- **👁 보기**: 문제 상세 보기
- **✏ 편집**: 문제 수정
- **통계 확인**: 제출 수, 정답률, 평균 점수

### 학생 제출물 확인

1. **대시보드에서 문제 선택**
2. **제출 목록 보기**
3. **각 제출물에서 확인 가능한 정보:**
   - 학생 답안
   - 풀이 과정
   - 자기평가 (검산 근거)
   - AI 분석 결과
     - 논리성 점수
     - 완전성 점수
     - 명확성 점수
     - AI 피드백
   - 최종 점수 (답안 70% + 검산 30%)

4. **추가 피드백 작성 (선택사항)**
   - AI 분석에 더해 교사의 코멘트 추가 가능

### 성적 관리

- 모든 성적은 자동으로 Moodle 성적부에 전송됨
- Moodle에서 성적 확인 및 관리
- 필요시 Moodle에서 수동 조정 가능

## 학생 가이드

### 시스템 접속

1. Moodle 코스에서 "Math Self-Grading" 활동 클릭
2. 자동으로 학생 대시보드로 이동
3. 사용 가능한 문제 목록 확인

### 문제 풀기

#### 1. 문제 선택

- **사용 가능한 문제** 섹션에서 원하는 문제 클릭
- 문제 정보 확인:
  - 난이도 (⭐ 개수)
  - 배점
  - 제한시간 (있는 경우)

#### 2. 문제 읽기

- 문제 지문을 꼼꼼히 읽기
- 수식이 있으면 제대로 표시되는지 확인
- 힌트가 있으면 "Show Hints" 클릭

#### 3. 답안 작성

**"Your Answer" 섹션:**
- 최종 답을 명확히 입력
- 예: `5/6`, `0.833`, `x=5`

**"Show Your Work" 섹션** (필수인 경우):
```
예시:
1단계: 두 분수의 분모를 통일합니다.
   1/2 = 3/6
   1/3 = 2/6

2단계: 분자를 더합니다.
   3/6 + 2/6 = 5/6

3단계: 답: 5/6
```

#### 4. 자기평가 작성 (중요! 🌟)

**"Self-Verification (검산 근거)" 섹션:**

이 부분이 이 시스템의 **핵심 기능**입니다!

**무엇을 써야 할까요?**
- **어떻게 답을 확인했는지** 설명
- **왜 답이 맞다고 생각하는지** 근거 제시

**좋은 예시들:**

```
예시 1 (대입 검증):
"제 답 5/6을 확인하기 위해 소수로 바꿔서 계산했습니다.
1/2 = 0.5, 1/3 = 0.333...
0.5 + 0.333 = 0.833
5/6 = 0.833이므로 답이 맞습니다."

예시 2 (역산):
"5/6에서 1/3 (2/6)을 빼면 3/6 (1/2)이 나옵니다.
그리고 5/6에서 1/2 (3/6)을 빼면 2/6 (1/3)이 나옵니다.
따라서 제 계산이 맞습니다."

예시 3 (시각적 확인):
"피자를 6조각으로 나눈 그림을 그려서 확인했습니다.
철수가 3조각, 영희가 2조각을 먹었으므로
총 5조각 = 5/6입니다."

예시 4 (다른 방법으로 재계산):
"다른 방법으로 다시 계산해서 확인했습니다.
1/2 + 1/3
= (3 + 2) / 6
= 5/6
같은 답이 나왔으므로 맞습니다."
```

**나쁜 예시들 (점수가 낮을 수 있음):**

```
❌ "계산기로 확인했습니다."
   → 어떻게 확인했는지 구체적으로 써야 합니다.

❌ "맞는 것 같습니다."
   → 왜 맞다고 생각하는지 근거가 필요합니다.

❌ "다시 계산했더니 같았습니다."
   → 어떤 방법으로 다시 계산했는지 설명해야 합니다.
```

#### 5. 제출

1. **모든 내용 검토**
2. **"Submit Solution" 클릭**
3. **확인 팝업에서 "확인"**

#### 6. 결과 확인

제출 즉시:
- 답안 정확성 (맞음/틀림)
- AI 분석 결과
  - 논리성 점수 (0-100)
  - 완전성 점수 (0-100)
  - 명확성 점수 (0-100)
  - AI 피드백 및 개선 제안
- 최종 점수
  - 답안 정확도: 70%
  - 검산 품질: 30%

## 자기평가 작성 팁

### 좋은 자기평가의 특징

1. **구체적**
   - "확인했습니다" (X)
   - "답을 원래 식에 대입하여 확인했습니다" (O)

2. **논리적**
   - 검증 방법이 수학적으로 타당해야 함
   - 단계적으로 설명

3. **완전함**
   - 검증 과정의 모든 단계 포함
   - 결과까지 명확히 제시

4. **명확함**
   - 다른 사람이 읽고 이해할 수 있어야 함
   - 수식과 설명을 함께 사용

### 검산 방법 종류

#### 1. **역산 (Inverse Operation)**
```
나눗셈 → 곱셈으로 확인
뺄셈 → 덧셈으로 확인
제곱근 → 제곱으로 확인
```

#### 2. **대입 (Substitution)**
```
방정식의 해를 원래 식에 대입
등식의 양변이 같은지 확인
```

#### 3. **다른 방법으로 재계산**
```
다른 풀이법 사용
다른 접근 방식 시도
```

#### 4. **어림 (Estimation)**
```
답의 크기가 예상 범위 안인지 확인
대략적인 값과 비교
```

#### 5. **시각화**
```
그림이나 도표로 확인
구체적인 예시로 검증
```

### AI는 무엇을 평가할까?

**논리성 (Logic):**
- 검증 방법이 수학적으로 타당한가?
- 추론 과정이 올바른가?

**완전성 (Completeness):**
- 모든 필요한 검증 단계를 포함했는가?
- 결과까지 명확히 제시했는가?

**명확성 (Clarity):**
- 설명이 이해하기 쉬운가?
- 용어를 올바르게 사용했는가?

## FAQ

### 학생 FAQ

**Q: 답은 맞는데 검산 점수가 낮아요.**
A: 답안 정확도는 70%, 검산 품질은 30%를 차지합니다. 검산 근거를 더 구체적이고 논리적으로 작성해보세요.

**Q: 어떻게 써야 높은 점수를 받나요?**
A:
1. 구체적인 검증 방법 설명
2. 단계별로 어떻게 확인했는지 기술
3. 왜 답이 맞다고 확신하는지 근거 제시

**Q: 시간 제한이 있나요?**
A: 문제에 따라 다릅니다. 문제 상단에 시간 제한이 표시됩니다.

**Q: 여러 번 제출할 수 있나요?**
A: 각 문제당 1회 제출이 원칙입니다. 신중히 작성 후 제출하세요.

**Q: 초안을 저장할 수 있나요?**
A: "Save as Draft" 버튼으로 임시 저장 가능합니다.

**Q: AI 피드백을 꼭 따라야 하나요?**
A: AI 피드백은 참고용입니다. 다음 문제에서 더 나은 검산을 작성하는 데 활용하세요.

### 교사 FAQ

**Q: AI 없이도 사용할 수 있나요?**
A: 네, `config.php`에서 `AI_ENABLED = false`로 설정하면 수동 채점 모드로 동작합니다.

**Q: 채점 비율을 변경할 수 있나요?**
A: 네, `config.php`에서 `ANSWER_WEIGHT`와 `VERIFICATION_WEIGHT`를 수정하세요.

**Q: 학생의 검산을 수동으로 재평가할 수 있나요?**
A: 현재는 AI 자동 평가만 지원됩니다. 추가 피드백은 작성 가능합니다.

**Q: 문제에 이미지를 넣을 수 있나요?**
A: 현재 버전에서는 텍스트와 LaTeX 수식만 지원합니다.

**Q: 성적이 Moodle에 안 들어가요.**
A: Moodle 외부 도구 설정에서 "성적을 도구에서 받아옴" 옵션이 체크되어 있는지 확인하세요.
