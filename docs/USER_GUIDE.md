## 교사용 가이드

### 활동 생성하기

#### 1. 코스에 활동 추가

1. 코스 페이지로 이동
2. **편집 모드 켜기** 클릭
3. 원하는 섹션에서 **활동 또는 리소스 추가** 클릭
4. **Overlap Field** 선택
5. **추가** 클릭

#### 2. 활동 설정

##### 기본 정보
- **활동명**: 학생에게 표시될 활동 이름
  - 예: "연립부등식의 영역", "부등식 시스템 1"

- **소개**: 활동에 대한 설명
  - 예: "다음 연립부등식의 교집합을 관찰하고 특징을 기술하세요."

##### 부등식 입력

**한 줄에 하나의 부등식**을 입력합니다:

```
y > 2*x + 1
y < -x + 5
x > -3
x < 4
```

**지원되는 형식**:
- 선형 부등식: `y > 2*x + 1`
- 수평선: `y < 3`
- 수직선: `x > -2`
- 원: `x*x + y*y < 16`
- 절댓값: `y > abs(x)`

##### 시각화 설정 (고급)

JSON 형식으로 시각화 옵션을 설정할 수 있습니다:

```json
{
  "xMin": -5,
  "xMax": 5,
  "yMin": -5,
  "yMax": 5,
  "gridSize": 100,
  "showGrid": true,
  "showAxes": true,
  "colorIntensity": 0.7
}
```

**옵션 설명**:
- `xMin`, `xMax`: X축 범위
- `yMin`, `yMax`: Y축 범위
- `gridSize`: 격자 밀도 (50-200, 높을수록 정밀)
- `showGrid`: 격자 표시 여부
- `showAxes`: 좌표축 표시 여부
- `colorIntensity`: 색상 강도 (0.3-1.0)

#### 3. 저장 및 공개

- **저장하고 코스로 돌아가기**: 활동 저장 후 코스로
- **저장하고 표시**: 활동 저장 후 미리보기

### 학생 답안 확인

1. 활동 페이지로 이동
2. **참여자** 또는 **응답 보기** 클릭
3. 각 학생의 시도 기록 확인:
   - 시도 횟수
   - 소요 시간
   - 정답 여부 (설정 시)
   - 점수 (설정 시)

### 평가 설정

활동을 평가 항목으로 사용하려면:

1. 활동 설정 편집
2. **평가** 섹션에서:
   - 평가 유형: 척도 또는 점수
   - 최대 점수: 100
3. 저장

## 학생용 가이드

### 활동 참여하기

#### 1. 활동 열기

1. 코스 페이지에서 Overlap Field 활동 클릭
2. 활동 소개 및 문제 확인

#### 2. 시각화 관찰

**화면 구성**:

```
┌─────────────────────────────────────┐
│ Overlap Field                       │  ← 앱 헤더
│ 연립부등식 문제                     │
├─────────────────────────────────────┤
│ 주어진 부등식                       │
│ 1. y > 2·x + 1                      │  ← 부등식 목록
│ 2. y < -x + 5                       │
│ 3. x > -3                           │
├─────────────────────────────────────┤
│                                     │
│        [시각화 영역]                │  ← Canvas 그래프
│                                     │
├─────────────────────────────────────┤
│ 격자 밀도: [슬라이더]               │  ← 컨트롤
│ 색상 강도: [슬라이더]               │
│ [초기화] [애니메이션]               │
├─────────────────────────────────────┤
│ 범례                                │
│ ■ 부등식 1  ■ 부등식 2              │  ← 범례
└─────────────────────────────────────┘
```

#### 3. 인터랙션 기능

##### 부등식 하이라이트
- 부등식 항목 클릭 시 해당 영역 강조 표시

##### 격자 밀도 조절
- 슬라이더를 움직여 시각화 정밀도 조절
- 낮은 값: 빠른 렌더링, 낮은 정밀도
- 높은 값: 느린 렌더링, 높은 정밀도

##### 색상 강도 조절
- 슬라이더를 움직여 색상 투명도 조절
- 낮은 값: 투명한 색상
- 높은 값: 진한 색상

##### 초기화 버튼
- 모든 설정을 기본값으로 되돌림

##### 애니메이션 버튼
- 색상이 부드럽게 변하는 애니메이션 효과
- 다시 클릭하여 정지

#### 4. 관찰 및 분석

**확인할 사항**:

1. **교집합 영역**
   - 가장 진한 색 부분이 모든 부등식을 만족하는 영역

2. **경계선**
   - 각 부등식의 경계선이 색깔별로 표시됨
   - `>`, `<`: 경계선 미포함 (점선)
   - `≥`, `≤`: 경계선 포함 (실선)

3. **색상 계층**
   - 연한 색: 1-2개 부등식 만족
   - 중간 색: 3-4개 부등식 만족
   - 진한 색: 5개 이상 부등식 만족

#### 5. 답안 제출 (활동 설정에 따라)

1. 시각화를 충분히 관찰
2. 답안 작성 (문제에 따라):
   - 교집합 영역의 특징 기술
   - 특정 점이 영역에 포함되는지 판단
   - 영역의 넓이 추정
3. **제출** 버튼 클릭

## 부등식 작성 규칙

### 기본 형식

```
[좌변] [연산자] [우변]
```

**연산자**:
- `>`: 초과
- `<`: 미만
- `>=`: 이상
- `<=`: 이하
- `=`: 같음 (경계선만 표시)

### 변수 및 연산

**변수**: `x`, `y`

**사칙연산**:
- 덧셈: `+`
- 뺄셈: `-`
- 곱셈: `*` (필수!)
- 나눗셈: `/`

⚠️ **주의**: 곱셈 기호 `*` 생략 불가
- ✅ 올바름: `2*x + 3`
- ❌ 잘못됨: `2x + 3`

### 예제

#### 선형 부등식
```
y > 2*x + 1          # y가 2x + 1보다 큼
y <= -3*x + 5        # y가 -3x + 5 이하
```

#### 수평선/수직선
```
y < 3                # y가 3 미만
x >= -2              # x가 -2 이상
```

#### 원 및 타원
```
x*x + y*y < 16       # 반지름 4인 원 내부
x*x/9 + y*y/4 < 1    # 타원 내부
```

#### 절댓값
```
y > abs(x)           # y가 |x|보다 큼
y < abs(x - 2) + 1   # 절댓값 함수 이동
```

#### 복잡한 식
```
y > x*x - 4          # 포물선 위쪽
y < sqrt(16 - x*x)   # 반원 아래쪽 (x²+y²=16)
```

### 주의사항

1. **공백은 무시됨**: `y>2*x+1`과 `y > 2*x + 1` 동일
2. **대소문자 구분**: 변수는 소문자 `x`, `y`만 사용
3. **괄호 사용 가능**: `y > (2*x + 1) / 3`
4. **함수 지원**:
   - `abs(x)`: 절댓값
   - `sqrt(x)`: 제곱근
   - `pow(x, 2)`: 거듭제곱

## 시각화 해석

### 색상 의미

#### 단일 영역
![단일 영역](images/single-region.png)

연한 색상 → 하나의 부등식만 만족

#### 이중 교집합
![이중 교집합](images/double-overlap.png)

중간 색상 → 두 부등식 만족

#### 완전 교집합
![완전 교집합](images/full-overlap.png)

진한 색상 → 모든 부등식 만족

### 경계선 해석

- **실선**: 부등식에 `=` 포함 (`≥`, `≤`)
- **점선**: 부등식에 `=` 미포함 (`>`, `<`)

예시:
```
y >= 2*x + 1    → 경계선 포함 (실선)
y > 2*x + 1     → 경계선 미포함 (점선)
```

### 영역 판단

특정 점 `(a, b)`가 교집합에 포함되는지 확인:

1. 시각화에서 해당 좌표 찾기
2. 색상 확인:
   - 진한 색 → 모든 부등식 만족 → 교집합에 포함
   - 연한 색 또는 흰색 → 일부 부등식 불만족 → 미포함

## 예제 문제

### 예제 1: 기본 선형 부등식

**문제**:
```
y > x + 1
y < -x + 5
y > 0
```

**분석**:
- 세 직선으로 둘러싸인 삼각형 영역
- 꼭짓점: 대략 `(2, 3)`, `(-1, 0)`, `(5, 0)` 근처

**질문**:
1. 점 `(1, 2)`는 교집합에 포함되는가?
   - `2 > 1 + 1 = 2` ❌ → 미포함

2. 점 `(2, 3)`은 교집합에 포함되는가?
   - `3 > 2 + 1 = 3` ❌ (경계) → 경계 제외 시 미포함

### 예제 2: 사각형 영역

**문제**:
```
x > -3
x < 4
y > -2
y < 3
```

**분석**:
- 사각형 영역
- 너비: `4 - (-3) = 7`
- 높이: `3 - (-2) = 5`
- 넓이: `7 × 5 = 35`

### 예제 3: 원형 영역

**문제**:
```
x*x + y*y < 16
x > 0
y > 0
```

**분석**:
- 반지름 4인 원의 1사분면 부분
- 중심: `(0, 0)`
- 넓이: `π × 4² / 4 ≈ 12.57`

### 예제 4: 복잡한 영역

**문제**:
```
y > x*x - 4
y < -x*x + 4
x > -2
x < 2
```

**분석**:
- 두 포물선 사이 영역
- 대칭 구조 (y축 대칭)
- `x = 0`에서 최대 높이 8

## 팁과 요령

### 교사용 팁

1. **단계적 학습**
   - 먼저 2-3개의 간단한 부등식으로 시작
   - 점진적으로 복잡도 증가

2. **시각적 질문**
   - "가장 진한 부분은 어디인가?"
   - "경계선은 몇 개인가?"
   - "영역은 유계인가 무계인가?"

3. **실생활 연계**
   - 예산 제약 문제
   - 시간 및 자원 최적화
   - 물리적 제약 조건

### 학생용 팁

1. **체계적 관찰**
   - 먼저 각 부등식을 개별적으로 이해
   - 그 다음 교집합 영역 찾기

2. **검증**
   - 특정 점을 선택하여 모든 부등식에 대입
   - 시각화 결과와 일치하는지 확인

3. **격자 밀도 활용**
   - 전체 구조 파악: 낮은 밀도
   - 세부 관찰: 높은 밀도

4. **애니메이션 활용**
   - 경계가 모호한 경우 애니메이션으로 확인

## 자주 묻는 질문 (FAQ)

**Q: 부등식이 너무 많으면 느려지나요?**
A: 네, 5개 이상의 부등식은 렌더링이 느릴 수 있습니다. 격자 밀도를 낮추면 개선됩니다.

**Q: 모바일에서도 사용할 수 있나요?**
A: 네, 반응형 디자인으로 모바일 브라우저에서도 작동합니다.

**Q: 경계선이 정확하지 않은 것 같아요.**
A: 격자 밀도를 높이면 더 정밀한 경계선을 볼 수 있습니다.

**Q: 3차원 부등식도 가능한가요?**
A: 현재 버전은 2차원만 지원합니다.

**Q: 색상을 변경할 수 있나요?**
A: 현재는 미리 정의된 색상만 사용합니다. 향후 업데이트에서 지원 예정입니다.
