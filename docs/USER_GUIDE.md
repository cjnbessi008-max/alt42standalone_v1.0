# Dot Collector - 사용자 가이드

## 소개

**Dot Collector**는 부분 넓이 개념을 시각화하여 학습하는 교육용 웹 애플리케이션입니다. 학생들은 도트(점)를 사용하여 도형의 넓이를 누적하며 넓이의 개념을 직관적으로 이해할 수 있습니다.

## 주요 기능

### 1. 가상 스마트폰 화면
- 우측 하단에 스마트폰 형태의 인터페이스로 표시
- 모바일 친화적인 디자인
- 터치 및 마우스 클릭 지원

### 2. 도트 누적 시스템
- 캔버스에 도트를 클릭하여 배치
- 각 도트는 설정한 값만큼 넓이를 누적
- 실시간으로 누적 넓이 표시
- 시각적 피드백 (색상 구분)

### 3. 다양한 도형 지원
- 직사각형
- 삼각형
- 원
- 기타 다각형

### 4. 학습 진행 추적
- 점수 시스템
- 진행도 표시
- 정답/오답 피드백

## 사용 방법

### 학생용

#### 1단계: 활동 시작
1. Moodle 코스에서 Dot Collector 활동을 클릭합니다
2. 화면 우측 하단에 가상 스마트폰이 나타납니다
3. 첫 번째 문제가 자동으로 로드됩니다

#### 2단계: 문제 이해
- 문제 텍스트를 읽고 주어진 도형을 확인합니다
- 도형의 치수 (가로, 세로, 반지름 등)를 파악합니다
- 넓이 공식을 떠올립니다

#### 3단계: 도트로 넓이 표시

**도트 추가하기:**
1. 캔버스의 원하는 위치를 클릭합니다
2. 도트가 그리드에 맞춰 배치됩니다
3. 누적 넓이가 자동으로 업데이트됩니다

**도트 값 조정:**
- "도트 값" 입력란에서 각 도트가 나타내는 넓이를 설정합니다
- 예: 1cm², 0.5cm², 2cm² 등

**도트 제거:**
- "- 도트 제거" 버튼: 마지막 도트 삭제
- 기존 도트를 다시 클릭: 해당 도트 삭제
- "초기화" 버튼: 모든 도트 삭제

#### 4단계: 답안 제출
1. 누적된 넓이를 확인합니다
2. "최종 답" 입력란에 답을 입력합니다 (자동으로 누적 넓이가 입력됨)
3. "답안 제출" 버튼을 클릭합니다

#### 5단계: 피드백 확인
- **정답**: 축하 메시지와 함께 다음 문제로 진행
- **오답**: 정답과 함께 설명 제공, 다시 도전 가능

#### 6단계: 다음 문제
- "다음 문제" 버튼을 클릭하여 계속 학습합니다

### 교사용

#### 활동 생성
1. 코스 편집 모드를 활성화합니다
2. "활동 또는 리소스 추가"를 클릭합니다
3. "Dot Collector"를 선택합니다
4. 활동 이름과 설명을 입력합니다
5. 저장합니다

#### 학생 진행 상황 모니터링
```sql
-- 학생별 진행 상황 조회
SELECT
    u.firstname,
    u.lastname,
    COUNT(*) as total_attempts,
    SUM(sa.is_correct) as correct_answers,
    AVG(sa.time_spent_seconds) as avg_time
FROM student_attempts sa
JOIN mdl_user u ON sa.moodle_user_id = u.id
GROUP BY sa.moodle_user_id;
```

## 팁과 전략

### 효과적인 학습 전략

**1. 작은 단위로 시작**
- 처음에는 도트 값을 작게 설정 (0.5 또는 1)
- 정확한 넓이를 표현하기 위해 여러 도트 사용

**2. 패턴 인식**
- 도형의 대칭성을 활용
- 반복되는 패턴을 찾아 도트 배치

**3. 검산**
- 공식으로 계산한 값과 도트로 누적한 값 비교
- 차이가 있다면 도트 배치 재확인

**4. 시각화 연습**
- 도트를 배치하며 넓이의 개념을 시각적으로 이해
- 부분과 전체의 관계 파악

## 자주 묻는 질문 (FAQ)

### Q1: 도트를 잘못 배치했어요. 어떻게 수정하나요?
**A**: 잘못 배치한 도트를 다시 클릭하면 삭제됩니다. 또는 "- 도트 제거" 버튼으로 마지막 도트를 제거할 수 있습니다.

### Q2: 누적 넓이가 정답과 다른데 왜 그런가요?
**A**: 도트 값을 확인해보세요. 각 도트의 값과 개수를 곱한 것이 누적 넓이입니다.

### Q3: 문제가 너무 어려워요.
**A**: 작은 도트 값 (0.1, 0.5 등)을 사용하여 더 정확하게 넓이를 표현해보세요.

### Q4: 앱이 로드되지 않아요.
**A**:
- 페이지를 새로고침하세요
- 브라우저 캐시를 삭제하세요
- 다른 브라우저를 사용해보세요
- 교사나 관리자에게 문의하세요

### Q5: 모바일에서도 사용할 수 있나요?
**A**: 네, 터치 입력을 지원하여 태블릿과 스마트폰에서도 사용 가능합니다.

## 학습 목표

Dot Collector를 통해 학생들은:

1. **넓이 개념 이해**: 넓이가 단위 면적의 누적임을 시각적으로 학습
2. **공식 적용**: 도형별 넓이 공식을 실제로 적용
3. **추정 능력**: 대략적인 넓이를 추정하는 능력 향상
4. **정확성**: 정밀한 계산을 통한 정확한 답 도출
5. **자기 주도 학습**: 시행착오를 통한 능동적 학습
