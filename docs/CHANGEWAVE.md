# Change Wave 기능 명세서

## 개요

**Change Wave**는 수학 함수의 변화 패턴을 파동(wave)처럼 시각화하여, 학습자가 함수의 동적 변화를 직관적으로 이해할 수 있도록 돕는 교육용 웹 애플리케이션입니다.

### 핵심 개념

- **파동(Wave)**: 함수의 x값이 변할 때 y값의 변화를 시간에 따라 애니메이션으로 표현
- **변화율(Derivative)**: 각 지점에서의 함수 변화율(미분값)을 접선으로 시각화
- **실시간 추적**: 현재 x, y, 변화율 값을 실시간으로 표시

## 주요 기능

### 1. 함수 시각화

#### Canvas 기반 렌더링

- **좌표계**: 수학 좌표를 Canvas 픽셀 좌표로 변환
- **그리드**: 동적 그리드 라인 생성
- **축**: X축, Y축 표시
- **함수 곡선**: 전체 함수 그래프를 반투명하게 표시

#### 파동 애니메이션

```javascript
// 파동 데이터 구조
{
    x: 현재_x값,
    y: f(x),
    derivative: f'(x)
}
```

- **파동 궤적**: 함수 곡선을 따라 이동하는 두꺼운 선
- **현재 포인트**: 파동의 선두를 나타내는 원
- **펄스 효과**: 포인트 주변의 링 애니메이션
- **접선**: 현재 지점의 변화율을 나타내는 직선

### 2. 변화율 계산

#### 수치 미분

```javascript
f'(x) ≈ [f(x + h) - f(x - h)] / (2h)
```

- **h 값**: 0.001 (정밀도와 성능의 균형)
- **중앙 차분법**: 오차 감소를 위한 수치 미분 방식

#### 변화율 시각화

- **색상**: 청록색(#20c997)
- **길이**: 고정 길이(60px)로 방향만 표시
- **업데이트**: 매 프레임마다 재계산

### 3. 인터랙티브 컨트롤

#### 재생 컨트롤

| 버튼 | 기능 | 단축키 |
|------|------|--------|
| ▶ 재생 | 파동 애니메이션 시작 | Space |
| ⏸ 일시정지 | 애니메이션 멈춤 | Space |
| ↻ 리셋 | 초기 상태로 복귀 | R |

#### 속도 조절

- **범위**: 0.1x ~ 3.0x
- **기본값**: 1.0x
- **단계**: 0.1x 간격
- **실시간 적용**: 슬라이더 조작 즉시 반영

### 주요 테이블

#### 1. changewave_problems

문제 정보를 저장합니다.

**주요 필드**:
- `function_expr`: JavaScript로 평가 가능한 함수 표현식
- `x_min`, `x_max`, `y_min`, `y_max`: 좌표계 범위
- `moodle_quiz_id`: Moodle 퀴즈와 연동

#### 2. changewave_learning_logs

학습 활동을 기록합니다.

**주요 필드**:
- `play_count`, `pause_count`, `reset_count`: 인터랙션 추적
- `duration`: 총 학습 시간
- `score`: 학습 성과

#### 3. changewave_user_progress

사용자별 진도를 관리합니다.

**상태 값**:
- `not_started`: 미시작
- `in_progress`: 학습 중
- `completed`: 완료

## 지원 함수

### 기본 함수

| 카테고리 | 함수 예시 | JavaScript 표현식 |
|----------|-----------|-------------------|
| 일차함수 | f(x) = 2x + 1 | `2 * x + 1` |
| 이차함수 | f(x) = x² | `x * x` |
| 삼차함수 | f(x) = x³ - 3x | `x * x * x - 3 * x` |
| 절댓값 | f(x) = \|x\| | `abs(x)` |

### 삼각함수

| 함수 | JavaScript 표현식 |
|------|-------------------|
| sin(x) | `sin(x)` |
| cos(x) | `cos(x)` |
| tan(x) | `tan(x)` |

### 지수/로그 함수

| 함수 | JavaScript 표현식 |
|------|-------------------|
| 2^x | `pow(2, x)` |
| e^x | `exp(x)` |
| ln(x) | `log(x)` |
| log₁₀(x) | `log10(x)` |

### Math 객체 함수

모든 JavaScript Math 객체 함수를 사용할 수 있습니다:
- `sqrt(x)`: 제곱근
- `abs(x)`: 절댓값
- `floor(x)`, `ceil(x)`, `round(x)`: 반올림
- `min(a, b)`, `max(a, b)`: 최소/최대

## 성능 최적화

### 렌더링 최적화

- **requestAnimationFrame**: 브라우저 리페인트에 동기화
- **부분 렌더링**: 변경된 영역만 다시 그리기 (향후 개선)
- **Canvas 해상도**: 고정 해상도로 GPU 가속 활용

### 데이터 최적화

- **파동 길이 제한**: 최대 100개 포인트로 제한
- **샘플링 간격**: 0.1 단위로 함수 곡선 샘플링
- **메모리 관리**: 오래된 파동 데이터 자동 제거

### 네트워크 최적화

- **문제 캐싱**: 한 번 로드한 문제 정보 캐싱
- **지연 로딩**: 필요한 시점에만 API 호출
- **샘플 데이터**: DB 연결 실패 시 로컬 샘플 사용

## 보안 고려사항

### 함수 표현식 평가

- **샌드박싱**: Function 생성자로 격리된 환경에서 평가
- **입력 검증**: 허용된 Math 함수만 사용
- **오류 처리**: try-catch로 악의적 코드 차단

### SQL 인젝션 방지

- **Prepared Statements**: 모든 쿼리에 바인딩 파라미터 사용
- **입력 검증**: `real_escape_string` 추가 적용
- **최소 권한**: DB 사용자 권한 제한

### XSS 방지

- **출력 이스케이프**: 사용자 입력 HTML 렌더링 시 이스케이프
- **Content Security Policy**: 인라인 스크립트 제한
- **입력 필터링**: HTML 태그 제거

## 문제 해결 가이드

### 일반적인 문제

#### 1. 파동이 표시되지 않음

**원인**:
- Canvas 초기화 실패
- JavaScript 오류

**해결**:
- 브라우저 콘솔 확인
- Canvas 지원 브라우저 사용

#### 2. Moodle 연동 실패

**원인**:
- DB 연결 정보 오류
- 네트워크 문제

**해결**:
- `api/config.php` 설정 확인
- DB 서버 상태 확인
- 샘플 데이터로 테스트

#### 3. 느린 애니메이션

**원인**:
- 복잡한 함수
- 저사양 디바이스

**해결**:
- 속도 낮춤
- 샘플링 간격 증가
- 파동 길이 제한 감소
