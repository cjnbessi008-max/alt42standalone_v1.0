# 수학사 여정 게임 - Game Design Document (GDD)

## 📋 프로젝트 개요

### 프로젝트명
**수학사 여정: 수의 문명을 찾아서** (Math History Journey: Quest for Numerical Civilizations)

### 장르
교육용 RPG / 역사 탐험 게임

### 타겟
- 중학생 ~ 고등학생 (13-18세)
- 수학에 흥미를 가진 학습자
- 역사와 스토리를 좋아하는 학생

### 핵심 컨셉
17개의 수학 영역을 역사적 시대별로 여행하며, 각 시대의 수학적 발견을 직접 체험하고 "영역을 정복"해 나가는 몰입형 학습 게임

---

## 🎮 게임 구조

### 전체 여정 구조

```
고대 → 중세 → 근대 → 현대
  │      │      │      │
  └──────┴──────┴──────┴── 17개 영역 (Chapters)
```

**17개 영역 (Chapters)**:
1. 수체계 (수의 역사)
2. 지수와 로그
3. 수열
4. 식의 계산
5. 집합과 명제
6. 방정식
7. 부등식
8. 함수
9. 미분
10. 적분
11. 평면도형
12. 평면좌표
13. 입체도형
14. 공간좌표
15. 벡터
16. 경우의 수·확률
17. 통계

### 게임 진행 방식

1. **선형 진행**: 1번부터 17번까지 순차적으로 진행
2. **장면 기반**: 각 영역은 3-7개의 "장면(Scene)"으로 구성
3. **인터랙티브 체험**: 각 장면은 퍼즐, 미니게임, 시뮬레이션 등의 인터랙션 포함
4. **서사 연결**: 장면 사이에 시대감 있는 문투의 스토리 텍스트로 연결

## 🎭 핵심 시스템

### 1. 시대감 있는 문투 시스템

각 시대별로 다른 문투를 사용하여 몰입도 극대화:

**고대 (메소포타미아, 이집트, 그리스)**
```
"그 밤, 별은 고요히 숨을 고르고 있었도다."
"저잣거리의 상인들은 서둘러 덧셈을 마치려 애썼다."
"현자는 모래 위에 도형을 그리며 깊은 사색에 잠겼노라."
```

**중세 (인도, 아랍)**
```
"숫자의 비밀이 실크로드를 따라 흘러갔다."
"학자들은 별을 관측하며 새로운 계산법을 고안했다."
```

**근대 (르네상스)**
```
"이 계산이 옳지 않다면, 내일의 장부는 무너질 터였다."
"금지된 수에 대한 논쟁이 광장을 뜨겁게 달궜다."
```

**현대**
```
"수학은 더 이상 숫자가 아니라, 구조와 패턴의 학문이 되었다."
```

### 2. 능력치 시스템

학습 스탯이 아닌, **캐릭터의 성향**을 나타내는 능력치:

```typescript
interface PlayerStats {
  creativity: number;    // 창의성: 독특한 방식으로 문제 해결
  intuition: number;     // 직관: 힌트 최소 사용, 빠른 이해
  persistence: number;   // 집착: 반복 시도, 완벽 추구
  logic: number;         // 논리: 체계적 접근
  imagination: number;   // 상상력: 추상적 개념 수용
}
```

**능력치 변화 방식**:
- 장면 클리어 방식에 따라 1-3포인트 조정
- 예시:
  - 창의성 +1: 독특한 방식으로 퍼즐 해결
  - 직관 +1: 힌트 없이 빠르게 해결
  - 집착 +1: 여러 번 반복해서 정확히 맞춤
  - 논리 +2: 체계적으로 단계별 해결
  - 상상력 +1: 추상 개념 수용 (0, 음수, 허수 등)

### 3. 카드 앨범 시스템

각 장면 클리어 시 **카드** 획득:

```typescript
interface Card {
  id: string;
  title: string;           // 예: "0의 탄생"
  era: string;             // 예: "인도, 6세기"
  description: string;     // 역사적 설명
  mathematician?: string;  // 관련 수학자
  visual: string;          // 카드 이미지 URL
  statsGained: Partial<PlayerStats>; // 획득한 능력치
}
```

**카드 앨범 UI**:
- 시대별로 분류된 카드 컬렉션
- 각 카드에 "나의 여정" 메모 (어떻게 클리어했는지)
- 능력치 성향 그래프 (레이더 차트)

### 4. 장면 전환 연출

**장면 종료 → 다음 장면 전환**:

1. **페이드 아웃**: 현재 장면이 서서히 어두워짐
2. **카드 획득 애니메이션**: 새 카드가 빛나며 등장
3. **능력치 업데이트**: "+창의성 1" 등의 알림
4. **전환 텍스트**: 시대감 있는 문투
   ```
   "그리하여, 그는 또 다른 땅을 향해 발걸음을 옮겼노라."
   "그러나 세상은 아직 더 큰 진실을 감추고 있었다."
   ```
5. **능력치 반영 대사**: 능력치에 따라 미묘하게 변형
   - 직관↑: "그대의 눈은 이미 사물의 본질을 포착하고 있도다."
   - 집착↑: "그대는 답을 찾고자 한순간도 망설임이 없구나."
6. **페이드 인**: 다음 장면 시작

## 📚 Chapter 1: 수체계 (수의 역사) - 상세 설계

### 장면 구성 (7개 Scene)

#### Scene 1: 메소포타미아 - 점토판의 기록
**시대**: 기원전 2000년, 바빌로니아
**배경**: 별이 총총한 밤, 진흙 벽돌 건물 앞

**내러티브**:
```
"그 밤, 별은 고요히 숨을 고르고 있었도다.

티그리스 강가의 저잣거리에서는 상인들이 분주히 움직이고 있었다.
곡식의 양을 세고, 거래의 기록을 남겨야 했다.

그들은 갈대로 만든 첨필을 들고, 축축한 점토판에 쐐기 모양을 새겨 넣었다.

이것이 인류 최초의 수학, 그 시작이었도다."
```

**인터랙션**: 점토판에 쐐기문자 숫자 새기기
- 60진법 체계 체험
- 드래그하여 쐐기 모양 그리기
- 목표: 숫자 "270"을 60진법으로 표현하기

**퍼즐 메커니즘**:
```
1. 화면에 빈 점토판이 나타남
2. 오른쪽에 60진법 기호 팔레트:
   - V 모양 (1을 의미)
   - < 모양 (10을 의미)
   - 특수 기호 (60을 의미)
3. 사용자는 드래그하여 기호를 배치
4. 정답: 4×60 + 30 = 270
   → 60 기호 4개 + 10 기호 3개
```

**클리어 조건**:
- 정답 도출: 기본 클리어
- 힌트 없이 해결: 직관 +1
- 3회 이내 성공: 논리 +1

**획득 카드**: "점토판의 기록자"

---

#### Scene 2: 이집트 - 단위분수의 비밀
**시대**: 기원전 1650년, 이집트
**배경**: 나일강변, 피라미드가 보이는 서기관의 방

**내러티브**:
```
"나일강은 해마다 범람하여 땅의 경계를 지워버렸다.

서기관 아메스는 두루마리 파피루스를 펼쳐 들었다.
땅을 다시 나누어야 했다. 3개의 땅을 4명에게 공평하게.

하나, 이집트에서는 분수를 오직 '단위분수'로만 표현할 수 있었다.
3/4는 1/2 + 1/4로 써야 했다.

"이것이 우리의 방식이니라."
```

**인터랙션**: 분수를 단위분수 합으로 분해하기
- 시각적 도구: 원형 파이 차트
- 목표: 2/3, 3/4, 5/6을 단위분수 합으로 표현

**퍼즐 메커니즘**:
```
1. 화면에 원형 파이가 나타남
2. 목표 분수(예: 3/4)가 표시됨
3. 사용자는 단위분수 조각을 선택하여 합침:
   - 1/2 선택 → 원의 절반이 채워짐
   - 1/4 선택 → 원의 1/4이 추가로 채워짐
   - 합: 3/4 완성!
4. 다음 문제로 진행
```

**클리어 조건**:
- 3개 문제 모두 해결: 기본 클리어
- 최소 조각 수로 해결: 창의성 +1
- 힌트 없이 해결: 직관 +1

**획득 카드**: "나일강의 서기관"

---

#### Scene 3: 그리스 - 무리수의 발견과 공포
**시대**: 기원전 500년, 그리스 해변
**배경**: 피타고라스 학파의 비밀 집회

**내러티브**:
```
"모든 것은 수라고, 그들은 믿었도다.

피타고라스 학파의 현자들은 정사각형의 대각선을 측정하려 했다.
한 변이 1인 정사각형. 대각선의 길이는?

제자 히파소스는 계산을 거듭했다.
√2 = 1.414213...
끝없이 이어지는 숫자들.

"이것은... 분수로 표현할 수 없습니다!"

학파는 경악했다. 세상의 근본이 흔들렸다.
그날 밤, 히파소스는 바다에 수장되었다는 전설이 전해진다.

"신의 실수를 발견한 자의 운명이었도다."
```

**인터랙션**: √2가 무리수임을 발견하는 체험
- 정사각형 대각선 측정 시뮬레이션
- 분수로 표현하려는 시도 → 실패 체험

**퍼즐 메커니즘**:
```
1. 한 변이 1인 정사각형이 나타남
2. 사용자는 대각선 길이를 분수로 추측:
   - 예: 7/5, 10/7, 17/12...
3. 시스템이 계산: (분수)² vs 2 비교
4. 항상 오차 발생!
5. "더 정확한 분수를 찾을 수 있을까?" 반복
6. 일정 시도 후, NPC 히파소스 등장:
   "이것은 영원히 찾을 수 없는 수입니다..."
7. 무리수 개념 설명 애니메이션
```

**클리어 조건**:
- 10회 이상 시도 후 포기: 집착 +2
- 빠르게 패턴 인식: 직관 +1
- 무리수 개념 수용: 상상력 +2

**획득 카드**: "히파소스의 발견"

---

#### Scene 4: 인도 - 0의 탄생과 세계의 변화
**시대**: 628년, 인도 우자인 천문대
**배경**: 별 관측소, 브라마굽타의 연구실

**내러티브**:
```
"'없음'을 어찌 수로 쓸 수 있단 말인가?"

천문학자 브라마굽타는 밤하늘을 관측했다.
별의 위치를 계산하고, 궤도를 예측했다.

그는 새로운 기호를 만들었다. 작은 원, '0'.
'없음'을 의미하는 수.

a + 0 = a
a × 0 = 0
0 ÷ a = 0

세상이 밝아지기 시작했다.
위치기수법이 완성되었다.

"이제 우리는 무한을 표현할 수 있도다."
```

**인터랙션**: 0이 등장하는 순간 세계가 밝아지는 체험
- 0 없는 숫자 체계 → 0 있는 체계 비교
- 위치기수법 퍼즐

**퍼즐 메커니즘**:
```
1. "0이 없는 세계" 장면:
   - 화면이 어둡고 혼란스러움
   - 숫자 270을 표현하려면 복잡한 기호 나열

2. "0의 등장":
   - 작은 원 기호가 빛나며 등장
   - 화면이 서서히 밝아짐

3. 위치기수법 퍼즐:
   - 목표: 205를 표현하기
   - 백의 자리: 2
   - 십의 자리: 0 (없음을 표시!)
   - 일의 자리: 5

4. 성공 시 폭죽 애니메이션
```

**클리어 조건**:
- 기본 클리어: 모든 퍼즐 해결
- 0의 중요성 빠르게 이해: 직관 +2
- 추상 개념 수용: 상상력 +2

**획득 카드**: "브라마굽타의 혁명"

---

#### Scene 5: 아랍 - 십진법의 완성과 전파
**시대**: 825년, 바그다드 지혜의 집
**배경**: 알콰리즈미의 서재

**내러티브**:
```
"숫자의 비밀이 실크로드를 따라 흘러갔다.

바그다드의 학자 알콰리즈미는 인도의 수 체계를 연구했다.
0부터 9까지, 단 열 개의 기호로 모든 수를 표현할 수 있다니!

그는 '인도 수학에 의한 계산법'이라는 책을 저술했다.
이 책은 라틴어로 번역되어 유럽을 뒤흔들었다.

'알고리즘'이라는 단어는 그의 이름에서 유래했도다.

"계산은 이제 예술이 아니라, 방법이 되었노라."
```

**인터랙션**: 십진법 계산법 체험
- 사칙연산 미니게임
- 로마 숫자 vs 아라비아 숫자 계산 속도 비교

**퍼즐 메커니즘**:
```
1. 단계 1: 로마 숫자로 계산
   - XXVII + XLIII = ?
   - 시간 측정: 평균 60초 이상 소요

2. 단계 2: 아라비아 숫자로 계산
   - 27 + 43 = ?
   - 시간 측정: 5초 이내

3. 극적 비교:
   "똑같은 계산인데, 12배 빨라졌습니다!"

4. 복잡한 계산 도전:
   - 987 × 654 = ?
   - 세로 계산법 가이드
```

**클리어 조건**:
- 기본: 모든 계산 완료
- 빠른 계산: 논리 +1
- 패턴 이해: 창의성 +1

**획득 카드**: "알콰리즈미의 지혜"

---

#### Scene 6: 르네상스 - 음수를 둘러싼 논쟁
**시대**: 1545년, 이탈리아 밀라노
**배경**: 카르다노의 연구실

**내러티브**:
```
"빚을 수로 쓴다니, 말도 안 되는 소리!"

수학자들은 음수를 거부했다.
"0보다 작은 수가 어디 있단 말인가?"
"현실에 존재하지 않는 허구의 수다!"

그러나 카르다노는 방정식을 풀다 마주했다.
x + 5 = 3
x = -2

"이것은 빚이다. 빚도 분명 실재하지 않는가?"

논쟁은 거리를 뜨겁게 달궜다.
현자들과 논리 배틀을 벌여야 할 때도다.
```

**인터랙션**: 음수 거부 철학자 NPC와 논리 배틀
- 토론 시뮬레이션
- 음수의 실용성 증명

**퍼즐 메커니즘**:
```
1. NPC 철학자 등장:
   "음수는 존재하지 않는다! 증명해 보라!"

2. 논리 배틀 (3라운드):

   라운드 1: "온도"
   - 질문: 겨울에 영하 5도는?
   - 선택지: 음수로 표현 / 없는 온도라고 주장
   - 정답: 음수로 표현 → 승리

   라운드 2: "빚"
   - 질문: 5원을 가진 사람이 8원을 빚지면?
   - 계산: 5 - 8 = -3
   - NPC: "그것은 빚이지, 수가 아니다!"
   - 반박: "빚도 계산할 수 있어야 합니다!"

   라운드 3: "방정식"
   - x + 3 = 1 풀기
   - x = -2
   - NPC: "...인정하겠다."

3. 승리 시 화려한 애니메이션
```

**클리어 조건**:
- 기본: 3라운드 승리
- 완벽한 논리: 논리 +2
- 추상 개념 수용: 상상력 +1
- 설득력: 창의성 +1

**획득 카드**: "카르다노의 용기"

#### Scene 7: 근대 - 허수와 복소평면
**시대**: 1797년, 독일 괴팅겐
**배경**: 가우스의 서재, 복잡한 수식들

**내러티브**:
```
"√(-1)이라니... 미친 짓이 아닌가?"

데카르트는 이것을 '상상의 수(imaginary)'라 불렀다.
존재하지 않는, 순전히 상상 속의 수.

하지만 오일러는 발견했다. e^(iπ) + 1 = 0
세상에서 가장 아름다운 방정식.

가우스는 더 나아갔다.
복소평면을 그렸다. 실수축과 허수축.

"이제 모든 방정식은 해를 가진다."
대수학의 기본정리.

수의 여정이 완성되는 순간이었도다.
```

**인터랙션**: 복소평면 조작 미니게임
- 복소수를 평면 위 점으로 표현
- 회전, 이동 시뮬레이션

**퍼즐 메커니즘**:
```
1. 복소평면 소개:
   - 가로축: 실수
   - 세로축: 허수

2. 복소수 배치하기:
   - 3 + 2i → (3, 2) 위치에 점 찍기
   - -1 + i → (-1, 1)
   - 2 - 3i → (2, -3)

3. 복소수 연산 시각화:
   - (1 + i) + (2 + i) = ?
   - 벡터 덧셈으로 시각화

4. 오일러 공식 체험:
   - e^(iθ) = cos(θ) + i·sin(θ)
   - 슬라이더로 θ 조정 → 원 위를 도는 점
   - 아름다운 애니메이션

5. 최종 문제: e^(iπ) = ?
   - θ = π 대입
   - 답: -1
   - e^(iπ) + 1 = 0 도출!
```

**클리어 조건**:
- 기본: 모든 단계 완료
- 오일러 공식 이해: 상상력 +3
- 시각적 패턴 인식: 직관 +2
- 수학적 아름다움 감상: 창의성 +1

**획득 카드**: "가우스의 복소평면"

// 플레이어 능력치
interface PlayerStats {
  creativity: number;
  intuition: number;
  persistence: number;
  logic: number;
  imagination: number;
}

interface Card {
  id: string;
  title: string;
  era: string;
  description: string;
  mathematician?: string;
  visual: string;
  statsGained: Partial<PlayerStats>;
}

interface Scene {
  id: string;
  chapterId: number;
  sceneNumber: number;
  title: string;
  era: string;
  location: string;
  narrative: string;
  interactionType: 'puzzle' | 'simulation' | 'debate' | 'minigame';
  clearConditions: ClearCondition[];
  cardReward: string;
}

// 클리어 조건
interface ClearCondition {
  description: string;
  type: 'basic' | 'bonus';
  statsReward: Partial<PlayerStats>;
}

// 챕터
interface Chapter {
  id: number;
  title: string;
  scenes: Scene[];
  totalCards: number;
}

// 게임 진행 상황
interface GameProgress {
  currentChapter: number;
  currentScene: number;
  completedScenes: string[];
  collectedCards: Card[];
  playerStats: PlayerStats;
}
